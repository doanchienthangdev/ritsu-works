# YouTube adapter (Sprint 2 PR4 baseline — v2.0.0)

## When this adapter runs

Dispatched by `wiki-sync/ingest` Step 1 when `<path>` matches:
- `youtube.com/watch?v=*`
- `youtu.be/*`
- `youtube.com/shorts/*`
- `youtube.com/embed/*`

source_kind: `youtube_video`
entity_type: `episode`
wiki target: `wiki/episodes/<slug>.md`

## Inputs

- `path` — YouTube URL (any of the supported forms above)
- `force` — bool; passed through

## External dependencies

- **yt-dlp** — `pip install yt-dlp` OR via brew `brew install yt-dlp`. Must be in PATH.
- **ffmpeg** — required by yt-dlp for audio extraction when whisper fallback fires. `brew install ffmpeg`.
- **OPENAI_API_KEY** — required ONLY if whisper fallback fires (auto-captions missing AND `wiki_sync_llm_fallback` flag enabled).

The adapter fails fast with clear install instructions if a missing dep is detected.

## Process

### Step 1 — Normalize URL + extract video_id

Match URL against the 4 supported forms; extract `video_id` (11-character base64-ish string). Reject playlist URLs (`playlist?list=...`) with workaround: "ingest individual videos one at a time, or fold into a folder-adapter pattern v2.1+".

### Step 2 — Fetch metadata via yt-dlp

```bash
yt-dlp --no-download --print-json --no-playlist "<url>" 2>/dev/null
```

Capture:
- `id` — video_id
- `title` — for slug derivation + wiki page title
- `uploader` / `uploader_id` — attribution
- `upload_date` — YYYYMMDD format
- `duration` — seconds (for cost estimate)
- `chapters` — array of `{start_time, end_time, title}` (if present in description)
- `description` — full video description (parsed for additional refs)

Failure modes:
- yt-dlp not in PATH → bail with install instructions
- Video private / age-gated / removed → bail with clear error
- Region-blocked → bail; suggest VPN or alternative source

### Step 3 — Fetch transcript

Try auto-captions first (free, ~instant):
```bash
yt-dlp --write-auto-subs --skip-download --sub-format vtt --sub-langs en \
       --no-warnings -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

If `en.vtt` exists → parse it (Step 4).
If not, try manual subs (sometimes uploader provides):
```bash
yt-dlp --write-subs --skip-download --sub-format vtt --sub-langs en,vi \
       --no-warnings -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

If still no transcript AND `wiki_sync_llm_fallback` feature flag is enabled AND `OPENAI_API_KEY` is present → whisper fallback (Step 3b). Otherwise bail:
```
No transcript available for video <id>. Auto-captions not generated by YouTube.
Workaround:
  1. Enable wiki_sync_llm_fallback in knowledge/feature-flags.yaml
  2. Set OPENAI_API_KEY in env
  3. Re-run /wiki sync (will whisper-transcribe; cost ~$0.006/min audio)
```

### Step 3b — Whisper fallback (feature-flagged, off by default)

```bash
yt-dlp -x --audio-format mp3 -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

Then call OpenAI Whisper API on `/tmp/yt-<id>.mp3`. Cost: `$0.006 × ceil(duration_min)`. Track in `ops.cost_attributions` with `model='whisper-1'`.

Resulting transcript: plain text without timestamps (Whisper API limitation in standard mode; use `response_format=verbose_json` to get word-level timestamps if needed for chapter alignment).

### Step 4 — Parse VTT to structured transcript

VTT format (typical YouTube auto-caption):
```
WEBVTT

00:00:01.500 --> 00:00:04.000
intro music plays

00:00:04.500 --> 00:00:08.000
welcome back to the channel today we
```

Parser output: array of `{ start_ms, end_ms, text }` cues. Strip duplicate cues (YouTube auto-captions often repeat for visual rolling effect).

### Step 5 — Align with YouTube chapters

If `metadata.chapters` array is non-empty, partition the cue array into chapter buckets (cue's `start_ms` falls in `[chapter.start, chapter.end)`).

If no native chapters AND duration > 10 minutes, auto-detect chapters from VTT cue gaps (gap > 5 seconds of silence often = section break). Output 3-10 chapters max.

### Step 6 — Compose raw_text

```
# <video_title>

**Uploader:** <uploader>
**Date:** <YYYY-MM-DD>
**Duration:** <H:MM:SS>
**URL:** <canonical url>

---

## Chapter 1: <chapter_title>  [00:00 - 03:45]

<cue 1 text>
<cue 2 text>
...

## Chapter 2: <chapter_title>  [03:45 - 08:12]

...
```

The structured raw_text preserves chapter boundaries for downstream chunking (per `ingestion-sources.yaml` `chunking: structural_per_yt_chapter_else_token_1024`).

### Step 7 — Slug generation

- Slug base: `kebab-case(metadata.title)`
- Cap at 60 chars
- Append disambiguator: `<slug-base>-<video_id-first-6>` to handle title collisions across videos
- Example: `make-it-stick-talk-by-roediger-a1b2c3`

### Step 8 — Compute source_hash

`source_hash = sha256(video_id + transcript_text)`. video_id ensures different videos with identical transcripts (unlikely but possible) get different hashes. Transcript content hash means re-running on the same video AFTER YouTube regenerates captions correctly identifies the new content.

## Outputs

```jsonc
{
  "raw_text": "...",
  "source_ref": "https://www.youtube.com/watch?v=<id>",
  "source_hash": "sha256:...",
  "source_kind": "youtube_video",
  "attribution": {
    "uploader": "<channel_name>",
    "uploader_id": "@channel",
    "video_id": "<id>",
    "upload_date": "YYYY-MM-DD",
    "duration_seconds": N,
    "transcript_method": "auto_captions" | "manual_subs" | "whisper_fallback"
  },
  "pages_or_size_metric": "<duration_seconds>",  // used by chapter-splitter if very long
  "suggested_slug": "<title-slug-<id6>>",
  "suggested_entity_type": "episode",
  "chapters_detected": N
}
```

## HITL

- Tier A normally
- Tier B if:
  - whisper fallback would fire (cost > $0.30 for video > 50 min)
  - duration > 2 hours (cost concern + chunker pressure)
  - description contains URL spam or suspicious affiliate links (extract carefully)

## Failure modes

| Symptom | Response |
|---|---|
| yt-dlp not installed | Bail with install instructions (`brew install yt-dlp` or `pip install yt-dlp`) |
| Video private/removed/age-gated | Bail with clear error + video URL |
| Region-blocked | Bail; suggest manual transcript download |
| No transcript + flag off | Bail with workaround instructions (Step 3) |
| No transcript + flag on + no key | Bail "OPENAI_API_KEY missing for whisper fallback" |
| Whisper API rate limit | Retry with exponential backoff (1m → 5m → 30m); after 3 fails, surface to founder |
| VTT parse error (malformed cues) | Log warning; continue with best-effort cue parsing |
| Playlist URL | Bail with refuse-playlist error + single-video workaround |

## Cost estimate

| Path | Per 1 hour video |
|---|---|
| Auto-captions (most common) | $0 fetch + $0.005 embed = **$0.005** |
| Manual subs (some uploaders) | $0 fetch + $0.005 embed = **$0.005** |
| Whisper fallback (when captions missing) | $0.006/min × 60 + $0.005 embed = **$0.36** |
| + LLM-fallback link extraction (Sprint 4 flag) | +$0.05/chapter on top |

Per-task-kind cap from SOP-INGEST-001 README: `wiki-ingest-youtube` = $0.30 / invocation. Whisper fallback for > 50 min videos breaches this → Tier B founder confirm.

## Chapter-split integration (v2.0)

For videos > 100 cues OR `--split` flag:
- This adapter returns standard outputs (raw_text with chapter-headed sections, `pages_or_size_metric=duration_seconds`).
- `wiki-sync/ingest` Step 5 dispatches `wiki-sync/chapter-splitter` in `toc` mode (uses YouTube native chapters from this adapter's `chapters_detected`).
- If native chapters absent, splitter falls back to `count=N` (N derived from duration; ~10 minutes per chapter).
- Each chapter becomes own `ingestion_jobs` row with `parent_job_id` (migration 00030 Block C).
