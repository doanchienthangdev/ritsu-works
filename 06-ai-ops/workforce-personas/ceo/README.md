# CEO — `ceo` — worked example

This folder is the canonical example: the `02-entity-template/` filled in for CEO. When implementing, this is roughly what `06-ai-ops/workforce-personas/ceo/` will contain.

- `PERSONA.md` — CEO voice, posture, decisions
- `playbook.md` — CEO's common routing patterns
- `routing-matrix.md` — full routing table (the master copy for the cabinet)
- `kpis.md` — CEO measurement
- `agent.md` — compiled `.claude/agents/ceo.md`
- `command.md` — compiled `.claude/commands/ceo.md`

CEO is unique: it owns the master routing matrix that all other personas reference. Other personas have local routing matrices; CEO has the cabinet-wide one.
