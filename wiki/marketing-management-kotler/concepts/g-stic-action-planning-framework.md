# G-STIC Action Planning Framework

**Type:** concept · **From:** *Marketing Management* (Kotler/Keller/Chernev 16e SE), Ch 2 — Marketing Planning and Management (pp. 40–45)

## Summary

MM 16e's MBA planning spine: Goal → Strategy (5Cs target market + 3V value prop) → Tactics (7Ts offering) → Implementation (dev + deployment) → Control (performance + environment).

## Raw quotes (verbatim, for citation)

> Five key activities guide the development of an action plan: setting a goal, developing a strategy, designing the tactics, defining an implementation plan, and identifying a set of control metrics. The G-STIC (Goal-Strategy-Tactics-Implementation-Control) framework comprises these five activities and acts as the lynchpin of marketing planning and analysis.
>
> Implementing the company goal requires three main objectives: what the company aims to achieve (goal focus), how much (quantitative benchmark), and when (temporal benchmark).
>

## Ritsu relevance

Ritsu's PMF sprint maps to G-STIC: Goal = 100 paying retained 30d + NPS ≥40; Strategy = students/self-learners + active-learning value prop; Tactics = freemium + referral; Implementation = Collison install; Control = SOP-METRICS-007 weekly tile.
