# Value Chain and Value Delivery Network

> **Source.** [Chapter 2](../chapters/chapter-02-company-and-marketing-strategy.md), book pp. 67–68, chunk 4 (confidence 0.95, auto-accepted).
>
> "Each department carries out value-creating activities to design, produce, market, deliver, and support the firm's products. The firm's success depends not only on how well each department performs its work but also on how well the various departments coordinate their activities."
>
> — Kotler/Armstrong/Opresnik, *Principles of Marketing* (18e Global, Pearson 2021)

## Summary

Value chain = internal departments that each add value across design/produce/market/deliver/support. Chain is only as strong as weakest link. Value delivery network extends outward to suppliers, distributors, customers partnering to improve customer value.

## Additional quotes

> "Competition no longer takes place only between individual competitors. Rather, it takes place between the entire value delivery network created by these competitors."
>

## For Ritsu

Ritsu internal value chain: content ingestion, AI generation, UX delivery, support. External delivery network: LLM providers, payment processors. Weak links (poor PDF parsing, slow quiz generation) immediately degrade the core promise.
