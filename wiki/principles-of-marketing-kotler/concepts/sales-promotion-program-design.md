# Sales Promotion Program Design — 5 Decisions

> **Source.** [Chapter 16](../chapters/chapter-16-personal-selling-and-sales-promotion.md), book pp. 480–486, chunk 5 (confidence 0.95, auto-accepted).
>
> "Consumer promotions: urge short-term buying or boost brand engagement."
>
> — Kotler/Armstrong/Opresnik, *Principles of Marketing* (18e Global, Pearson 2021)

## Summary

(1) Set objectives. (2) Select tools. (3) Determine incentive size (minimum threshold for response). (4) Set participation conditions + distribution channel. (5) Evaluate by comparing sales before/during/after. Avoid 'quick fix' price-only promotions — erode brand equity. Frequency programs (airline miles, IKEA Family) build loyalty via added value not discounted prices.

## Additional quotes

> "Frequency programs (airline miles, hotel points, IKEA Family loyalty club) build loyalty through added value rather than discounted prices."
>
> "Evaluation: Did promotion attract new customers or increase existing customer purchasing? Can new customers be retained?"
>

## For Ritsu

For Ritsu's referral + retention programs: define objectives (e.g., 'increase free→paid conversion 20%'), pick tool (premium for referrer + referred), set conditions (referred user must complete first session), evaluate (cohort analysis). Avoid blanket discounts that train deal-prone users.
