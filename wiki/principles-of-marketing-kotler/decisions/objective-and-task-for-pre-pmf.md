# Use Objective-and-Task Budget Method Pre-PMF

> **Source.** [Chapter 14](../chapters/chapter-14-engaging-consumers-imc.md), book pp. 423–423, chunk 6 (confidence 0.9, auto-accepted).
>
> "Objective-and-task method: Define specific promotion objectives. Determine tasks needed. Estimate costs. Budget = sum of task costs."
>
> — Kotler/Armstrong/Opresnik, *Principles of Marketing* (18e Global, Pearson 2021)

## Summary

Decision: Ritsu uses objective-and-task for promotion budget. Define objective (e.g., '5K new student users Q3 from organic') → identify tasks (SEO, YouTube demos, Reddit seeding) → cost each → sum = budget. Forces explicit ROI assumptions per task.

## Additional quotes

> "Advantage: forces explicit assumptions about promotion ROI."
>

## For Ritsu

Practical implementation: quarterly budget = sum of (tasks needed for each 5As stage × task cost). Tasks without signal within 4 weeks = cut. Track conversion per task through 5As. Mitigates affordable-method drift + competitive-parity laziness.
