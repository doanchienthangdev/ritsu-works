# BHP Mining Acquisition: Scenario Analysis with Development Options

**Type:** observation · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 8 — Problem Solving with Long Time Frames and High Uncertainty

## Summary

Rob McLean led a team advising BHP on a major 50+-year mine acquisition. The analysis built a valuation tree with four key uncertainties (world mineral price, AUD/USD exchange rate, ore volume, development option value) and modeled scenarios including 2-standard-deviation price extremes. Development options were estimated at 22% of NPV. A look-back 20 years later found the analysis was very conservative: China's resource boom produced an outcome close to the bonanza scenario, with billions in value above the original estimate — largely driven by development option value that was underestimated.
