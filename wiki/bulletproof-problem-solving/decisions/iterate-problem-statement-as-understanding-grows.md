# Iterate the Problem Statement as Understanding Grows

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 2 — Define the Problem

## Summary

The chapter recommends treating the problem statement as a living artifact that should be sharpened through successive rounds of data engagement and stakeholder interaction. A first-cut problem statement is rarely the best one; iterating it pays off by generating sharper hypotheses and more targeted strategies.
