# Prune Branches Before Deep Work Using Impact and Feasibility

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 3 — Problem Disaggregation and Prioritization

## Summary

Before investing significant time in analysis or work planning, teams must prune the logic tree using a prioritization matrix that scores each branch on impact (how much does it move the overall problem?) and feasibility (can the team actually affect it?). Branches that are low-impact or immovable should be cut regardless of their intrinsic interest. Prioritization defines what not to work on, which is as important as what to work on.
