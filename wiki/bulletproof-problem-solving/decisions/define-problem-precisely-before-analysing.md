# Define the Problem Precisely Before Analysing

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century

## Summary

The chapter identifies 'weak problem statements' as the first and most common pitfall in problem solving. A good problem statement must have specificity, clarity around the decision-maker's criteria and constraints, an indication of what action will occur if the problem is solved, and a time frame and required accuracy level. Rushing into analysis with a vague problem statement is called 'a clear formula for long hours and frustrated clients.'

## Raw quotes (verbatim, for citation)

- **From [Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century](../chapters/chapter-00-introduction-problem-solving-for-the-challeng.md)** (PDF pp. 15–30, confidence 0.95):

  > Too many problem statements lack specificity, clarity around decision-maker criteria and constraints, an indication of action that will occur if the problem is solved, or a time frame or required level of accuracy for solving the problem.

  > Rushing into analysis with a vague problem statement is a clear formula for long hours and frustrated clients.
