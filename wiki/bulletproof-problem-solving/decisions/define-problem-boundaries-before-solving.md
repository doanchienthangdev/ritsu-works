# Define Problem Boundaries Before Solving

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 1 — Learn the Bulletproof Problem Solving Approach

## Summary

The most important first step is to agree on what the problem is and is not, bounding the scope explicitly. Undefined boundaries cause analysts to waste time on irrelevant dimensions or miss the true problem. The chapter illustrates this with the Sydney Airport case, where the problem was bounded to passenger capacity only, excluding policy factors like noise, safety, or rail alternatives.
