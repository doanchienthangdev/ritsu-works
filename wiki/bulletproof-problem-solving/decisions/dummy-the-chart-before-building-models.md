# Dummy the Chart Before Building Any Model

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 4 — Build a Great Workplan and Team Processes

## Summary

Before starting any analysis or model, pre-visualize what the output would look like ('dummy the chart'). This forces clarity about what question the analysis answers and whether you would actually want the output if you had it. It prevents teams from investing time in analyses whose results would not resolve any hypothesis.

## Raw quotes (verbatim, for citation)

- **From [Ch 4 — Build a Great Workplan and Team Processes](../chapters/chapter-04-build-a-great-workplan-and-team-processes.md)** (PDF pp. 117–140, confidence 0.95):

  > We sharpen our thinking even more by requiring that we can visualize what form the output might take (we call this dummying the chart), so we know if we would want it if we had it.

## Ritsu relevance

Applied to Ritsu capability development: before building a new feature or running an experiment, dummy up 10 exhibits showing what the result would look like and confirm the founder would act differently based on each.
