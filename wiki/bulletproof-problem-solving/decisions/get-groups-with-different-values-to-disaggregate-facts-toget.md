# Get Groups With Different Values to Disaggregate Facts Together

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 9 — Wicked Problems

## Summary

When values conflicts seem to make a problem intractable, the recommended approach is to bring opposing groups into a shared fact-gathering and problem-disaggregation process. This is more effective than debating values directly, because working on a common factual structure creates bridges to common ground — illustrated by gun control and death-penalty cases where error-rate data shifted conversations.
