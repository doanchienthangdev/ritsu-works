# Use the Simplest Model That Sufficiently Explains the Phenomenon

**Type:** decision · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 6 — Big Guns of Analysis

## Summary

The chapter issues an explicit rule against over-specifying models: adding more variables to a regression may improve fit measures but risks overfitting — an artefact of mathematics that reduces external validity. The prescription is parsimony: choose the model with the fewest parameters that adequately accounts for the observed variance. This principle applies equally to machine learning architecture choices.

## Raw quotes (verbatim, for citation)

- **From [Ch 6 — Big Guns of Analysis](../chapters/chapter-06-big-guns-of-analysis.md)** (PDF pp. 165–208, confidence 0.95):

  > always use the simplest model that sufficiently explains your phenomenon.
