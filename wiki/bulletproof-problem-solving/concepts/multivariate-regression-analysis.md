# Multivariate Regression Analysis

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 6 — Big Guns of Analysis

## Summary

Regression is presented as the primary tool for understanding the relative contribution of multiple independent variables to an outcome. Multiple regression allows analysts to 'control for' confounding variables and separate their individual effects. Key pitfalls include confusing correlation with causation, omitted variable bias, and overfitting from adding too many variables — the chapter recommends always using the simplest model that sufficiently explains the phenomenon.

## Raw quotes (verbatim, for citation)

- **From [Ch 6 — Big Guns of Analysis](../chapters/chapter-06-big-guns-of-analysis.md)** (PDF pp. 165–208, confidence 0.95):

  > Multiple regression analysis allows us to combine and control for variables as we explore our understanding of the underlying relationships.

  > Adding more variables may improve the performance of the regression analysis—but adding more variables may then be overfitting the data. This problem is a consequence of the underlying mathematics—and a reminder to always use the simplest model that sufficiently explains your phenomenon.
