# Reasoning by Analogy

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 5 — Conduct Analyses

## Summary

Reasoning by analogy means applying a known problem structure and solution to a new problem that shares the same underlying structure—the reference class. The technique is powerful when the reference class is correct but dangerous when it is misidentified. The chapter recommends lining up all assumptions that underpin the reference class and testing the current case against each. Failure modes include disruptive Internet business models (no prior analogy), beer-wine cross-category acquisitions (false commonality), and halo-effect executive turnarounds like 'Chainsaw' Al Dunlap at Sunbeam.

## Raw quotes (verbatim, for citation)

- **From [Ch 5 — Conduct Analyses](../chapters/chapter-05-conduct-analyses.md)** (PDF pp. 141–164, confidence 0.95):

  > Reasoning by analogy is an important heuristic for quick problem solving. An analogy is when you have seen a particular problem structure and solution before that you think may apply to your current problem.

  > Analogies are powerful when you have the right reference class (that is, have correctly identified the structure type), but dangerous when you don't.
