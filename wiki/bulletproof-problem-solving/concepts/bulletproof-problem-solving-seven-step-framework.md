# Bulletproof Problem Solving Seven-Step Framework

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century

## Summary

A systematic seven-step process for creative problem solving developed at McKinsey & Company. The steps are: (1) define the problem precisely, (2) disaggregate and develop hypotheses, (3) prioritize work, (4) develop a workplan, (5) gather facts and analyse while avoiding cognitive biases, (6) synthesise findings, and (7) communicate conclusions in a compelling way. The framework is intended to be teachable to anyone and applicable across business, nonprofit, government, and personal domains.
