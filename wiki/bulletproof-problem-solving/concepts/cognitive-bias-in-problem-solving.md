# Cognitive Bias in Problem Solving

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century

## Summary

The chapter identifies three biases that corrupt problem solving when teams assert answers prematurely: availability bias (drawing only on facts at hand), anchoring bias (selecting from a previously seen numerical range), and confirmation bias (ignoring data that contradicts prejudices). It also highlights sunk-cost bias (loss aversion) and groupthink as team-level failure modes. The book treats debiasing as an explicit, integrated part of the problem-solving process rather than an afterthought.
