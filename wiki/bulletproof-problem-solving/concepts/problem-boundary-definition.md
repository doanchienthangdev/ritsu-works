# Problem Boundary Definition

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 2 — Define the Problem

## Summary

The explicit articulation of what is in scope and what is off limits for a problem-solving effort. The chapter argues that incorrect boundary definition is a primary source of problem-solving failure: boundaries that are too narrow create blind spots to real threats (as in the newspaper case), while boundaries that are too local sub-optimize for the larger organization. Knowing what is off limits is equally critical to knowing what is in scope.

## Raw quotes (verbatim, for citation)

- **From [Ch 2 — Define the Problem](../chapters/chapter-02-define-the-problem.md)** (PDF pp. 61–78, confidence 0.95):

  > Getting problem definition right, including boundaries, is essential to good problem solving and can be an essential competitive advantage.

  > It is also critical to know what is off limits and to understand the implications of the boundaries to the solution set.
