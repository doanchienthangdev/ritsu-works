# Porpoising

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 2 — Define the Problem

## Summary

An iterative technique of repeatedly diving into data and hypotheses and surfacing back to refine the problem statement, as a porpoise dives and resurfaces. The chapter presents porpoising as the mechanism by which problem statements evolve from vague to sharp: each dive into evidence or stakeholder input yields a better-specified problem, which in turn yields better hypotheses. The chapter explicitly says 'sharp problem statements lead to better and more testable hypotheses.'

## Raw quotes (verbatim, for citation)

- **From [Ch 2 — Define the Problem](../chapters/chapter-02-define-the-problem.md)** (PDF pp. 61–78, confidence 0.95):

  > You should iterate and refine your problem statement as you porpoise into the data and learn more about the problem
