# Seven Common Problem-Solving Pitfalls

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century

## Summary

The chapter catalogues seven recurring failures: (1) weak problem statements, (2) asserting the answer from experience without testing, (3) failing to disaggregate, (4) neglecting team structure and diversity, (5) using an incomplete analytic toolkit, (6) failing to link conclusions into a storyline for action, and (7) treating the process as one-off rather than iterative. The authors present these as the practical motivation for why a complete, integrated seven-step framework is necessary.
