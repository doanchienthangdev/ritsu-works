# Problem Statement Worksheet

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 2 — Define the Problem

## Summary

A structured template that captures the full context of a problem beyond what fits in a single statement. It records outcomes focus, measurability, time bounds, decision-maker values and boundaries, scope for creativity, and the highest-level framing. The worksheet externalizes the constraints and success criteria that a simple problem statement cannot hold.

## Raw quotes (verbatim, for citation)

- **From [Ch 2 — Define the Problem](../chapters/chapter-02-define-the-problem.md)** (PDF pp. 61–78, confidence 0.95):

  > Usually you can't fit all those characteristics into a single statement, so we like to use a problem statement worksheet that captures the whole context
