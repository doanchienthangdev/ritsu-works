# Problem Disaggregation

**Type:** concept · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 0 — Introduction: Problem Solving for the Challenges of the Twenty-First Century

## Summary

The practice of breaking a complex problem into component parts to find the crux of the issue. The chapter argues that few problems can ever be solved without this step. The right 'cleaving point' — the dimension along which to split the problem — determines whether analysis leads to insight or dead ends. The Sydney asthma case illustrates how disaggregation by incidence versus severity revealed a socioeconomic and environmental root cause that aggregate data obscured.
