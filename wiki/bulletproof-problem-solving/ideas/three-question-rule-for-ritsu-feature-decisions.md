# Three-Question Rule for Ritsu Feature Prioritization

**Type:** idea · **From:** *Bulletproof Problem Solving* (Charles Conn, Robert McLean, 2018), Ch 5 — Conduct Analyses

## Summary

The chapter's three-question shortcut (heart-attack triage, knee surgery) suggests that Ritsu's product-orchestrator could adopt a standing three-question screen for feature prioritization: (1) Does the feature improve activation rate for the core ICP? (2) Is there evidence this activity type drives retention beyond day-7? (3) Can it be built within one sprint without adding fixed cost? A simple decision tree from these questions would cut pre-sprint debate and anchor decisions in data.
