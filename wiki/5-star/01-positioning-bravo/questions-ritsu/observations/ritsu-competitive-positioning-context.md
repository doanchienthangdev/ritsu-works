# Ritsu's competitive positioning context

The questions module's framing context defines Ritsu's positioning landscape as a three-way differentiation problem: against established memorization tools (Anki, Quizlet — manual cards), against general-purpose AI assistants (ChatGPT — manual copy-paste), and against fragmented tool combinations that students currently stitch together. Ritsu's claimed wedge is "deep understanding, not memorization" delivered via a CLI-style command surface (`/quiz`, `/explain`) with visual/interactive output, with share links as the viral growth mechanism.

This is a positioning context observation, not a positioning decision — it records what the framework treats as Ritsu's competitive frame as of this module's authoring, and serves as the input for positioning decisions to be made in 01-marketing and 03-gtm sub-pillars. The frame includes a target audience constraint (price-sensitive university students) and a GTM constraint (university pilot launches preceding public freemium launch) that any positioning statement must reconcile.

This matches the product charter's "what Ritsu is NOT" enumeration of ChatGPT, Anki, Quizlet, Kahoot, Notion — though the charter adds Kahoot and Notion which the questions module does not.
