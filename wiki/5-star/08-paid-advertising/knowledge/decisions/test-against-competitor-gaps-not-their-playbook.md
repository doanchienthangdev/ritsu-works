# Test against competitor gaps, not their playbook

The default response to competitor research is to copy what works — same keywords, same messaging, same creative format. The framework rejects this. Look at what they're NOT doing and test the inverse: if competitors emphasize discounts → test premium positioning; if competitors are text-heavy → test minimalist; if competitors use video → test static; if competitors push features → test customer testimonials; if competitors show stock photos → test UGC; if competitors show product-only → test lifestyle context.

The principle: replicating a competitor's playbook lands you in the same auction at the same CPC against an incumbent who has already optimized — a losing position for a smaller advertiser. The gap in their approach is where uncontested attention lives. Differentiation in ad creative is cheaper to win than parity.
