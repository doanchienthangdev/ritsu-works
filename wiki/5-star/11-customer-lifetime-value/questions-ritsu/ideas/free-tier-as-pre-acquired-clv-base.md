# Ritsu's free-user base is a pre-acquired CLV goldmine, not a cost center

The Ritsu question set repeatedly frames the free user base as "an untapped CLV goldmine" — every free user is effectively pre-acquired audience whose conversion cost is approximately zero compared to a cold paid-ad prospect. The strategic question shifts from "how do we get more free users?" to "what conversion rate from the existing free base would maximize CLV without spending another dollar on acquisition?"

This reframing also constrains the roadmap. If free users are zero-cost acquisition, then improving free→premium conversion (subscription default at checkout, usage-triggered upsells, exam-season urgency) is the highest-leverage CLV move available — strictly higher leverage than spending paid budget on new free signups before that conversion math works.
