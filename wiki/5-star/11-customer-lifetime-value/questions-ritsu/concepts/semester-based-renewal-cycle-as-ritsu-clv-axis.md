# Semester-based renewal cycle as Ritsu's natural CLV axis

Ritsu's user population (university students) follows academic calendars, which creates a built-in periodic renewal cycle that most consumer SaaS lacks. The natural repurchase rhythm is semester-based — students "buy" study tools at the start of each term, dial down over summer, and re-engage at the next start. Exam calendars create predictable demand spikes within each semester.

This is a strategic asset, not a limitation. It maps directly to Exposure Ninja's "start renewal marketing before customer runs out" principle: Ritsu can pre-market premium ahead of each semester start using student exam schedules and academic calendars as deterministic triggers. Competitors without education-specific seasonality cannot replicate this signal. The corollary risk: students cancel between semesters, so retention metrics must be measured semester-over-semester, not month-over-month.
