# Define link-building success quantitatively before starting

Before pitching the first publication or writing the first article, define success as a number across multiple dimensions: backlinks per month, referring domains, organic traffic growth, lead generation, keyword rankings. Without quantitative targets, link-building drifts — it always feels like "more would be better," and there's no signal for when to pivot a strategy that isn't working.

The discipline extends to per-strategy benchmarks: guest posting should hit roughly 20% pitch-to-acceptance on personalized pitches; if you're at 5%, something is wrong (either pitch quality, target list, or timing). Each strategy needs a try-period (e.g., 3 months) before pivoting, and a benchmark to evaluate against. This converts "are we getting links?" into "are we on the curve we predicted?" — the only question with an actionable answer.
