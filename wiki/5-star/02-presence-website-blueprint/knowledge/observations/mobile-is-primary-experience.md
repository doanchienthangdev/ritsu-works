# Mobile is the Primary Experience, Not Secondary (60%+ of Traffic)

Mobile drives 60%+ of website traffic for most B2C audiences, which means mobile is the **primary** experience — not a scaled-down desktop afterthought. Hard requirements: text readable without zooming (16px minimum), thumb-friendly buttons (48px minimum tap target), no horizontal scrolling ever, images sized for mobile (not desktop-images-shrunk), unobtrusive mobile navigation (sticky nav or hamburger), mobile-appropriate form input types (number pad, date picker, email keyboard), and table data reformatted for narrow viewports.

Most "mobile-optimized" sites still leak conversions because they treat mobile as a responsive afterthought. The Blueprint's stance: design for mobile first, then expand. If a desktop element doesn't survive that constraint, it probably wasn't earning its space anyway.
