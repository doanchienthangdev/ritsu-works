# Choose Grouping vs. Argument Based on Audience Receptivity

**Type:** decision · **From:** *Cracked It! How to Solve Big Problems and Sell Solutions Like Top Strategy Consultants* (Bernard Garrette, Corey Phelps, Olivier Sibony, 2018), Ch 10 — Sell the Solution: Core Message and Storyline

## Summary

Use a grouping pattern when the audience is receptive and primarily needs reasons or implementation steps. Use an SCR argument pattern when the recommendation is complex, the audience is skeptical, or a list of counter-reasons would feel blunt or confrontational. In argument patterns, summarise the full SCR in the governing thought when it is awkward to state only the resolution upfront.

## Raw quotes (verbatim, for citation)

- **From [Ch 10 — Sell the Solution: Core Message and Storyline](../chapters/chapter-10-sell-the-solution-core-message-and-storyline.md)** (PDF pp. 211–235, confidence 0.95):

  > Choose groupings for "easy sells" and arguments for more difficult ones.

  > Grouping patterns are better suited to simple problems, where audiences are already convinced by the essence of the solution and merely want to know the details of the recommendation or the action plan to implement it.
