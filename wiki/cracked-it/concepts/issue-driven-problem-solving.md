# Issue-Driven Problem Solving

**Type:** concept · **From:** *Cracked It! How to Solve Big Problems and Sell Solutions Like Top Strategy Consultants* (Bernard Garrette, Corey Phelps, Olivier Sibony, 2018), Ch 3 — The 4S Method

## Summary

An alternative to hypothesis-driven reasoning that treats problems as open questions, avoiding the explicit formulation of hypotheses. The problem is broken down using an issue tree—a structured decomposition that examines all facets without a preconceived solution. It is harder to master and more time-consuming than building a hypothesis pyramid, but mitigates the worst manifestations of the solution confirmation pitfall.

## Raw quotes (verbatim, for citation)

- **From [Ch 3 — The 4S Method](../chapters/chapter-03-the-4s-method.md)** (PDF pp. 52–69, confidence 0.95):

  > This version of logical problem solving eschews the formulation of hypotheses, and treats problems as "open questions."

  > An issue-driven approach requires you to break down the problem into smaller components with an issue tree. An issue tree is a way to structure the problem thoroughly, to look at its different facets systematically, without a preconceived idea of what the solution might be.
