# TOSCA Framework

**Type:** concept · **From:** *Cracked It! How to Solve Big Problems and Sell Solutions Like Top Strategy Consultants* (Bernard Garrette, Corey Phelps, Olivier Sibony, 2018), Ch 3 — The 4S Method

## Summary

TOSCA is a five-element checklist for stating a problem before solving it: Trouble (the gap between reality and aspiration), Owner (whose problem it is), Success criteria (what done looks like), Constraints (limits on the solution space), and Actors (stakeholders whose objectives matter). Once all five are answered, the problem solver writes a core question that is consistent with all five elements. The framework is the primary tool of the 'State' step in the 4S method.
