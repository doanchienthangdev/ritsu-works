# Problem Reframing via Empathy

**Type:** concept · **From:** *Cracked It! How to Solve Big Problems and Sell Solutions Like Top Strategy Consultants* (Bernard Garrette, Corey Phelps, Olivier Sibony, 2018), Ch 8 — Redefine the Problem: The Design Thinking Path

## Summary

A core mechanism of design thinking is that deep empathy with users reveals the root cause of a problem that the original problem statement misidentifies. The chapter illustrates this with the GE/Dietz case: hospital administrators framed the problem as 'maximize scans while minimizing sedation costs'—but sedation was a symptom, not the root cause. By understanding why children were scared, Dietz reframed the problem as turning a scary medical procedure into an adventure, unlocking a solution unavailable within the original frame. The chapter argues neither hypothesis-driven nor issue-driven approaches would have led to this reframing.
