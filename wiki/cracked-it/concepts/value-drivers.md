# Value Drivers (Industry-Specific)

**Type:** concept · **From:** *Cracked It! How to Solve Big Problems and Sell Solutions Like Top Strategy Consultants* (Bernard Garrette, Corey Phelps, Olivier Sibony, 2018), Ch 6 — Structure the Problem: Analytical Frameworks

## Summary

Value drivers are the key levers of value creation specific to an industry—the dimensions of performance that actually move profitability in that business. The chapter distinguishes value drivers from accounting line items: revenues-vs-costs is a static MECE split of the income statement but is not MECE from a managerial (dynamic) standpoint because the levers interact. Identifying value drivers requires understanding how management actions in that industry create or destroy value, typically by studying management commentary in financial reports rather than accounting statements.
