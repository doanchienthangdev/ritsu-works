# North Star Framework

**Type:** concept · **From:** *The North Star Playbook* (Amplitude, Inc., John Cutler, Ibrahim Bashir, 2024), Ch 0 — Introduction: Why should you read this playbook?

## Summary

A product management model built around a single metric—the North Star Metric—that best captures the value customers derive from a product. It includes a set of key input metrics that teams can directly influence through daily work. The framework serves three critical purposes: enabling decentralized decision-making, aligning teams, and focusing effort on sustainable product-led growth.
