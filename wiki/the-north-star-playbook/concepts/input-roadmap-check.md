# Input Roadmap Check

**Type:** concept · **From:** *The North Star Playbook* (Amplitude, Inc., John Cutler, Ibrahim Bashir, 2024), Ch 3 — Get specific: defining your North Star

## Summary

A second test for inputs that uses the existing product roadmap as a probe. Teams map current initiatives against each proposed input; a clear link validates the input, an implicit link surfaces hidden assumptions worth discussing, and no link signals either a missing input or a roadmap item of questionable value.

## Raw quotes (verbatim, for citation)

- **From [Ch 3 — Get specific: defining your North Star](../chapters/chapter-03-get-specific-defining-your-north-star.md)** (PDF pp. 23–33, confidence 0.95):

  > In some cases, you can't see the link between the roadmap item and the input. This is a good sign that your set of inputs is missing some factor of your North Star—or that you're working on something that isn't actually valuable.

## Ritsu relevance

Ritsu's product-orchestrator role can run this test weekly: map each roadmap item to a named input metric for '100 paying who love'; items that don't map to any input are candidates for deprioritisation.
