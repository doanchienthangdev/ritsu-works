# Wiki Entity Types (Bài #14 Knowledge Graph)

Per Bài #14 + migration 00006 (`knowledge_pages.page_type` CHECK constraint), wiki entries carry an entity type.

**v4.0 layout (since migration 00032 + Sprint 1 of wiki-sync-from-refs v4.0):** wiki is **source-grouped**, not entity-type-grouped. The `page_type` enum is unchanged (singular per CHECK); the FOLDER convention changed from `wiki/<plural>/<slug>.md` to `wiki/<source-slug>/<plural>/<entity-slug>.md`.

## v4.0 layout

```
wiki/
├── <source-slug>/                          ← one folder per ingested source
│   ├── source.md                           ← page_type ∈ {article, book, episode, meeting, customer, company, person, repo}
│   ├── concepts/<entity-slug>.md           ← page_type='concept'
│   ├── observations/<entity-slug>.md       ← page_type='observation'
│   ├── decisions/<entity-slug>.md          ← page_type='decision'
│   ├── ideas/<entity-slug>.md              ← page_type='idea'
│   └── chapters/chapter-NN.md              ← page_type='book' (book chapters)
├── _index/                                 ← reverse-lookup link-lists (regenerated by index-rebuild skill; NOT canonical entities)
│   ├── concept/<canonical-name>.md
│   ├── observation/<canonical-name>.md
│   ├── decision/<canonical-name>.md
│   └── idea/<canonical-name>.md
└── capabilities/<id>/spec.md               ← page_type='capability' (Phase 8 promoted)
```

### Source RECORD vs Derived entity

The composite UNIQUE on `(extracted_from_source_id, slug)` (migration 00032) draws the line:

- **Source RECORDs**: `extracted_from_source_id IS NULL`. Globally unique slug. Live at `wiki/<source-slug>/source.md`. These ARE the sources (an article, a book, a meeting transcript).
- **Derived entities**: `extracted_from_source_id IS NOT NULL` (FK to a source RECORD page). Slug unique WITHIN that source — `wedge` can exist in `wiki/pg-do-things/concepts/wedge.md` and `wiki/blank-4-steps/concepts/wedge.md` simultaneously. Live under the source's type subfolder.

## File frontmatter convention

Each wiki page should have YAML frontmatter:

```yaml
---
type: concept                                              # singular page_type
slug: wedge
extracted_from_source: wiki/pg-do-things/source.md         # NULL for source RECORDs; v4.0 path format
created: 2026-05-04
updated: 2026-05-04
license_status: public_domain                              # v3.0+ for source RECORDs
---
```

Pre-commit hook + Phase 8 catalog-updater (Bài #20) verify type matches folder.

## Auto-link extraction (Bài #14)

Per `knowledge/link-inference-rules.yaml`, regex patterns extract links from page content:

- Person works_at Company
- Decision attributed_to Person
- Concept mentioned_in Article
- etc.

Links populate `ops.knowledge_links` table → 2x P@5 precision improvement.

**v4.0 cross-page link format:** when traversing packages, include the source-slug prefix: `wiki/<source-slug>/concepts/<entity>.md#anchor`. Same-package links can be relative.
