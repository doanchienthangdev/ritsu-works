# McKinsey 7S Framework

*Category: analysis · Toolkit: Management Consulting*

## What it is
A model of seven interdependent organisational elements — Strategy, Structure, Systems, Shared Values, Style, Staff, Skills — used to assess and align organisational effectiveness.

**Origin:** Tom Peters, Robert Waterman & Richard Pascale at McKinsey, ~1980 ('In Search of Excellence', 1982).

## Why it works
Strategy fails without organisational alignment. The seven elements (three 'hard', four 'soft', anchored by Shared Values) must reinforce each other; a change in one demands changes in the others to be effective.

## When to use
When assessing whether the organisation can execute a strategy, and to plan organisational change.

## Visual
`cycle`

## Step-by-step tutorial
1. Document the current state of each of the seven elements.
2. Define the desired state of each given the chosen strategy.
3. Find misalignments — elements that conflict with the strategy or each other.
4. Design changes that bring all seven into alignment, anchored on shared values.
5. Sequence and implement, then re-check alignment.

## Real-life example — Apple
Apple's elements reinforce one another: a differentiation strategy, functional structure, design-driven systems, 'think different' shared values, a perfectionist style, top-tier staff and deep hardware-software skills — alignment that is hard to copy.

**So what:** Sustained advantage comes from all seven elements reinforcing the strategy.

## Pitfalls
- Changing strategy/structure but ignoring soft S's — counter: align all seven.
- Treating shared values as decoration — counter: anchor the change on them.
