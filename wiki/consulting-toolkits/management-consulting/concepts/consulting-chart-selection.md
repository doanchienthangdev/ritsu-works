# Consulting Chart Selection

*Category: communication · Toolkit: Management Consulting*

## What it is
Choosing the right chart type to convey each message — from a library of standard consulting visuals (waterfall, funnel, matrix, Gantt, speedometer, etc.).

**Origin:** Consulting visual grammar; informed by Gene Zelazny's 'Say It With Charts' (McKinsey).

## Why it works
The chart must match the message type. Comparisons, compositions, distributions, trends and relationships each have a 'correct' chart; matching them makes the evidence instantly readable and the title's claim self-evident.

## When to use
When building each slide of the recommendation deck.

## Visual
`table`

## Step-by-step tutorial
1. State the message of the slide in one sentence (the action-title).
2. Classify the message type (comparison / composition / distribution / trend / relationship).
3. Pick the chart that matches that type.
4. Strip the chart to the data that proves the message; remove clutter.
5. Make the title the conclusion and the chart its proof.

## Real-life example — Consulting (method)
To show why profit fell, a team uses a waterfall bridging last year's profit to this year's via price, volume, mix and cost effects — the chart type makes the driver instantly visible, matching the slide title.

**So what:** Matching chart type to message type makes the evidence speak for itself.

## Template
Per slide: message → message type → chart.

- [ ] Slide message
- [ ] Message type
- [ ] Chosen chart
- [ ] Data shown
- [ ] Clutter removed

## Pitfalls
- Decorative chart that doesn't match the message — counter: pick by message type.
- Overloaded charts — counter: one message per chart.
