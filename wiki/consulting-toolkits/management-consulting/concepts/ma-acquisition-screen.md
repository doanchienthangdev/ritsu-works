# M&A Acquisition Screen & Deal Funnel ('should we acquire this company?')

*Category: growth · Toolkit: Management Consulting*

## What it is
A structured screen for an acquisition: strategic rationale, target fit, valuation, synergies, due diligence and integration.

**Origin:** Standard corporate-development M&A process (the deal funnel: screen → diligence → value → negotiate → integrate).

## Why it works
Most acquisitions destroy value because price exceeds achievable synergies or integration fails. A disciplined funnel forces a clear rationale, an evidence-based valuation, and an integration plan before signing.

## When to use
When the question is 'should we acquire this company?'

## Visual
`funnel`

## Step-by-step tutorial
1. State the strategic rationale (scale, capability, market access) and screen criteria.
2. Shortlist targets against the criteria.
3. Value the target with DCF and comparable transactions; set a walk-away price.
4. Estimate cost and revenue synergies — separately, and net of cost-to-achieve.
5. Run due diligence to validate assumptions; negotiate, then plan integration (Day-1 and 100-day).

## Real-life example — Disney + Pixar (2006)
Disney's $7.4B Pixar acquisition had a clear rationale (refresh animation capability), a valuation, identified creative+distribution synergies, and a deliberate integration approach that preserved Pixar's culture — a model of rationale-before-price-before-integration.

**So what:** Value is created by synergies realised in integration, not by signing the deal.

## Template
Pass each funnel stage; separate synergies from price.

## Pitfalls
- Over-paying on optimistic synergies — counter: net cost-to-achieve and risk-weight.
- No integration plan — counter: plan Day-1 and 100-day before signing.
