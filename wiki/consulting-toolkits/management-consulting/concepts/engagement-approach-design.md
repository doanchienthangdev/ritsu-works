# Engagement Approach Design (Workplan)

*Category: planning · Toolkit: Management Consulting*

## What it is
Designing the phased workplan for an engagement — workstreams, methods, milestones and timeline — that the proposal commits to.

**Origin:** Standard consulting engagement-management practice.

## Why it works
Clients buy confidence in the path, not just the destination. A clear phased approach tied to named methods signals rigor and de-risks delivery for both sides.

## When to use
When writing the approach section of a proposal and planning delivery.

## Visual
`process-flow`

## Step-by-step tutorial
1. Break the engagement into phases mapped to the problem-solving arc.
2. Define workstreams and the named method each uses.
3. Set milestones and a realistic timeline with buffers.
4. Identify the data and client involvement each phase needs.
5. Map to fees and resourcing; present as the proposal's approach.

## Real-life example — Consulting (method)
A cost-reduction proposal lays out diagnose → benchmark → identify levers → implementation-plan phases, each with a method (value-chain, benchmarking, driver-tree) and a milestone, so the client sees exactly how value is produced.

**So what:** A method-anchored workplan turns a promise into a credible path.

## Template
Per phase: workstreams, methods, milestone, duration.

- [ ] Phase
- [ ] Workstreams
- [ ] Methods
- [ ] Milestone
- [ ] Duration
- [ ] Client involvement

## Pitfalls
- Vague approach ('we'll analyse the business') — counter: name the methods.
- No buffers — counter: plan for slippage.
