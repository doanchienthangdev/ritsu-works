# Value Proposition Canvas

*Category: planning · Toolkit: Management Consulting*

## What it is
A tool that maps a customer's jobs, pains and gains against the offering's pain-relievers and gain-creators to ensure fit.

**Origin:** Alexander Osterwalder et al., 'Value Proposition Design', 2014.

## Why it works
Value exists only if the offer fits the customer's real jobs, pains and gains. Mapping both sides explicitly prevents building/selling features nobody values.

## When to use
When articulating the practice's or the proposal's value proposition.

## Visual
`comparison`

## Step-by-step tutorial
1. List the customer's functional/emotional/social jobs.
2. List their pains (obstacles, risks, costs) and gains (desired outcomes).
3. List your products/services and how they relieve pains and create gains.
4. Check fit: does each pain-reliever/gain-creator map to a real pain/gain?
5. Sharpen the value proposition statement around the strongest fits.

## Real-life example — Uber
Uber mapped rider jobs (get somewhere reliably) and pains (hailing, payment friction, uncertainty) to pain-relievers (one-tap request, cashless, ETA/tracking) — a tight value-prop fit that drove adoption.

**So what:** Explicit fit between offer and customer jobs is what makes a value proposition land.

## Template
Map both sides; confirm fit before stating the value prop.

- [ ] Customer jobs
- [ ] Pains
- [ ] Gains
- [ ] Products/services
- [ ] Pain relievers
- [ ] Gain creators
- [ ] Value-prop statement

## Pitfalls
- Listing features with no mapped pain/gain — counter: every feature must relieve a pain or create a gain.
- Assuming the jobs — counter: validate with customers.
