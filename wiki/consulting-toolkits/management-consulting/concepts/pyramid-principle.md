# Minto Pyramid Principle

*Category: communication · Toolkit: Management Consulting*

## What it is
A top-down structuring method for communication: lead with the answer, then group supporting arguments MECE-ly beneath it.

**Origin:** Barbara Minto at McKinsey; 'The Minto Pyramid Principle' (1987).

## Why it works
Executives want the conclusion first. Structuring the message as a pyramid — governing thought on top, supported by a MECE set of arguments, each backed by data — matches how people absorb a recommendation and makes the logic auditable.

## When to use
When structuring any recommendation, report, or executive presentation.

## Visual
`tree`

## Step-by-step tutorial
1. State the single governing thought (the answer) at the top.
2. Support it with 3-4 mutually exclusive, collectively exhaustive key arguments.
3. Back each argument with data/analysis at the level below.
4. Check vertical logic (each level summarises the one below) and horizontal logic (arguments are MECE and ordered).
5. Open the document/presentation with the governing thought, not the build-up.

## Real-life example — McKinsey (method)
McKinsey decks lead with the recommendation on page one, supported by a MECE set of arguments and evidence — the Pyramid Principle is the firm's house style for every client document.

**So what:** Answer-first, MECE-supported communication is faster to absorb and harder to refute.

## Template
Write the governing thought, then the MECE arguments and their evidence.

## Pitfalls
- Building up to the answer (chronological) — counter: lead with it.
- Overlapping arguments — counter: enforce MECE.
