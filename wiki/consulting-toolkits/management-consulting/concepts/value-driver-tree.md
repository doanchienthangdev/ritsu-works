# Value Driver Tree

*Category: financial · Toolkit: Management Consulting*

## What it is
A tree that decomposes a top-line value metric (e.g. profit or ROIC) into the operational drivers that move it.

**Origin:** Rooted in the DuPont analysis (DuPont Corp., 1910s) and modern value-based-management practice.

## Why it works
You manage what you can decompose. Breaking value into a hierarchy of drivers (price, volume, cost, capital) shows exactly which levers create or destroy value and by how much.

## When to use
In internal/financial analysis and to quantify where value is made and improvement comes from.

## Visual
`tree`

## Step-by-step tutorial
1. Pick the value metric to explain (profit, ROIC, FCF).
2. Decompose it arithmetically into first-level drivers (revenue, cost, capital).
3. Break each into operational sub-drivers down to controllable levers.
4. Quantify the dollar/percent sensitivity of each leaf.
5. Rank levers by impact and feasibility; focus the recommendation on the top few.

## Real-life example — Amazon
Amazon manages a clear free-cash-flow driver tree — decomposing into revenue growth, contribution margin, fixed-cost leverage and working-capital efficiency (negative cash-conversion cycle) — to know which levers fund reinvestment.

**So what:** A driver tree makes the path from operations to value explicit and quantifiable.

## Pitfalls
- Drivers that don't multiply/add up to the parent — counter: keep the math exact.
- Un-quantified leaves — counter: size each in $.
