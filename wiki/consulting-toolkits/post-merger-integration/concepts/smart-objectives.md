# SMART Integration Objectives

*Category: strategy · Toolkit: Post Merger Integration*

## What it is
A structured objective-setting method ensuring each integration objective is Specific, Measurable, Achievable, Relevant, and Time-bound — converting broad deal rationale statements into actionable, trackable commitments.

**Origin:** SMART criteria attributed to George Doran (1981), 'There's a S.M.A.R.T. Way to Write Management's Goals and Objectives', Management Review. Universally applied in project management and strategic planning.

## Why it works
Integration objectives stated as 'realize revenue synergies' or 'integrate cultures' are unmeasurable and unaccountable. SMART forces the leadership team to commit to specifics before execution begins, making progress observable and deviation visible.

## When to use
Phase I Step 2, immediately after the deal rationale canvas is complete. Objectives must be agreed before the KPI register is built.

## Step-by-step tutorial
1. Begin with the deal rationale canvas — each driver generates at least one integration objective.
2. Draft an objective statement for each driver. Test against SMART: is it specific enough to assign to one owner? Is there a metric that confirms it? Is the target achievable given known constraints? Does it link to deal value? Does it have a deadline?
3. Distinguish horizons: Day-1 objectives (what must be true for operations to function on close), Year-1 objectives (early synergy realization), Year-3 objectives (strategic transformation completion).
4. Limit to 5–8 objectives — more than 8 signals insufficient prioritization.
5. Assign one accountable owner per objective — not a committee.
6. Validate objectives with the Steering Committee and lock them before workstream planning begins.

## Real-life example — United Airlines / Continental Airlines merger (2010)
United and Continental set explicit SMART integration objectives including a specific milestone to achieve a single FAA operating certificate — a measurable, time-bound regulatory objective. The certificate was achieved in November 2011, one year post-close. Without this specific milestone, the integration teams would have had no single north-star that defined regulatory readiness.

**So what:** Regulatory milestones make ideal SMART objectives — they are binary (achieved or not), date-bound, and universally visible.

## Template
Write one row per integration objective. Test each against all five SMART criteria before the Steering Committee session.

- [ ] Objective statement
- [ ] Specific: what exactly will be different
- [ ] Measurable: KPI name + current baseline + target value
- [ ] Achievable: assumption or evidence supporting achievability
- [ ] Relevant: which deal driver does this serve
- [ ] Time-bound: target date (Day 1 / Year 1 / Year 3)
- [ ] Accountable owner

## Pitfalls
- Objectives written at the deal-thesis level — 'achieve cost synergies' is not an objective, it is a category; 'reduce combined headcount costs by $45M by December 31' is an objective.
- Too many objectives dilute focus and accountability — limit to 5–8 regardless of integration complexity.
- Not updating objectives when the integration reveals that some deal assumptions were wrong — SMART objectives should be living commitments, not a founding document.
