# McKinsey 7S Model

*Category: diagnosis · Toolkit: Post Merger Integration*

## What it is
A framework analyzing an organization across seven interdependent dimensions — Strategy, Structure, Systems, Shared Values, Style, Staff, and Skills — to identify alignment gaps and guide organizational design and change.

**Origin:** Developed by Tom Peters and Robert Waterman at McKinsey in the late 1970s, published in 'In Search of Excellence' (Harper & Row, 1982). One of the most widely cited organizational analysis frameworks globally.

## Why it works
Organizational effectiveness depends on the coherent alignment of all seven dimensions, not structure alone. In PMI, an integration that changes Structure (org chart) without addressing Systems (IT, processes) or Shared Values (culture) will fail to produce the behavioral changes the deal requires.

## When to use
Phase I Step 6 (integration approach design) and Phase III Step 4 (culture integration planning). Use as completeness check at every 90-day integration review.

## Step-by-step tutorial
1. For each of the seven dimensions, document the current state for BOTH acquirer and target — do not assume you know the target's state; use due diligence data and early-integration interviews.
2. Identify the desired future state for each dimension in the integrated organization.
3. Map the gap between current and desired state for each dimension — rank gaps by severity.
4. Identify interdependencies: which gap must be resolved first because others depend on it? (Typically: Strategy must be clear before Structure can be set; Structure before Systems; Shared Values must be explicitly addressed once Structure and Systems are moving.)
5. Assign an integration initiative to close each material gap, and assign it to the relevant workstream.
6. Use the 7S model as a completeness check at every 90-day integration review: has every dimension been addressed in the integration plan?

## Real-life example — Daimler / Chrysler merger (1998, $36B)
The Daimler-Chrysler merger is the canonical 7S misalignment case. Strategy (premium German engineering + American mass-market volume) was fundamentally contradictory. Structure (dual headquarters, dual leadership) was unresolved. Shared Values were diametrically opposed. Systems were never integrated. The merger was unwound in 2007 at a fraction of the original price. A rigorous 7S analysis before integration design would have surfaced the irreconcilable tensions.

**So what:** The 7S model's PMI power is as a pre-flight check — identify misalignments before the integration plan is locked, not after execution has amplified them.

## Pitfalls
- Treating the 7S as a labelling exercise rather than a gap analysis — the framework only creates value when gaps are identified and closed.
- Neglecting the Soft Ss (Shared Values, Style, Staff, Skills) in favour of the Hard Ss — the Soft Ss are where integration most commonly fails.
- Running the 7S analysis too late — by the time the org chart is announced, many Soft S decisions are already effectively made.
