# Stakeholder Engagement Matrix

*Category: stakeholder-management · Toolkit: Post Merger Integration*

## What it is
A structured matrix translating the Power/Interest Grid quadrant assignment into specific, bespoke engagement strategies for each priority stakeholder — detailing the engagement type, frequency, channel, key messages, and relationship owner.

**Origin:** Extension of the Mendelow Power/Interest Grid; codified in PMI PMBOK Guide stakeholder management practices and in McKinsey, Deloitte, and BCG integration communication frameworks.

## Why it works
The Power/Interest Grid identifies who needs attention; the Engagement Matrix specifies how to give it. Without the matrix, 'Manage Closely' remains an intention — with it, every relationship has an owner, a touchpoint schedule, and a key message.

## When to use
Phase VI Step 2. Built immediately after the stakeholder analysis; updated monthly.

## Step-by-step tutorial
1. For each priority stakeholder from the Power/Interest Grid, write the engagement strategy using the quadrant as a starting point.
2. For 'Manage Closely' stakeholders, define co-creation touchpoints (bilateral meetings, working group membership, advance briefings before public announcements).
3. For 'Keep Satisfied' stakeholders, define a regular briefing cadence (monthly report, quarterly meeting) and an escalation trigger (what development requires an out-of-cycle call).
4. For 'Keep Informed' stakeholders, design a proactive communication program (newsletter, milestone announcements, open Q&A sessions).
5. For each stakeholder, draft the 3–5 key messages most relevant to their concern — the engagement is only useful if the message is relevant.
6. Review the engagement matrix monthly and update sentiment scores based on the most recent touchpoint.

## Real-life example — AB InBev / SABMiller (2016)
The South African Competition Commission was classified as 'Manage Closely': AB InBev assigned a dedicated regulatory partner as relationship owner, held bilateral meetings every 2 weeks during the review period, and provided advance briefings on all structural remedies before public announcements. This pre-signalling strategy prevented the surprise-and-backlash dynamic that often characterizes regulatory review.

**So what:** For regulatory stakeholders classified as 'Manage Closely', advance notice of decisions (before public announcement) is the most important relationship-building tool — regulators hate surprises.

## Template
Complete one row per priority stakeholder. Update after each touchpoint.

- [ ] Stakeholder name
- [ ] Quadrant (Manage Closely / Keep Satisfied / Keep Informed / Monitor)
- [ ] Engagement type (co-create / brief / inform / monitor)
- [ ] Touchpoint frequency
- [ ] Primary channel
- [ ] Key messages (top 3)
- [ ] Relationship owner
- [ ] Current sentiment (Supportive / Neutral / Resistant)
- [ ] Target sentiment
- [ ] Last touchpoint date and outcome
- [ ] Next planned touchpoint

## Pitfalls
- Engagement matrix as a planning document only — it must be a living record updated after each touchpoint.
- All touchpoints assigned to the IMO Director — high-priority stakeholders require the most senior available relationship owner.
- Key messages that don't address the stakeholder's actual concern — if a major customer's key concern is product roadmap continuity, a message about financial performance is irrelevant.
