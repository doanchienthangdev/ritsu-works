# Capability Heat Map

*Category: analysis · Toolkit: Operating Model & Organization Design*

## What it is
A structured diagnostic that scores each strategic capability (required by the strategy) on two dimensions—current state (1–5) and required target state (1–5)—to produce a visual priority map of capability gaps.

**Origin:** Synthesized from McKinsey's Organizational Health Index and the capability-based strategy literature (Prahalad & Hamel's 'Core Competencies of the Corporation', HBR 1990).

## Why it works
Strategy execution fails most often not because the strategy is wrong but because the organization lacks the capabilities to execute it. The capability heat map makes the gap between 'where we are' and 'where we need to be' visible, quantified, and actionable—converting an abstract strategic intent into a concrete development agenda.

## When to use
Use at the start of Phase 2 (Capability Management pillar) as the foundational gap analysis.

## Step-by-step tutorial
1. Define the strategy in operational terms: what must the organization be able to do better than competitors to win?
2. Brainstorm the required capabilities with the leadership team (workshop, 2 hours). Converge on 8–12 strategic capabilities.
3. Score current state for each capability using a 1–5 scale: 1=non-existent/very weak, 3=adequate, 5=best-in-class. Use evidence (benchmarks, customer feedback, process data) to anchor scores.
4. Score required target state for each capability using the same scale: 'What level do we need to be at to execute the strategy?'
5. Calculate gap = target minus current. Rank by gap size.
6. Color-code: gap 0–1 = green (maintain), gap 2 = amber (develop), gap ≥3 = red (urgent priority).
7. For each red and amber capability, generate at least 2 initiative ideas in Phase 3.

## Real-life example — Walmart
When Walmart launched its e-commerce transformation in 2016, its capability heat map (implicit in its strategic planning) showed a critical gap in digital commerce and data analytics (current state: 1–2; required state: 5). This drove the $3.3B acquisition of Jet.com—a 'buy' decision in the build-buy-borrow-bot taxonomy—rather than an attempt to build the capability organically, which was assessed as too slow given the Amazon competitive threat.

**So what:** The capability heat map's most valuable output is often the sourcing decision it implies: should each capability gap be closed by building, buying, borrowing (partnership), or automating (bot)?

## Template
List 8-12 strategic capabilities. Score current and target. Calculate gap. Color-code. Prioritize.

- [ ] Capability name | Current state (1-5) | Evidence for current score | Required state (1-5) | Gap | Priority (red/amber/green) | Proposed sourcing (build/buy/borrow/bot)

## Pitfalls
- Listing operational activities instead of strategic capabilities—'answer customer calls' is a task; 'omnichannel customer service excellence' is a capability.
- Scoring current state too generously due to executive optimism bias—anchor scores with benchmarks or customer data, not self-assessment alone.
- Not defining 'required state' against competitive benchmarks—a score of 3 might be fine if competitors are at 2 but catastrophic if competitors are at 4.
