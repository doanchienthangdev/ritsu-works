# Value vs. Complexity Prioritization Matrix

*Category: prioritization · Toolkit: Operating Model & Organization Design*

## What it is
A 2×2 prioritization tool that plots initiatives on strategic value (y-axis) vs. implementation complexity (x-axis) to classify them as Quick Wins, Strategic Investments, Fill-Ins, or Deprioritize.

**Origin:** Adapted from the classic Boston Consulting Group portfolio logic, widely standardized in management consulting practice since the 1990s.

## Why it works
Not all high-value initiatives are equally urgent, and not all complex initiatives are strategic. By separating value from complexity, the matrix creates a rational sequencing logic: Quick Wins first (build momentum and fund further change), Strategic Investments second (the core transformation), Fill-Ins when capacity exists, and Deprioritize everything else.

## When to use
Use at the start of Phase 5 (Prioritize) and re-run quarterly during implementation.

## Step-by-step tutorial
1. List all approved initiatives from Phase 4.
2. Score each initiative on strategic value (1–5): Does it directly close a gap to a stated strategic objective? A score of 5 means direct, material impact on a top-priority objective.
3. Score each initiative on implementation complexity (1–5): Combines timeline (1=<3 months, 5=>18 months), resource intensity, stakeholder resistance, and technical difficulty.
4. Plot each initiative on the 2×2 matrix using its value and complexity scores.
5. Label each quadrant and assign sequencing: Quick Wins in Months 1–3, Strategic Investments in Months 3–18, Fill-Ins as opportunistic, Deprioritize as formally out of scope.
6. Validate the quadrant assignments with functional leads to catch scoring errors.
7. Revisit the matrix quarterly as new information changes the value or complexity of initiatives.

## Real-life example — Microsoft
When Satya Nadella became CEO in 2014, he applied implicit Value vs. Complexity logic to deprioritize the Windows Phone initiative (high complexity, declining strategic value) and accelerate the Azure cloud business (high value, already-in-motion momentum). This sequencing freed engineering resources for the high-value/now-manageable-complexity initiatives like Office 365's subscription transition, which became Microsoft's largest revenue engine within 4 years.

**So what:** The matrix's most important output is often the bottom-right quadrant (Deprioritize)—the explicit decision to stop doing something is more valuable than the decision to do new things.

## Pitfalls
- Letting politics inflate the value scores of pet projects—require evidence for any value score above 3.
- Underestimating complexity because the team hasn't done the implementation planning yet—use reference-class forecasting (similar past projects) to calibrate complexity scores.
- Never re-running the matrix—strategic value and implementation complexity both change as the transformation proceeds.
