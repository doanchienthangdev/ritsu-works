Ritsu Works — Knowledge Manifest

File này là HỢP ĐỒNG nói cho tất cả agent biết nơi mỗi loại sự thật công ty được lưu trữ. Đọc file này trước khi tìm kiếm, query, hoặc ghi dữ liệu.

Bốn tầng:
  T1 = Canonical (repo git này) — nhân dạng, chiến lược, SOP, skill, agent
  T2 = Operational (Postgres / Supabase ritsu-ops) — trạng thái hiện tại
  T3 = Events & Artifacts (Supabase Storage / S3) — append-only, bất biến
  T4 = Derived (Vector DB + cache) — có thể xây dựng lại từ T1+T3

Quy tắc:
  - Tier 1 là nơi duy nhất con người thương lượng ý nghĩa. Chỉ PR.
  - Tier 2/3 có thể được ghi bởi agent theo RACI trong mỗi SOP.
  - Tier 4 không bao giờ có thẩm quyền. Rebuild scripts nằm trong `scripts/sync/`.
  - DDL cho mọi Tier 2 table nằm trong `supabase/migrations/`.
    (`knowledge/schemas/` chứa JSON Schemas xác thực file YAML registry,
     KHÔNG phải SQL — đừng tìm DDL table ở đó.)
