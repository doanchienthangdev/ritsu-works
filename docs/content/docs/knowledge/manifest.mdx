## Mô tả

Ritsu Works — Knowledge Manifest

File này là CONTRACT cho biết mỗi loại company truth nằm ở đâu cho mọi
agent. Đọc nó trước khi search, query, hoặc write data.

Bốn tier:
  T1 = Canonical (git repo này) — identity, strategy, SOPs, skills, agents
  T2 = Operational (Postgres / Supabase ritsu-ops) — state hiện tại
  T3 = Events & Artifacts (Supabase Storage / S3) — append-only, immutable
  T4 = Derived (Vector DB + caches) — rebuildable từ T1+T3

Quy tắc:
  - Tier 1 là tier duy nhất nơi con người negotiate ý nghĩa. Chỉ PRs.
  - Tier 2/3 có thể được agent write theo RACI trong mỗi SOP.
  - Tier 4 không bao giờ là authoritative. Rebuild scripts ở `scripts/sync/`.
  - DDL cho mọi Tier 2 table nằm ở `supabase/migrations/`.
    (`knowledge/schemas/` chứa JSON Schemas validate registry YAML files,
     KHÔNG phải SQL — đừng tìm table DDL ở đó.)
  - Operating AI KHÔNG ĐƯỢC write tới product.supabase. Read-only qua ETL.
