## Description

============================================================================
write-types.yaml — content-type registry (capability write-platform)
============================================================================
The vocabulary of `/write --type=<id>`. Each type carries its popular
`mediums[]` (the `/write --medium=<id>` options for that type), a default
length, a structure hint that seeds the orchestrator's outline, and
`recommends` flags that drive auto image/dataviz/research enrichment.

`humanize: true` is the default for every type — de-AI is the whole point.
A type may set `humanize: false` only where AI-tells are irrelevant (none do
in v0.1; the field exists for future structured/code-only types).
