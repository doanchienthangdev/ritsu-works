## AI Runtime endpoint

Each MDX page has a stable endpoint:

```
GET /api/raw/<category>/<slug>
```

Returns `text/markdown` (frontmatter + body) so AI agents can fetch as runtime context. Examples:

- `/api/raw/agents/cto` → CTO persona definition
- `/api/raw/skills/docs-engine` → docs-engine umbrella skill
- `/api/raw/sops/SOP-AIOPS-001-deprecate` → SOP deprecate flow
