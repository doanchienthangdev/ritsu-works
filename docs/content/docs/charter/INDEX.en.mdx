# 00-core — Where to find each kind of truth

## What this folder is

**00-core is the canonical foundation of `ritsu-works`** — the "who / what / why" that every AI agent, the cofounder (when joining), and every future operator references back to. If you're making a decision and unsure what Ritsu would do, the answer is either:

1. **In here** — read the relevant doc and apply.
2. **Documented as "not yet decided"** — see the stubs with `entry_condition` frontmatter for what triggers a fill.
3. **Out of scope for this pillar** — `00-core` covers identity + strategy + operating principles at the COMPRESSED level. Detailed workflows live in other pillars (`03-gtm/`, `04-product/`, `05-customer/`, etc.).

Tier 1 governance applies: any edit to 00-core is **HITL Tier C** per `governance/HITL.md` (PR-only). This file is the navigation index — it changes when docs are added / removed / promoted from stub to v0.1-draft to canonical.

## When to read 00-core

**For new AI agent sessions:**
- Relevant docs auto-load via CLAUDE.md imports (product, brand_voice, transparency) — these 3 are the always-on minimum
- On-demand for other docs: skill invokes `Read 00-core/<doc>.md` OR `/core compose <bundle>` for a coherent set

**For cofounder onboarding (when cofounder formally joins):**
- Read this INDEX first (~3 min)
- `/core compose identity` for "who is Ritsu" bundle — ~20 min reading
- `/core compose strategy` for "what we're building toward" bundle — ~15 min reading
- Drill into individual docs via `/core show <doc>` as questions arise
- Then `governance/HITL.md` + `governance/ROLES.md` for decision rights + workforce structure

**For founder review:**
- Quarterly: `/core diff` to see what's changed since last review; soul-audit cycle per SOP-FOUNDER-015
- At stage transitions (100 paying → PMF-scaling; etc.): revisit canonical docs; promote v0.1-drafts; graduate stubs whose `entry_condition` has fired

**For skill / capability building (via `/cla propose`):**
- `/core compose <relevant bundle>` for context — the canonical answers cited rather than re-derived
- Reduces "every agent invents its own north star" silent drift
