# /mcp-doctor

Chạy CLI chẩn đoán của supabase-ops MCP shim và hiển thị kết quả.

## Lệnh này làm gì

Thực thi chẩn đoán từ `mcp-server/src/cli/doctor.ts`. Mỗi check là một
trong các trạng thái PASS / FAIL / WARN / SKIP. Failures chỉ ra cách sửa
cụ thể (tên env var thiếu, migration thiếu, v.v.).

## Khi nào sử dụng

- Ngay sau khi pull main / chuyển worktrees — xác minh môi trường đã được cấu hình
- Khi một skill sử dụng tool `mcp__supabase-ops__*` thất bại — nhanh chóng
  phân loại xem shim có ổn hay không
- Sau khi áp dụng migration 00026_mcp_query_rpc.sql — xác nhận RPC đã hoạt động
- Định kỳ (ví dụ đầu phiên) như một kiểm tra cơ bản

## Cách chạy

```bash
cd /Users/doanchienthang/ritsu-works   # hoặc thư mục gốc repo phù hợp
npm --prefix mcp-server install         # chạy một lần, nếu chưa làm
npm --prefix mcp-server run doctor
```

Hoặc gọi slash command này trong Claude Code — nó sẽ chạy cùng bash
và trả về output đã render.

## Các chế độ lỗi thường gặp

| Triệu chứng | Nguyên nhân có thể | Cách sửa |
|---|---|---|
| `env loaded FAIL — MissingEnv: SUPABASE_OPS_URL` | env var chưa được export | `export SUPABASE_OPS_URL=https://<project_ref>.supabase.co` |
| `project_ref allowlisted FAIL` | URL trỏ vào Product Supabase | **DỪNG — đây là sự cố bảo mật**. Xác minh URL là ritsu-ops, không phải ritsu |
| `mcp-tools.yaml loaded FAIL` | File thiếu hoặc lỗi parse YAML | kiểm tra cú pháp `knowledge/mcp-tools.yaml` |
| `ops.ops_run_select RPC FAIL — not deployed` | migration 00026 chưa được áp dụng | `bash scripts/wave2-bootstrap-cron-secrets.sh` không phù hợp ở đây — dùng `supabase db push --linked --yes` |
| `supabase connectivity FAIL — JWT expired` | service key đã được rotate | rotate `SUPABASE_OPS_SERVICE_KEY` từ project settings |

## Bash để thực thi

Bash bên dưới tự động phát hiện thư mục gốc repo và source `runtime/secrets/.env.local`
từ **root repo** (không phải worktree — runtime/secrets/ bị gitignore và
chỉ tồn tại tại vị trí canonical của repo). Việc đi ngược lên thư mục gốc repo
của Doctor xử lý tự động việc đổi CWD của npm (xem env.ts findRepoRoot).

```bash
REPO_ROOT="$(git rev-parse --show-toplevel 2>/dev/null)" || REPO_ROOT="/Users/doanchienthang/ritsu-works"
cd "$REPO_ROOT" || exit 1
# Source env from root repo path (runtime/secrets/ is gitignored, only at root)
ROOT_ENV="/Users/doanchienthang/ritsu-works/runtime/secrets/.env.local"
if [ -f "$ROOT_ENV" ]; then
  set -a; source "$ROOT_ENV"; set +a
fi
RITSU_REPO_ROOT="$REPO_ROOT" npm --prefix mcp-server run doctor 2>&1
```
