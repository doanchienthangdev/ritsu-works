`page/governance-HITL` when any capability is HITL tier B+), `goal_metrics`, optional

| `feature_disabled` | `RESOLVER_JIT_ENABLED=false` in `.env.local` | Unset env var + restart session to re-enable JIT mode. Fall back to v2.2 ambient (if CLAUDE.md still has @imports) or `--mode=C` keyword fallback. |
| (no error, but `degraded: true`) | catalog corrupt | Returns INDEX-only data as fallback. Fix `knowledge/recipients/*.md` manually + regen INDEX via `pnpm resolver:index`. Founder alert via `ops.events resolver.catalog_corrupt`. |
| (no error, but empty `matches[]`) | NO_MATCH — no recipient passes keyword pre-filter | Broaden intent; drop `--kind` filter; check `--role` allowlist; verify spelling. |
| (sync errors) `lock_held` | concurrent `--apply` running | Wait 10 min (`.archives/resolver-v2-sync.lock` staleness) OR `rm` lock if known-dead session. |

## Defensive notes

- `/resolver sync --auto-pr` opens a PR via `gh` CLI; requires `gh auth login` + clean working tree
- Concurrent `--apply` blocked by `.archives/resolver-v2-sync.lock` (10-min staleness — `rm` if known-dead)
- `/resolver query` Mode A2 writes audit row best-effort (failure non-blocking, returns `audit_run_id: null` silently)
- Mode C keyword fallback recall ~30%; prefer Mode A2 (JIT MCP) or Mode A (ambient) whenever possible
- Per-session find() hard cap **20 in 4h window** — circuit breaker against runaway loops (cherry-pick #11)
- `pre-tool-publish` hook gates external publishing actions per `governance/HITL.md` — runs before MCP write tools touch external surface
- `pre-bash-mass-action` hook (cherry-pick #13, post-cutover) logs bypass events when model uses Bash instead of available recipient — observability only, never blocks
- `RESOLVER_JIT_ENABLED=false` in `.env.local` disables MCP tool path → emergency rollback without code change
