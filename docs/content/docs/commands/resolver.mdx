## Argv schema (mỗi verb)

```
/resolver query "<trigger>" [flags]
  positional:
    <trigger>            bắt buộc; trigger string để match
  flags:
    --semantic           bật semantic fallback (v1.1; v1.0 trả về SemanticUnavailable)
    --plan               trả về composition.plan nếu route có (CP-2)
    --json               output machine-readable
    --role=<r>           override caller role (mặc định: $MCP_CALLER_ROLE)
    --kind=<k>           giới hạn theo recipient kind cụ thể

/resolver list [flags]
  flags:
    --kind=<k>           skill | command | agent | mcp | wiki | sop | capability | persona
    --pillar=<p>         tên 0X-pillar
    --role=<r>           filter theo role_scope
    --status=<s>         active | stub | deprecated
    --json               machine-readable

/resolver validate [<file>]
  positional:
    <file>               tùy chọn; routes file cụ thể. Bỏ trống để chạy tất cả.
  flags:
    --verbose            output đầy đủ (mặc định: terse pass/fail)

/resolver sync [flags]
  flags:
    --dry-run            (mặc định theo D-2) in diff đề xuất; không ghi gì
    --apply              ghi thay đổi vào working tree local
    --auto-pr            apply + commit lên branch + mở PR (Tier C)
    --kind=<k>           giới hạn theo recipient kind cụ thể (skill | command | agent)

/resolver explain "<trigger>" [flags]
  Luôn verbose. Hiển thị: tokenization, keyword hits theo từng route, semantic
  scores (nếu --semantic), kết quả role filter, quyết định cuối.
  flags:
    --semantic           include semantic match attempt (v1.1)
```

## Cách invoke

Chạy các Node script ở project root:


## Khi nào invoke explicit

Các verb của lệnh này hướng tới operator (build/manage/introspect). Mode
TIÊU THỤ CHÍNH của resolver là BACKGROUND-LAYER (skills/agents invoke
`resolver-query` SKILL hoặc `mcp__supabase-ops__resolver_query` MCP tool
một cách trong suốt).

Dùng `/resolver query` explicit khi:
- Bạn muốn xem cái gì sẽ được dispatch mà không thực sự dispatch
- Bạn đang curate overrides và cần test một trigger
- Bạn đang debug tại sao lookup của agent chọn một recipient cụ thể
- Onboarding (ví dụ `/resolver list` để xem tất cả routes)
