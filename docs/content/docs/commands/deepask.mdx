## Dispatch (vòng lặp 5-stage)

0. **Pre-flight (orchestrator):** **resolver-budget accountant** — đọc `session_finds_count` mới nhất, gọi `breaker-budget.cjs`; nếu không viable → emit PARTIAL trung thực ngay (`gap_reason='breaker_budget'`), không bao giờ `no_coverage` giả; nếu `capped_to_budget` → giảm depth và báo operator.
1. `deepask/decompose` — câu hỏi → sub-needs MECE (≤6/≤12), gắn IA-type A/B/C/D.
2. `deepask/orchestrator` → mỗi sub-need gọi `resolver-plan` → `ResolverPlan v1`.
3. `deepask/execute` — subagent song song: **ĐỌC** `content_axis`; **CHẠY** `capability_axis` Tier-A + surface Tier-B+ + ủy quyền web→`deep-research`. Tự viết SQL read-only / câu `wiki_ask` / params, **grounded trong `grounding_ref`/`columns_hint`; không bao giờ bịa tên cột**.
4. `deepask/synthesize` — Pyramid + citation + authority + conflict + freshness + adversarial-verify → IR format-agnostic.
5. `deepask/completeness-critic` — coverage matrix + MECE + live-probe → COMPLETE | PARTIAL+remedy; ≤1 follow-up.
6. Format → **`inline` (mặc định):** render câu trả lời **vào hội thoại** (không file). **File mode (có `--format`):** artifact ở `.archives/deepask/<YYYY-MM-DD>-<slug>/`. **`--style`/`--art-style` (nếu có):** resolve một lần và truyền tokens/genre làm **design context** vào renderer của format — không thêm dispatch row.
   - **Nhánh image (`infographics` · `img-slide`):** `image-compose` biến IR + tokens `--style` (brand) **+ genre `--art-style`** thành `image-plan.json` (prompt gpt-image-2 mỗi mảnh = **brand STYLE block + GENRE block + một `focal_illustration` bắt buộc mỗi mảnh từ IR cited + `aesthetic` Part-3**). Orchestrator chạy cost gate → `image-gen.cjs` mỗi mảnh → PNG, và với `img-slide` `slide-deck.cjs` → `slides.pdf` (16:9 native). `answer.md` LUÔN được ghi kèm. **Honesty invariant:** không một con số/claim chịu-lực nào tồn tại CHỈ dưới dạng minh hoạ — mọi số vẫn là text đọc-được + cited; minh hoạ mang HÌNH DẠNG luận điểm, không bao giờ BẢN CHẤT.
7. **Observe** → `ops.deepask_runs` (1) + `ops.deepask_coverage` (N) — ghi ở CẢ hai mode (`artifact_path` = NULL khi inline).
