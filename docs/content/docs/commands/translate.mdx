## Độ trung thực theo định dạng (v0.1, trung thực)
- **Đầu vào** pdf · docx · pptx · webpage · md · txt — hỗ trợ đầy đủ (PDF dùng TOC → dự phòng theo font/heading).
- **Đầu ra** **pdf · epub · md** = kiểu chữ sách/tài liệu được trau chuốt (bìa, mục lục, trang mở chương,
  eyebrow phân mục theo phong cách clay, chú thích dạng số mũ). **docx** = tài liệu sạch, có định kiểu. **pptx** = bộ slide chức năng
  (tiêu đề + bullet cho mỗi mục). Kiểu chữ = Source Serif 4 + Inter đi kèm sẵn (đầy đủ tiếng Việt);
  `--style` cung cấp bản sắc màu sắc.

## Ví dụ
```
/translate report.pdf                              # → report.vi.pdf (Vietnamese, claude style)
/translate the-book.pdf --out=pdf+epub             # book → Vietnamese PDF + EPUB
/translate https://blog.example.com/post --to=ja   # webpage → Japanese PDF
/translate deck.pptx --out=pptx --to=en            # slides → English deck
/translate notes.md --out=pdf+docx --style=ritsu   # styled with the Ritsu palette
/translate big-book.pdf --dry-run                  # plan only: chapters + words + cost
```
