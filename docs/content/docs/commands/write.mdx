Cửa trước cho nền-tảng viết nội-dung phổ-quát. Phân-tích subcommand + flags, điều-khiển umbrella
skill `write` (`06-ai-ops/skills/write/SKILL.md`), rồi báo-cáo kết-quả.

## Cách dùng
```
/write "<yêu cầu>" [flags]                        # viết nội-dung (mặc-định)
/write distill <author-slug> --ref-src=<refs>     # chưng-cất giọng một tác-giả
/write authors | types | templates               # liệt-kê registry (chỉ-đọc)
/write humanize <text|file>                       # chỉ chạy lượt khử-mùi-AI + bơm-giọng
```

## Luồng (dispatch tới umbrella skill `write`)
1. Phân-tích flags (`params.cjs`) → subcommand + options.
2. **write**: `node scripts/write/plan.cjs …` → đọc `brief.md` → nạp giọng
   (`author-styles/<slug>/voice-card.md`) → outline → **draft theo giọng** → enrich (`/image`+`/dataviz`)
   → **cổng humanize** (`scripts/write/humanize/scan.cjs` đến khi pass) → `render.cjs` → tùy chọn `push.cjs`.
3. **distill**: `node scripts/write/distill/plan.cjs …` stage nguồn → Workflow fan-out theo hợp-đồng
   `_TEMPLATE` → ráp 6 file artifact → đăng-ký vào `author-styles.yaml`.
4. Báo-cáo `{ok, files[], type, medium, author_style, words, humanize{before→after,pass}, cost, warnings[]}` —
   luôn nêu cảnh-báo; hiển-thị nội-dung inline.

## Ví dụ
```
/write "Vì sao active recall thắng đọc-lại khi ôn thi" --type=blog --medium=substack --author-style=seth-godin --length=1200w --out=md+pdf
/write "Ritsu biến mọi PDF thành gia-sư" --type=ad --medium=facebook --author-style=david-ogilvy --image
/write "Thread ra-mắt tính-năng ôn-thi-trong-3-ngày" --type=thread --medium=x --author-style=seth-godin
/write "Báo-cáo retention Q3" --type=memo --template=decision-memo --dataviz --out=docx
/write distill paul-graham --ref-src=raw/write/paul-graham        # bắt một giọng mới
/write "bất-cứ-gì" --dry-run                                      # kế-hoạch + chi-phí, không nội-dung
/write humanize draft.md                                          # khử-mùi-AI một draft có sẵn
/write authors                                                    # liệt-kê các giọng đã chưng-cất
```

## Quản-trị

leo Tier C per `governance/HITL.md` (surface để duyệt, không bao giờ tự-gửi). Cost-bucket
`ai-ops-write` (gps `per_task_kind_caps`: write-orchestration $0.50 · write-draft $1.50 advisory ·
write-distill $2.00 · write-humanize $0.20 · write-research $1.00). Hợp-đồng runtime:
`06-ai-ops/sops/SOP-AIOPS-015-write-runtime-contract/flow.yaml`. Spec:
