> `node scripts/local-install/install.cjs --install-deps=supabase-cli --apply`
> (nó chạy việc cài bên trong). Mọi thứ khác (`pnpm`, `node`, `git`, `gh`,

## Luồng

### Bước 0 — Đảm bảo Node + pnpm (phần pre-Node duy nhất)
Engine là Node, nên Node phải có trước.
1. Chạy `node --version`. Nếu lỗi hoặc in ra `< v20`:
   - Dò package manager của nền tảng và cài Node LTS:
     - macOS: `brew install node` (hoặc hướng dẫn dùng nvm/fnm nếu thiếu brew)
     - Linux: `sudo apt-get install -y nodejs` / `sudo dnf install -y nodejs` / `sudo pacman -S --noconfirm nodejs npm` (nếu Node đóng gói \< 20, dùng nvm/fnm)
     - Windows: `winget install -e --id OpenJS.NodeJS.LTS` (hoặc choco/scoop)
   - Hoặc, chạy một lần preflight: `bash scripts/local-install/preflight.sh` (macOS/Linux) / `powershell -ExecutionPolicy Bypass -File scripts\local-install\preflight.ps1` (Windows).
2. Chạy `pnpm --version`. Nếu thiếu: `corepack enable pnpm && corepack prepare pnpm@latest --activate` (fallback `npm install -g pnpm@latest`).

### Bước 1 — Dò máy
Chạy `node scripts/local-install/doctor.cjs`. Nó báo nền tảng, từng dependency
(có/version/thiếu), trạng thái cài workspace, và tình trạng nối dây env. Hiển thị
báo cáo cho người dùng.

### Bước 2 — Cài system deps còn thiếu
Với mỗi dep **required** hoặc **recommended** mà doctor báo thiếu:
- Chạy lệnh cài theo nền tảng mà doctor in ra (để prompt mật khẩu `sudo` hiện ra
  cho người dùng nhập; không chặn prompt).
- Riêng **Supabase CLI** (recommended), chạy qua engine để khỏi đụng tường lửa:
  `node scripts/local-install/install.cjs --install-deps=supabase-cli --apply`
- Các dep **feature** (python/ffmpeg/bun) là tuỳ chọn — chỉ cài nếu người dùng
  muốn capability tương ứng (PDF / /voice / gbrain). Nhắc đến, đừng ép.

### Bước 3 — Chạy lõi tất định
Chạy `node scripts/local-install/install.cjs --apply` (thêm `--with-docs` nếu
người dùng truyền `--with-docs`). Nó stream tiến độ `[i/N]` cho:
1. ensure pnpm  2. cài root deps (frozen)  3. cài deps supabase-ops MCP
4. cài deps analytics MCP  5. scaffold `runtime/` + `.env.local`  6. husky
7. refresh resolver index.

Tường thuật tiến độ cho người dùng khi nó chạy. Nếu một workspace cài thất bại,
chạy lại `pnpm install` của workspace đó (engine đã tự fallback từ
`--frozen-lockfile` sang cài lỏng).

> Nếu có `--dry-run`, chạy `install.cjs` KHÔNG `--apply` trước để hiện kế hoạch;
> chỉ tiến tới `--apply` khi được xác nhận.

### Bước 4 — Hướng dẫn env
Scaffold đã tạo `runtime/secrets/.env.local` từ `.env.example` (hoặc giữ nguyên
nếu đã có). Báo người dùng, từng bước rõ ràng:
> **Sửa `runtime/secrets/.env.local`** và điền tối thiểu:
> - `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_KEY` (dự án ritsu-ops của bạn)
> - `MCP_CALLER_ROLE=founder` (hoặc `cofounder`) cho các phiên tương tác
> - Khoá LLM là tuỳ chọn (chế độ subscription-only chạy được mà không cần chúng)
>
> Xem `.env.example` cho danh sách chú thích đầy đủ + 3 chế độ truy cập.

### Bước 5 — Bàn giao
Báo người dùng rõ ràng:
> ✅ Cài đặt xong. Tiếp theo:
> 1. Điền `runtime/secrets/.env.local` (ở trên).
> 2. Chạy **`/test-ritsu-works`** — nó chạy bộ test hệ thống đầy đủ và báo cho bạn
>    khi ritsu-works đã được xác minh sẵn sàng.
