## Luồng (điều phối tới skill umbrella `image`)
1. Phân tích cờ (`params.cjs`); resolve `--use` dựa trên `knowledge/image-adapters.yaml`.
2. Nếu có `--enhance` → `image/enhance` (tinh chỉnh trong-phiên).
3. `--style`/`--art-style` truyền tới gen.cjs (bước prompt trong-phiên duy nhất là `--enhance` tùy chọn ở bước 2).
4. `node scripts/image/gen.cjs --prompt="<prompt>" --style=… --art-style=… [--ref=… --mask=…] …` → **gen.cjs soạn prompt một cách tất định**: khối BRAND (`--style` → token DESIGN.md qua `lib/compose.cjs`) + khối GENRE (`--art-style`), thứ tự ưu tiên brand > a11y > genre > art-direction > density; resolve kích thước (R2); ước tính chi phí (R3); thực thi `--max-cost-usd` TRƯỚC khi gọi; định tuyến tới endpoint **edits** khi có `--ref`; ghi PNG + `run.json` có kiểu + sidecar.
5. Báo cáo `{ok, files[], model, cost_usd, warnings[]}` — **luôn hiển thị cảnh báo**; khi `not_built|breaker_refusal|moderation_block|api_error`, đưa ra lý do có kiểu.
