The front door that turns **the name of any subject** (mental model · concept · idea · theory
· model · system · **algorithm** · framework · principle · phenomenon…) into **a book chapter
that leaves the reader spellbound**. Mental Models is the flagship library and the default
template, but `/mm` writes about *any entity* — it keeps the 13-movement *structure* and bends
the *content* to the kind of subject. Composes `/write` (voice + humanize + longform) +
`/dataviz` + `/image` for visuals + a Claude-styled renderer for EPUB/PDF. The brain lives in
the skill `06-ai-ops/skills/mm/SKILL.md` — read it, then execute.

## Usage
```
/mm "<Subject>"                   # write a deep chapter (default)
/mm template                      # print the 13-movement template (read-only)
/mm authors                       # print the voice blend + matching voices (read-only)
/mm rubric                        # print the quality rubric (read-only)
```

## Visual & chart types

`--visuals` (default `auto`) lets `/mm` embed three kinds of visual, each chosen for fit and
rendered on-brand (Claude Design System: clay/cream palette, Source Serif 4 + Inter):

**1. Hero diagram — hand-authored inline SVG (`::: svg`).** The primary visual and the one that
carries almost every chapter: a single crisp, on-brand schematic, authored to fit the model
exactly. Vector, zero-cost, prints sharp. Shipped examples: the AQAL 2×2 matrix, Indra's-Net node
web (Oneness), the linear-chain → condition-mesh (Cause & Effect), the two-level murmuration
emergence diagram, the variation → selection → retention cycle (Evolution).

**2. Data charts — embedded via `/dataviz` (60 types across 6 families).** When the subject is
genuinely data-bearing, `/mm` calls `/dataviz` (McKinsey-grade, pure-Node, byte-stable) and embeds
the result. The chart is picked the way an analyst picks it — by the message + data shape +
audience. The full vocabulary `/mm` can request:

| Family | Chart types |
|---|---|
| **Comparison** | bar · column · grouped · lollipop · dot · dumbbell · slope · radar · quadrant · bullet · small-multiples · range · matrix-chart · table-chart |
| **Correlation** | scatter · bubble · heatmap · connected-scatter · hexbin |
| **Part-to-whole** | stacked · stacked100 · pie · donut · marimekko · diverging · funnel · waffle · treemap · population-pyramid · sunburst · dendrogram · venn · semicircle-donut |
| **Change-over-time** | line · area · stacked-area · waterfall · bump · spline · step-line · gantt · candlestick · ohlc · barcode |
| **Distribution** | histogram · box · density · ridgeline · violin · strip · jitter · beeswarm · horizon |
| **Flow** | sankey · chord · arc · network · flowchart · tile-map (flowcharts via the `flow-graphviz` renderer) |
| **(single value)** | kpi tile |

**3. Raster images — via `/image`** for the rare case a generated illustration beats a schematic
(cover art, a concrete scene). Out-of-band (`OPENAI_API_KEY`), each call under the `--max-cost-usd`
breaker.

In practice the hero SVG diagram carries nearly every chapter (crisp, on-brand, free); `/dataviz`
charts appear only when the subject genuinely has data; `/image` is rare.

## Flow (dispatch to the `mm` skill)
1. Parse flags → slugify the subject name → create `.archives/Mental Models/<slug>/{,artifacts/}` (root repo).
2. **Bible:** build the source-of-truth for the subject — facts (grounded via `--research`/`--grounding`)
   + locked Vietnamese terminology + the voice blend + a per-movement brief following the **13-movement**
   template (including Upthink). **Lock the bible.**
3. **Draft:** blind-parallel longform (one agent per movement) via a Claude Code Workflow, bound to the
   bible, Vietnamese, on-voice + visual boxes + word budgets.
4. **Synthesize + Visualize:** assemble in order → smooth the seams + master-editor pass (em-dash
   discipline) → **humanize gate** until it passes → build the **hero `::: svg` diagram** (§3) +
   `/dataviz` charts + `/image` rasters where they earn it → write the front matter (frontmatter +
   epigraph + one-page map) and back matter (fieldcard + glossary + sources).
5. **Render:** `scripts/mm/render.py <slug>.md --out=epub+pdf --style=claude --out-dir=<dir> --name=<slug>`
   (run via anaconda python + `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib`).
6. **Report:** files[], word count, humanize before→after, cost, warnings[]. Keep bible/research/drafts
   in `<slug>/artifacts/`.

> For top-tier output, run an adversarial **5-judge review → revise → re-verify** pass on the
> assembled chapter (prose/voice · intellectual-honesty · pedagogy · source-fidelity · hard skeptic),
> then fix the critical/high findings before render. This is how the shipped Mental Models chapters
> reached ~9.3/10.
