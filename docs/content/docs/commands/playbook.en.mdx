## Workflow

### `/playbook build`

1. **Drift gate** — run validator. WARN → AskUserQuestion (proceed/abort). FAIL → abort.
2. **Change detection** — compare chapter mtimes vs latest published PDF mtime. If no changes AND no `--force` AND no `--add-chapter` → exit with "no changes, skipping" (≠ error).
3. **Auto bump** — semver patch/minor/major (see skill spec). If MAJOR detected → AskUserQuestion Tier B.
4. **Add chapter** (if `--add-chapter`) — verify file exists at path; skip if not provided.
5. **Sync meta** — invoke `playbook-builder/sync-meta` skill: rewrite 4 fields in 00-toc.md + 3 fields in build_pdf.py.
6. **Build** — `bash scripts/playbook/build.sh` (env preset + build_pdf.py).
7. **Publish** — `cp build/playbook-vX.Y.pdf .archives/ritsu-handoff-bundle/playbook/`.
8. **Persist** — INSERT `ops.agent_runs`; emit `ritsu.playbook.built` event.
9. **Output** — strict JSON to stdout (version_built, pdf_path, pdf_size_bytes, wall_clock_s, changes_detected).

### `/playbook check`

1. Run `node scripts/cross-tier/validate-playbook-coherence.cjs`.
2. Report 5 invariants:
   - Every chapter file in CHAPTER_ORDER
   - Every CHAPTER_ORDER entry has a file
   - TOC version == build_pdf.py pdf_path version
   - TOC version == build_pdf.py cover-meta version
   - TOC date ≥ youngest chapter file mtime
3. Exit 0 if clean, exit 1 if any FAIL (warn-tier doesn't block).

`--fix` flag also invokes `playbook-builder/sync-meta` to repair detected drift.
