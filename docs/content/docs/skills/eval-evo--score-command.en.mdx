## Process

Same as `score-skill/SKILL.md` §Process. The differences:

## Cost

~$0.10 per invocation. 2 invocations/iter × N iters per /evolve run.

- Single-judge mode (no 3-judge median).
- Golden cases run as part of judge prompt (text-level pass/fail).
- @ceo resolution: v1.0 routes to `general-purpose` subagent with @ceo
  system prompt. v1.1 may use native subagent_type=ceo.
