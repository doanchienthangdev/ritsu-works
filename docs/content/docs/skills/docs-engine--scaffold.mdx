# docs-engine/scaffold

## Khi nào dùng

- Cấu hình site docs lần đầu tiên, HOẶC xây dựng lại đầy đủ sau khi `/cla deprecate docs-engine` được đảo ngược.
- Gọi bằng lệnh `/docs scaffold`.

## Inputs

- (Không có — chỉ đọc trạng thái hiện tại của repo để phát hiện đã scaffold hay chưa.)

## Process

1. Xác minh `docs/` không tồn tại (hoặc trống). Nếu tồn tại với nội dung → hủy với "Already scaffolded; use `/docs sync` instead".
2. Chạy `npx create-fumadocs-app docs/ --template next-mdx --lang vi` (hoặc template tương đương).
3. Viết `docs/source.config.ts` với các nguồn nội dung tùy chỉnh (9 adapter được kết nối).
4. Viết `docs/lint-secrets.cjs` (trình redactor fail-loud 3 lớp; CTO mod #2).
5. Viết `docs/app/api/raw/[...slug]/route.ts` (endpoint raw-MDX cho AI runtime).
6. Viết `docs/.vercelignore` để bỏ qua các thư mục không cần thiết.
7. Lần sync đầu tiên: dispatch tới `docs-engine/sync --area=all` tự động.
8. Emit sự kiện `ritsu.docs.built`.

## Outputs

- Thư mục `docs/` đã scaffold đầy đủ.
- Hàng `ops.events` sự kiện `ritsu.docs.built`.

## HITL

Tier A.

## Failure modes

- `npx create-fumadocs-app` thất bại → hiển thị lỗi; hủy bỏ. Đừng để lại scaffold không hoàn chỉnh.
- Vercel template không bao gồm cấu hình i18n → vá `next.config.ts` thủ công với `defaultLanguage: 'vi'`.
