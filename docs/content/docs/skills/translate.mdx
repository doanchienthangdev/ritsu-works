Bộ điều phối runtime. Ba pha: **plan → translate (Workflow) → build**. Phần việc
cơ học mang tính tất định bằng Python/Node (`scripts/translate/`); phần *dịch thuật*
là một đợt fan-out các agent LLM được dẫn dắt bởi một bản brief chung. Kết quả đầu ra nằm ngay cạnh nguồn.

> **Quyền dịch thuật:** một lần gọi /translate khẳng định rằng người gọi nắm giữ quyền
> dịch nguồn. Hãy xử lý tài liệu; ghi kết quả đầu ra để người gọi tự sử dụng.

## Pha 1 — Plan

Chạy bộ lập kế hoạch (nó nạp nguồn, phát hiện book/doc/slides, tách thành các unit,
ghi `brief.md` + `plan.json` vào một thư mục làm việc runtime):

```
node scripts/translate/cli.cjs plan "<src>" [--to=… --out=pdf+epub --style=claude --mode=auto --split=auto --max-cost-usd=8 --dry-run …]
```

Đọc kết quả JSON: `{workdir, brief, mode, title, units, total_words, cost_estimate_usd, outputs, to, tasks[], warnings[]}`.
- **Hiển thị mọi cảnh báo.**
- **`--dry-run`** (hoặc `dry_run:true`): trình bày kế hoạch (mode, số unit, số từ, chi phí, outputs) rồi DỪNG. Không dịch.
- **Cổng chi phí:** nếu `cost_estimate_usd` > giá trị `--max-cost-usd` đã giải quyết, hãy hiển thị ước tính và DỪNG để xác nhận (không âm thầm chi tiêu).

## Pha 2 — Dịch tiêu đề, sau đó fan out các unit

**2a. Tiêu đề.** Tự dịch tiêu đề của sách/tài liệu (`plan.title`) sang ngôn ngữ đích
(một dòng) — giữ nguyên danh từ riêng. Giữ nó dưới dạng `TITLE_TRANSLATED` cho bước build.

**2b. Khởi chạy Workflow dịch thuật.** Dùng công cụ Workflow. Nhúng danh sách tác vụ dưới dạng
một `const` trong thân script — **KHÔNG truyền nó qua `args`** (`args` lớn sẽ đến dưới dạng chuỗi
và `.map` sẽ ném lỗi). Mỗi agent xử lý một unit; mỗi agent đọc bản brief chung + unit nguồn của nó và
ghi unit đã dịch của nó. Mẫu:

```js
export const meta = { name: 'translate-<slug>', description: 'Parallel translation of <title> into <lang>', phases: [{ title: 'Translate' }] }
const BRIEF = "<plan.brief abs path>"
const TASKS = [ /* plan.tasks: {id, title, is_first, src, out} — embed literally */ ]
const SCHEMA = { type:'object', additionalProperties:false, required:['id','ok','words'],
  properties:{ id:{type:'string'}, ok:{type:'boolean'}, words:{type:'integer'}, note:{type:'string'} } }
phase('Translate')
const results = await parallel(TASKS.map(t => () =>
  agent(
`You are a world-class literary translator into <LANGUAGE>.
STEP 1 — Read the brief (follow it EXACTLY): ${BRIEF}
STEP 2 — Read the source unit: ${t.src}
STEP 3 — Translate the ENTIRE unit into <LANGUAGE> at the highest literary standard
  (faithful + natural). ${t.is_first ? 'This is the FIRST part — begin with the H1 line "# '+t.title+'" (translate the title), blank line, then body.' : 'This is a CONTINUATION part of "'+t.title+'" — do NOT repeat the title; begin with the first translated section/paragraph.'}
  Preserve every "## "/"### " heading (translated), "> " blockquote (translated),
  **bold**, lists, tables, and every <sup>N</sup> marker VERBATIM. Keep proper nouns.
STEP 4 — Write ONLY the translated markdown (no preamble/fences) to: ${t.out}
STEP 5 — return {"id":"${t.id}","ok":true,"words":<count>}.`,
    { label:`tr:${t.id}`, schema: SCHEMA }
  ).catch(e => ({ id:t.id, ok:false, words:0, note:String(e).slice(0,200) }))
))
return { ok: results.filter(r=>r&&r.ok).length, total: TASKS.length, failed: results.filter(r=>!r||!r.ok) }
```

- Các agent kế thừa model của phiên (dùng model mạnh nhất hiện có — chất lượng dịch thuật chính là cốt lõi).
- Mức đồng thời tự giới hạn (~8–16); sách lớn chạy theo từng đợt. Workflow chỉ trả về một manifest nhỏ (các bản dịch được ghi ra file, không bao giờ dồn ngược lại qua context).
- **Chạy lại bất kỳ unit nào bị lỗi** (file `out` của nó bị thiếu/rỗng) trước khi build.

## Pha 3 — Build

```
node scripts/translate/cli.cjs build <workdir> --title="<TITLE_TRANSLATED>" [--subtitle="…"]
```
Bước này lắp ráp các unit đã dịch (nối các nửa đã tách) và kết xuất mọi định dạng đầu ra
được yêu cầu với design system đã giải quyết. Đọc kết quả `{ok, outputs[], outDir}`.

## Pha 4 — Báo cáo

Báo cáo các file đã tạo (đường dẫn tuyệt đối), ngôn ngữ đích + style, mọi cảnh báo, và —
một cách trung thực — các ghi chú về độ trung thực từ ma trận của lệnh (pdf/epub/md được trau chuốt; docx sạch sẽ;
pptx dùng được). Kết quả đầu ra nằm trong thư mục của nguồn trừ khi `--out-dir` được cung cấp.

## v0.2 (STEM) — assets · math · format-preserving · LaTeX

Luồng plan → translate → build không thay đổi; `cli.cjs` định tuyến hành vi v0.2 trong nội bộ,
nên Workflow bạn khởi chạy là giống hệt. Điều đã thay đổi:
- **Hình/biểu đồ/bảng (Req 1):** `plan` trích xuất chúng vào `<workdir>/assets/` và chèn
  các tham chiếu `![alt](assets/…)` (`--no-assets` để bỏ qua). Bản brief yêu cầu các agent **giữ nguyên `(path)`
  chính xác và chỉ dịch alt text**. Các renderer nhúng chúng (latex `\includegraphics`, pdf
  base_url, epub items, md copy).
- **Math (Req 2):** bản brief giữ nguyên `$…$`/`\[…\]`/các environment **y nguyên**. `--out=latex` /
  `pdf-latex` sắp chữ chúng một cách tự nhiên. Hãy nói với người dùng: với math sắp chữ, hãy dùng các đầu ra LaTeX.
- **`--preserve` (Req 3):** với **docx/pptx**, `cli.cjs plan` chạy `preserve.py plan` (trích xuất
  các **segment** văn bản theo thứ tự thành các dòng `⟦S{n}⟧` thay vì markdown), Workflow dịch các
  segment đó (bản brief yêu cầu giữ nguyên mọi marker `⟦S{n}⟧` chính xác, mỗi dòng một marker, cùng thứ tự), và
  `build` chèn lại chúng vào một bản sao của bản gốc → **bố cục giống hệt**. Đầu ra = chỉ định dạng nguồn
  thôi. PDF `--preserve` quay về reflow (v0.2).
- **LaTeX (Req 4):** `--out=latex` (`.tex`, XeLaTeX, Source Serif 4) + `--out=pdf-latex` (biên dịch
  bằng **tectonic**, phải có trên PATH). Tốt nhất cho giáo trình STEM / AI-ML / báo cáo khoa học; `.tex` có tính di động
  (fonts + assets được dàn cạnh nó).

## Ghi chú
- **Hosts:** bộ lập kế hoạch/các renderer tự động chọn Python phù hợp (PDF → WeasyPrint host;
  epub/docx/pptx/md → anaconda). Fonts (Source Serif 4 + Inter, đầy đủ tiếng Việt) được tải về +
  tạo instance một lần vào `runtime/translate/fonts/` (gitignored).
- **Phát hiện cấu trúc** mang tính tổng quát (TOC → cỡ font → dự phòng theo heading cho PDF; các style
  đoạn văn cho docx; slides cho pptx; thẻ ngữ nghĩa cho HTML). Nó suy giảm một cách nhẹ nhàng.
- **Chuẩn chất lượng:** bản brief thực thi văn xuôi trung thực-nhưng-tự-nhiên, thuật ngữ nhất quán,
  cấu trúc được giữ nguyên + chỉ số trên cho trích dẫn — sự kỷ luật của một dịch giả nhà xuất bản hàng đầu.
- Skill này là nơi *duy nhất* khởi chạy Workflow dịch thuật; `cli.cjs` không bao giờ làm điều đó.
