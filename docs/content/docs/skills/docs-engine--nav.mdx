# docs-engine/nav

## Khi nào dùng

- Lệnh `/docs nav` (điều chỉnh sidebar thủ công).
- Gọi tự động ở cuối `/docs scaffold` để viết meta.json ban đầu.

## Inputs

- `action` — `init` | `reorder <area> <key1,key2,...>` | `group <area> <group-name> <pages>` | `hide <page>` | `unhide <page>`.

## Process

1. Đọc `docs/content/meta.json`.
2. Áp dụng action.
3. Viết lại. Xác thực so với schema meta.json của Fumadocs.
4. Hiển thị diff cho founder nếu tương tác.

## Outputs

- Cập nhật `docs/content/meta.json`.
