# YouTube adapter (baseline Sprint 2 PR4 — v2.0.0)

## Khi nào adapter này chạy

Được điều phối bởi `wiki-sync/ingest` Bước 1 khi `<path>` khớp với:
- `youtube.com/watch?v=*`
- `youtu.be/*`
- `youtube.com/shorts/*`
- `youtube.com/embed/*`

source_kind: `youtube_video`
entity_type: `episode`
wiki target: `wiki/<slug>/source.md` (layout source-grouped v4.0; các thực thể dẫn xuất được đặt dưới `wiki/<slug>/concepts/`, `wiki/<slug>/observations/`, v.v.)

## Inputs

- `path` — URL YouTube (bất kỳ dạng nào trong các dạng được hỗ trợ ở trên)
- `force` — bool; được truyền xuống

## Phụ thuộc bên ngoài

- **yt-dlp** — `pip install yt-dlp` HOẶC qua brew `brew install yt-dlp`. Phải có trong PATH.
- **ffmpeg** — bắt buộc bởi yt-dlp để trích xuất audio khi whisper fallback chạy. `brew install ffmpeg`.
- **OPENAI_API_KEY** — chỉ bắt buộc nếu whisper fallback chạy (auto-captions vắng mặt VÀ cờ `wiki_sync_llm_fallback` được bật).

Adapter fail fast với hướng dẫn cài đặt rõ ràng nếu phát hiện dep thiếu.

## Quy trình

### Bước 1 — Chuẩn hóa URL + trích xuất video_id

Khớp URL với 4 dạng được hỗ trợ; trích xuất `video_id` (chuỗi base64-ish 11 ký tự). Từ chối URL playlist (`playlist?list=...`) với giải pháp: "ingest từng video một, hoặc gộp vào pattern folder-adapter v2.1+".

### Bước 2 — Lấy metadata qua yt-dlp

```bash
yt-dlp --no-download --print-json --no-playlist "<url>" 2>/dev/null
```

Capture:
- `id` — video_id
- `title` — để dẫn xuất slug + title trang wiki
- `uploader` / `uploader_id` — attribution
- `upload_date` — định dạng YYYYMMDD
- `duration` — giây (để ước tính chi phí)
- `chapters` — mảng `{start_time, end_time, title}` (nếu có trong description)
- `description` — description đầy đủ của video (được parse cho ref bổ sung)

Các chế độ thất bại:
- yt-dlp không có trong PATH → dừng lại với hướng dẫn cài đặt
- Video riêng tư / giới hạn tuổi / đã bị xóa → dừng lại với lỗi rõ ràng
- Bị chặn khu vực → dừng lại; gợi ý VPN hoặc nguồn thay thế

### Bước 3 — Lấy transcript

Thử auto-captions trước (miễn phí, ~tức thì):
```bash
yt-dlp --write-auto-subs --skip-download --sub-format vtt --sub-langs en \
       --no-warnings -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

Nếu `en.vtt` tồn tại → parse nó (Bước 4).
Nếu không, thử manual sub (đôi khi uploader cung cấp):
```bash
yt-dlp --write-subs --skip-download --sub-format vtt --sub-langs en,vi \
       --no-warnings -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

Nếu vẫn không có transcript VÀ feature flag `wiki_sync_llm_fallback` được bật VÀ `OPENAI_API_KEY` có mặt → whisper fallback (Bước 3b). Nếu không thì dừng lại:
```
No transcript available for video <id>. Auto-captions not generated by YouTube.
Workaround:
  1. Enable wiki_sync_llm_fallback in knowledge/feature-flags.yaml
  2. Set OPENAI_API_KEY in env
  3. Re-run /wiki sync (will whisper-transcribe; cost ~$0.006/min audio)
```

### Bước 3b — Whisper fallback (feature-flagged, tắt mặc định)

```bash
yt-dlp -x --audio-format mp3 -o "/tmp/yt-%(id)s.%(ext)s" "<url>"
```

Sau đó gọi OpenAI Whisper API trên `/tmp/yt-<id>.mp3`. Chi phí: `$0.006 × ceil(duration_min)`. Track trong `ops.cost_attributions` với `model='whisper-1'`.

Transcript kết quả: text thuần không có timestamp (giới hạn của Whisper API ở chế độ chuẩn; dùng `response_format=verbose_json` để có timestamp ở mức từ nếu cần để căn chỉnh chapter).

### Bước 4 — Parse VTT thành transcript có cấu trúc

Format VTT (auto-caption YouTube điển hình):
```
WEBVTT

00:00:01.500 --> 00:00:04.000
intro music plays

00:00:04.500 --> 00:00:08.000
welcome back to the channel today we
```

Output parser: mảng các cue `{ start_ms, end_ms, text }`. Loại bỏ các cue trùng lặp (auto-caption YouTube thường lặp lại để tạo hiệu ứng cuộn trực quan).

### Bước 5 — Căn chỉnh với chapter YouTube

Nếu mảng `metadata.chapters` không rỗng, phân vùng mảng cue thành các bucket chapter (`start_ms` của cue nằm trong `[chapter.start, chapter.end)`).

Nếu không có native chapter VÀ duration > 10 phút, tự động phát hiện chapter từ khoảng trống cue VTT (gap > 5 giây im lặng thường = ngắt section). Output 3-10 chapter tối đa.

### Bước 6 — Compose raw_text

```
# <video_title>

**Uploader:** <uploader>
**Date:** <YYYY-MM-DD>
**Duration:** <H:MM:SS>
**URL:** <canonical url>

language: vi
translated: true
translated_at: 2026-05-19T13:00:00Z
translated_by: "Claude Opus 4.7 (Claude Code Desktop, session translation)"
---

## Chapter 1: <chapter_title>  [00:00 - 03:45]

<cue 1 text>
<cue 2 text>
...

## Chapter 2: <chapter_title>  [03:45 - 08:12]

...
```

raw_text có cấu trúc bảo toàn ranh giới chapter cho chunking downstream (theo `ingestion-sources.yaml` `chunking: structural_per_yt_chapter_else_token_1024`).

### Bước 7 — Tạo slug

- Slug base: `kebab-case(metadata.title)`
- Giới hạn ở 60 ký tự
- Thêm disambiguator: `<slug-base>-<video_id-first-6>` để xử lý đụng độ title giữa các video
- Ví dụ: `make-it-stick-talk-by-roediger-a1b2c3`

### Bước 8 — Tính source_hash

`source_hash = sha256(video_id + transcript_text)`. video_id đảm bảo các video khác nhau có transcript giống hệt (khó xảy ra nhưng có thể) sẽ có hash khác nhau. Hash nội dung transcript có nghĩa là chạy lại trên cùng video SAU KHI YouTube tái tạo caption sẽ xác định đúng nội dung mới.

## HITL

- Tier A bình thường
- Tier B nếu:

  - description chứa URL spam hoặc affiliate link đáng ngờ (trích xuất cẩn thận)

## Tích hợp Chapter-split (v2.0)

Cho video > 100 cue HOẶC cờ `--split`:
- Adapter này trả về output chuẩn (raw_text với section có heading chapter, `pages_or_size_metric=duration_seconds`).
- `wiki-sync/ingest` Bước 5 điều phối `wiki-sync/chapter-splitter` ở chế độ `toc` (dùng native chapter của YouTube từ `chapters_detected` của adapter này).
- Nếu native chapter vắng mặt, splitter fallback sang `count=N` (N được dẫn xuất từ duration; ~10 phút mỗi chapter).
- Mỗi chapter trở thành row `ingestion_jobs` riêng với `parent_job_id` (migration 00030 Block C).
