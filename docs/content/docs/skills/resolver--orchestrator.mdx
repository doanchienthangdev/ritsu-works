## Khi nào dùng

Được invoke bởi `.claude/commands/resolver.md` như top-level dispatcher. Route
tới verb sub-skill phù hợp dựa trên argv đã parse.

## Process

1. Parse argv: positional đầu tiên là subcommand; còn lại là positional args + flags
2. Validate subcommand theo enum: `query | list | validate | sync | explain`
3. Dispatch tới sub-skill tương ứng:
   - `query` → `resolver/query`
   - `list` → render qua load-index trực tiếp (không có sub-skill riêng)
   - `validate` → spawn `scripts/cross-tier/validate-resolver-*.cjs`
   - `sync` → `resolver/sync`
   - `explain` → `resolver/explain`
4. Capture output của sub-skill; render theo flag `--json`

## Error handling

- Unknown subcommand → in usage + danh sách valid, exit 1
- Thiếu positional bắt buộc → in usage cho verb đó
- Mọi lỗi của sub-skill propagated lên caller
