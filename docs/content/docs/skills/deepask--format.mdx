## Quá trình

### 1. Resolve target format / mode

- **Không `--format` (DEFAULT) → `inline` mode:** render câu trả lời được trích dẫn **vào cuộc trò chuyện**; viết **KHÔNG file nào**. Bỏ qua `format-select` và artifact dir hoàn toàn — đi đến inline dispatch row trong §2. Đây là con đường phổ biến cho câu hỏi nhanh (bạn hỏi, bạn đọc câu trả lời trong chat).
- Explicit `--format=<x>` → **file mode**; dùng `<x>` trực tiếp.
- Explicit `--format=smartauto` → **file mode**; `scripts/deepask/format-select.cjs` `selectFormat({intent})` (classify `intent` từ câu hỏi + IR). Kể từ **Sprint 5 default `available` set là `ALL_FORMATS`** — mỗi adapter được built. Trả về `{format, reason, fellBack}`; record `reason` trong `plan.json`.

### 3. Artifact layout (FILE MODE ONLY — bỏ qua hoàn toàn trong `inline` default)

**Inline mode (default) viết không gì vào disk** — câu trả lời được trích dẫn + Sources list sống trong cuộc trò chuyện; chỉ Stage-7 `ops.deepask_runs`/`ops.deepask_coverage` audit rows được viết (DB rows, không phải file), với `artifact_path = NULL`. Trong **file mode** (bất kỳ `--format` rõ ràng nào), viết vào `.archives/deepask/<YYYY-MM-DD>-<slug>/`:
- **`answer.md`** — cited article canonical (LUÔN trong file mode, bất kể `--format` nào).
- **`plan.json`** — decomposition + ResolverPlans + coverage matrix + smartauto `reason`.
- **`sources.json`** — citation ledger (mỗi `source-ref` với recipient_id, axis, authority, freshness, retrieved_at).
- **`<artifact>.<ext>`** — rendered `--format` output (khi không `text`/`article`).

### 4. Graceful degradation

Nếu reuse-skill không có sẵn trong session (ví dụ, `anthropic-skills:pdf` absent, hoặc Mac-local WeasyPrint missing), KHÔNG fail run: viết `answer.md` + note trong `plan.json` (`format_degraded: {requested, reason, delivered: 'article'}`) và báo cho operator "rendered như Markdown; \<format> adapter không có sẵn session này." Canonical answer không bao giờ bị mất.

## Constraints

- **Reuse chỉ** — không bespoke rendering engine. New format = new dispatch row + reuse pointer (+ add nó vào `format-select` availability khi được built).
- **Mode contract:** không `--format` → `inline` (conversational answer, **zero file**); bất kỳ `--format` rõ ràng nào → file mode nơi `answer.md` luôn được viết (câu trả lời durable, portable). Inline là default vì hầu hết câu hỏi muốn câu trả lời nhanh, không artifact.
- Không new content/claims ở render time — Format Engine chỉ *re-presents* IR (đã pass `citation-audit`); nó không bao giờ add uncited claim.
