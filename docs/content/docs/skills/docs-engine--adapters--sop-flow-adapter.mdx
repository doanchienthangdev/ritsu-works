# docs-engine/adapters/sop-flow-adapter

## Input pattern

`0[0-9]-*/sops/SOP-*/flow.yaml` + `README.md` liền kề (nếu có)

## Output pattern

`docs/content/sops/<pillar-slug>/<sop-id>.mdx`
ví dụ: `docs/content/sops/06-ai-ops/SOP-AIOPS-001-capability-lifecycle.mdx`

## Process

1. Parse `flow.yaml` (toàn YAML, không có markdown).
2. Trích xuất `id`, `title`, `description`, `pillar`, `cost_bucket`, `trigger`, `steps`, `acceptance_criteria`, `failure_handling`, `integrates_with`, `audit`.
3. Tính `source_hash` của tệp yaml.
4. Hiển thị MDX với các phần:
   - **Overview** (prose description)
   - **Trigger** (kinds + authorized_roles + hitl_tier)
   - **Inputs** (yaml table)
   - **Steps** — Fumadocs `<Steps>` component, mỗi step hiển thị dưới dạng collapsible với `name`, `kind`, `skill`, `timeout`, `on_failure`, `outputs`
   - **Acceptance criteria** (checklist)
   - **Failure modes** (table)
   - **Cross-Bài-toán integration** (table)
   - **Audit** (one-liner)
5. Thêm Fumadocs frontmatter:
   - `title: <sop-id>: <title>`
   - `description: <description>`
   - `pillar: <pillar-slug>`
   - `cost_bucket: <bucket>`
   - `status: <derived from pillar.stage_status>` (deep / lite / skeleton)
6. Thêm marker idempotency.

## Edge cases

- SOP yaml có thể có multi-line strings (`|` literal blocks) — giữ nguyên định dạng.
- Một số SOP tham chiếu SOP khác trong `integrates_with` — hiển thị dưới dạng Fumadocs internal links.
- `README.md` liền kề (nếu có) → thêm vào phía trước dưới dạng phần "Operator Notes" trước spec có cấu trúc.
