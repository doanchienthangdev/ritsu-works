# docs-engine/adapters/pillar-readme-adapter

## Input patterns

- `0[0-9]-*/README.md` (tổng quan pillar cấp cao)
- `0[0-9]-*/CLAUDE.md` (hướng dẫn Claude có phạm vi đường dẫn; per root file CLAUDE.md)
- `0[0-9]-*/<sub-pillar>/README.md` (tổng quan sub-pillar)
- `0[0-9]-*/<sub-pillar>/CLAUDE.md` (hướng dẫn Claude sub-pillar)
- `10-*/README.md` + `10-*/<sub-pillar>/README.md` (10-metrics)

## Output pattern

`docs/content/pillars/<pillar-slug>/index.mdx` cho pillar README.
`docs/content/pillars/<pillar-slug>/<sub-pillar>/index.mdx` cho sub-pillar README.
`docs/content/pillars/<pillar-slug>/_claude.mdx` cho pillar CLAUDE.md (lưu ý: `_claude` để phân biệt với index).
`docs/content/pillars/<pillar-slug>/<sub-pillar>/_claude.mdx` tương tự.

## Process

1. Duyệt recursive (BFS-bounded; depth ≤ 3, tương tự wiki-sync/folder-adapter v4.1).
2. Title từ H1 đầu tiên; fallback thành "Pillar: \<slug>" hoặc "Sub-pillar: \<slug>".
3. Tính `source_hash`.
4. Hiển thị MDX. Thêm frontmatter metadata pillar từ `knowledge/manifest.yaml`:
   - `layer: evergreen | stage`
   - `stage_status: deep | lite | skeleton | maintenance`
   - `pillar_code: PILLAR | GTM | etc.`
5. Thêm marker idempotency.

## Edge cases

- Một số pillar không có CLAUDE.md (skeleton pillars) — bỏ qua yên tĩnh.
- Sub-pillar không có README → không tạo trang rỗng; chỉ ghi chú trong adapter_errors.
- Tham chiếu chéo tới README của các pillar khác → giữ nguyên dưới dạng relative links (Fumadocs xử lý).

## HITL / Cost

Tier A. ~$0.05-0.10 tổng cộng (BFS qua ~20-30 tệp).
