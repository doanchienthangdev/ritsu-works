# docs-engine/adapters/tier1-yaml-adapter

## Input pattern

`knowledge/*.yaml` (KHÔNG `knowledge/schemas/**`, KHÔNG `knowledge/phase-a2-extensions/**`)

## Output pattern

`docs/content/knowledge/<yaml-name>.mdx`
ví dụ: `docs/content/knowledge/manifest.mdx`, `docs/content/knowledge/capability-registry.mdx`

## Process

1. Parse YAML. Bắt các ghi chú top-of-file (mọi thứ trước dòng không comment đầu tiên) dưới dạng prose intro.
2. Tính `source_hash` của tệp yaml.
3. Hiển thị MDX với các phần:
   - **Description** (top-of-file comments)
   - **Schema** (từ `knowledge/schemas/<yaml-name>.schema.json` nếu tồn tại — hiển thị dưới dạng auto-doc)
   - **Current state** (tên khoá + số hàng mẫu; KHÔNG full content dump — link tới git cho live values)
4. Thêm `<Callout>: "Live values in knowledge/<yaml-name>.yaml — this page describes the schema, not the data."`
5. Thêm marker idempotency.

## Edge cases

- `manifest.yaml` rất lớn (~600+ dòng) — hiển thị chỉ cấu trúc (top-level keys + 1-line summary mỗi cái), không full content.
- `capability-registry.yaml` — hiển thị schema + đếm capabilities theo state.
- `kpi-registry.yaml` — liệt kê tất cả KPI ids; mỗi cái trở thành mục Fumadocs `<Cards>`.
- `cla-routing-keywords.yaml` — hiển thị route → CxO map dưới dạng Fumadocs `<Tabs>` mỗi domain.
- yamls có ghi chú placeholder `{{ADD_X_HERE}}` — bỏ qua các phần đó.
