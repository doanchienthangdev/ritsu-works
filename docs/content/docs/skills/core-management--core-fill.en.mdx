## When to use

Invoked by `/core fill <doc-slug>` to graduate a doc:
- **stub-to-draft**: `status: stub` → `status: v0.1-draft` (fills body sections per layer schema; clears `entry_condition` + `triggered_by` + `why_deferred`; adds `revisit_at` + `revisit_trigger`)
- **draft-to-canonical**: `status: v0.1-draft` → `status: canonical` (founder confirms hypothesis tested + observed customer data merged; clears `revisit_at`)

Canonical docs cannot be re-filled via this skill — edit directly + bump `last_reviewed` instead.

- `target_doc`: path under `00-core/` (e.g., `00-core/wedge.md`)
- `mode`: `stub-to-draft` | `draft-to-canonical` (inferred from current status)

## Process

### Step 1 — Read target doc

```javascript
const { parse } = require('scripts/core/lib/frontmatter.cjs');
const content = fs.readFileSync(target_doc, 'utf-8');
const { frontmatter, body } = parse(content);
```

Determine current status, layer, and section list:
- `current_status = frontmatter.status` (must be `stub` or `v0.1-draft`)
- `target_status` = `stub` → `v0.1-draft`, `v0.1-draft` → `canonical`
- `layer = frontmatter.layer`
- `sections = SECTION_SCHEMAS[layer][slug]` per table above

If status is `canonical` or `deprecated` → ABORT with friendly error.

### Step 2 — Detect existing fills

If `body` already contains `## <Section Name>` headers matching some sections, mark those as "previously filled — confirm or skip"; mark missing sections as "needs new fill".

### Step 3 — Iterate sections via AskUserQuestion

For each section in order:

```javascript
AskUserQuestion({
  question: `[${doc_slug} §${section_index}] ${section_human_name} —
    write the content for this section. Plain English:
    ${section_prompt}. RECOMMENDATION: ${section_recommendation_or_skip}.`,
  header: section_short_name,
  multiSelect: false,
  options: [
    { label: 'Write content (next message)', description: '...' },
    { label: 'Skip — leave as TODO', description: '...' },
    { label: 'Use my draft (paste in next message)', description: '...' },
  ]
});
```

If founder chooses "Write content", wait for next user message (the content). If "Skip", insert `> TODO: revisit at next fill session.`. If "Use draft", treat next message as content.

**Batch up to 4 questions per AskUserQuestion call** (Anthropic limit).

### Step 4 — Compose new body

Assemble body from section answers:

```markdown
# {title}

> {1-line description from frontmatter}

{founder's transparency note if v0.1-draft, e.g., "v0.1-draft — first fill; revisit at 30-paying"}

## 1. {Section 1 name}

{Section 1 content}

## 2. {Section 2 name}

{Section 2 content}

...
```

### Step 5 — Update frontmatter

For `stub → v0.1-draft`:
```yaml
status: v0.1-draft  # was: stub
last_reviewed: <today>
revisit_at: 30-paying  # default; founder may override
revisit_trigger: "first 30-paying milestone + first NPS survey"
revisit_owner: founder
# Remove: entry_condition, triggered_by, why_deferred
```

For `v0.1-draft → canonical`:
```yaml
status: canonical  # was: v0.1-draft
last_reviewed: <today>
# Remove: revisit_at, revisit_trigger, revisit_owner
```

### Step 6 — Write file atomically

Use `scripts/core/lib/frontmatter.cjs`:
```javascript
const { serialize } = require('scripts/core/lib/frontmatter.cjs');
const newContent = serialize(updated_frontmatter, new_body);
fs.writeFileSync(target_doc, newContent, 'utf-8');
```

### Step 7 — Session save/resume

On interrupt (Ctrl-C, AskUserQuestion timeout):
- Save current state to `runtime/core/drafts/<slug>.draft.md` with:
  - completed sections
  - pending sections
  - `_resume_at` timestamp
- On next `/core fill <slug>`, detect draft + offer resume vs restart

### Step 8 — Print summary

## Failure modes

| Symptom | Response |
|---|---|
| Status not stub or v0.1-draft | Abort: "core-fill only graduates stub or v0.1-draft. Edit canonical docs directly." |
| Layer not in schema | Abort: "no section schema for layer X. Add to this SKILL.md per-layer table." |
| Frontmatter parse error | Abort: "fix frontmatter manually first; then re-run." |
| Founder cancels mid-section | Save draft to runtime/core/drafts/; suggest resume on next invocation |
| `runtime/core/drafts/` doesn't exist | mkdir -p before write |
