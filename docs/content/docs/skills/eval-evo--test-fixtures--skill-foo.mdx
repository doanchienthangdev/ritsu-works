Summarize a paragraph into a single sentence. The fixture exists to exercise
the `/evolve skillopt` end-to-end pipeline without committing real production
skills as guinea pigs.

## Inputs

A single paragraph of prose, 50-200 words. May contain quotes, numbers, named
entities. Domain-agnostic.

## Output

A single sentence:
- ≤ 30 words
- Preserves the paragraph's central claim
- Uses the same factual entities (names, dates, numbers) as the input
- No editorial framing ("The author argues..."); just state the claim

## Process

1. Identify the paragraph's central claim (the sentence the rest supports).
2. Extract the load-bearing entities + the relation between them.
3. Rephrase as a single declarative sentence under 30 words.
4. Output the sentence only — no preamble, no quotation marks.

## Rubric

The judge scores each output against these binary criteria:

1. **Word count ≤ 30 words** (PASS = 1; FAIL = 0).
2. **Single sentence** (no semicolons, no internal periods other than abbreviations).
3. **Names of all explicitly-named entities preserved** (no "the team", "researchers", etc. when input named them).
4. **Numeric claims preserved verbatim** (dates, percentages, distances).
5. **No editorial framing** ("argues", "claims", "according to" disallowed unless in the input).

A passing summary scores 5/5. The judge's composite score = pass_count / 5.
