# docs-engine/adapters/hook-adapter

## Input pattern

`.claude/hooks/*.md` (loại trừ `README.md`, `SPEC.md` — những cái này trở thành trang giải thích, không phải tham chiếu hook)

## Output pattern

`docs/content/hooks/<name>.mdx`

## Process

1. Parse YAML frontmatter (6 khoá: `name`, `version`, `type`, `tools`, `default_decision`, `fail_mode`).
2. Tính `source_hash`.
3. Hiển thị MDX với các phần: "Policy", "Triggers (tools list)", "Decision logic", "Default behavior", "Failure mode".
4. Hiển thị `tools: [*]` dưới dạng callout "All tools".
5. Hiển thị `default_decision` + `fail_mode` dưới dạng khối Fumadocs `<Cards>` 2 hàng.
6. Thêm marker idempotency.

## Edge cases

- `tools: [*]` glob → mở rộng thành ghi chú giải thích ("This hook fires on every tool call").
- Multi-line `description:` (không hiện tại, nhưng phòng chứng).
