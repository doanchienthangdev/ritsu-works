# Markdown adapter (baseline Sprint 1)

## Khi nào dùng

- Được điều phối bởi `wiki-sync/ingest` khi path kết thúc bằng `.md` hoặc `.markdown`
- source_kind: `markdown_passthrough`
- entity_type: đọc từ frontmatter `type:` của file (nếu vắng mặt → `concept`)
- wiki target: `wiki/<slug>/source.md` (layout source-grouped v4.0; RECORD nguồn luôn sống tại `source.md` bất kể trường `type:` của frontmatter — các thực thể dẫn xuất được trích xuất bởi `distill` được đặt dưới các thư mục anh em `concepts/`, `observations/`, `decisions/`, `ideas/`)

## Inputs

- `path` — đường dẫn tuyệt đối dưới `raw/`

## Quy trình

### Bước 1 — Validate

- File có tồn tại không? Nếu không, dừng lại.
- Extension `.md` hoặc `.markdown`? Nếu không, ủy thác.
- Kích thước > 0? Nếu không, dừng lại.
- Kích thước \< 5 MB? Nếu không, dừng lại (cần split thủ công).
- Báo cáo `pages_or_size_metric = file_size_bytes`. v2.0 (Sprint 2 PR2): `wiki-sync/ingest` Bước 5 điều phối đến `wiki-sync/chapter-splitter` khi `pages_or_size_metric > 25 KB` (hoặc founder truyền `--split=heading=h2`); splitter đọc lại `raw_text` của adapter này và chạy phát hiện ranh giới heading=h2 trên nó.

### Bước 2 — Tính source_hash

```bash
sha256sum "$path"
```

### Bước 3 — Parse YAML frontmatter

Nếu file bắt đầu bằng block `---\n`:
```yaml
language: vi
translated: true
translated_at: 2026-05-19T13:00:00Z
translated_by: "Claude Opus 4.7 (Claude Code Desktop, session translation)"
---
type: book          # entity_type
slug: my-note       # override slug
title: My Note      # override title
author: ...
created: 2026-05-16
language: vi
translated: true
translated_at: 2026-05-19T13:00:00Z
translated_by: "Claude Opus 4.7 (Claude Code Desktop, session translation)"
---
```

Parse qua `js-yaml`. Trích xuất `type`, `slug`, `title` cho entity_type và gợi ý slug. Mang các trường còn lại vào `attribution`.

Nếu không có frontmatter: mặc định `entity_type='concept'`, slug từ stem filename.

### Bước 4 — Tổng hợp raw_text

Loại bỏ block frontmatter (nếu có). Trả về body làm `raw_text`.

### Bước 5 — Slug + attribution

- Slug: ưu tiên `slug:` của frontmatter; nếu không thì từ stem filename.
- Title: ưu tiên `title:` của frontmatter; nếu không thì `# Heading` đầu tiên trong body; nếu không thì từ filename.
- Attribution: các trường frontmatter không thuộc (`type`, `slug`, `title`).
