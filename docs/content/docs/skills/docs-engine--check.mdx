# docs-engine/check

## Khi nào sử dụng

- Lệnh `/docs check`
- `/docs check --tutorials` (tập con)
- Cron `docs-drift-nightly`
- Cổng PR `.github/workflows/docs-check.yml`

## Inputs

- `mode` — `all` | `tutorials-only`
- `output_format` — `markdown` | `json`

## Quá trình

1. Walker đi qua phạm vi Phase 1 Q3

3. Tính toán missing, orphan, stale

5. Xuất báo cáo trôi dạt
6. INSERT vào `ops.kpi_snapshots`
7. Phát event nếu có trôi dạt
8. Exit non-zero nếu có trôi dạt

- 1 dòng `ops.kpi_snapshots`
- 1 dòng `ops.events` (nếu trôi dạt > 0)
