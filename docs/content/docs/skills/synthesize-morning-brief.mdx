# Synthesize Morning Brief

> Skill reader cho brief founder hàng ngày. Brief được **tạo ra server-side**; skill này **đọc** nó.

## Kiến trúc

```
05:45 ICT hàng ngày ──► pg_cron kích hoạt `morning-brief-assembly`
                        │
                        ▼
                  scheduled-run-dispatcher Edge Function
                        │
                        ▼
                  minion-worker nhận scheduled_run row
                        │
                        ▼
                  makeSynthesizeMorningBriefHandler(deps)
                  → Anthropic Messages API (claude-haiku-4-5)
                        │
                        ▼
                  ops.agent_runs row inserted:
                    state: completed
                    skill: synthesize-morning-brief
                    output_payload.text: <4-bullet brief>
                        │
                        ▼
                  Founder mở `/ceo` sau đó trong ngày
                        │
                        ▼
                  CEO command đọc skill này
                        │
                        ▼
                  Skill truy vấn ops.agent_runs cho most recent
                  morning-brief row (trong 12h)
                        │
                        ▼
                  Trả về brief cho CEO context
                        │
                        ▼
                  CEO trình bày cho founder + thêm framing Top-3-today
```

## Skill này làm gì

1. Truy vấn `ops.agent_runs` cho row mới nhất có:
   - `state_payload.skill = 'synthesize-morning-brief'` (hoặc trường định danh skill tương đương per `schedules.generated.ts`)
   - `state = 'completed'`
   - `ended_at > now() - interval '12 hours'`

2. Nếu row tồn tại:
   - Đọc `output_payload.text` (4-bullet brief từ Anthropic)
   - Đọc `output_payload.input_tokens`, `output_tokens` (để báo cáo chi phí)
   - Đọc `fired_at` (khi cron được kích hoạt)
   - Trả về `{ brief, fired_at, cost_usd_estimate, freshness: 'fresh' }`.

3. Nếu không có fresh row (cron thất bại HOẶC > 12h):
   - Hiển thị tình trạng cũ rõ ràng
   - Trả về `{ brief: null, freshness: 'stale-or-missing', fallback: 'CEO synthesizes inline' }`
   - CEO's playbook Pattern 1 tiếp quản

## Freshness contract

- **Fresh** (\< 12h): trình bày nguyên bản với attribution one-line "from 05:45 brief".
- **Stale** (12-36h): trình bày + cảnh báo + khuyến nghị CEO tổng hợp fresh inline.
- **Missing** (> 36h hoặc không bao giờ): cron đang thất bại. Hiển thị dưới dạng P1 alert cho founder + trả về fallback signal.

## Failure modes

| Trường hợp | Hành vi Skill |
|---|---|
| Cron không kích hoạt (pg_cron down) | `freshness: stale-or-missing`; CEO tổng hợp inline. Hiển thị alert cho founder. |
| Cron kích hoạt nhưng Anthropic API lỗi | Giống ở trên; kiểm tra `ops.agent_runs.error`. |
| Nhiều briefs trong cửa sổ 12h (cron duplicate) | Trả về most recent; ghi log anomaly. |
| Brief text trống | Giống cron failure path. |
| ANTHROPIC_API_KEY thiếu | Cron handler degrade thành placeholder text per worker.ts; skill trả về placeholder + warning. |
