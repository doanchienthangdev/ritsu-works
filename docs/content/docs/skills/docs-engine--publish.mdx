# docs-engine/publish

## Khi nào dùng

- Lệnh `/docs publish` (triển khai sản xuất do founder khởi tạo).

## Inputs

- (Không có — sử dụng `main` HEAD.)

## Process

1. Xác minh `docs_drift_count == 0` (truy vấn `ops.kpi_snapshots` mới nhất).
2. Xác minh `pnpm check` sạch trên HEAD hiện tại.
3. Lấy URL xem trước Vercel mới nhất cho HEAD.
4. **AskUserQuestion** (Tier B): hiển thị URL xem trước; founder xác nhận publish.
5. Kích hoạt triển khai sản xuất Vercel (CLI `vercel --prod` hoặc webhook).
6. Poll trạng thái deploy lên đến 120s.
7. Emit `ritsu.docs.published` với `{deploy_id, deploy_url, status}`.

## Outputs

- Hàng `ops.events` sự kiện `ritsu.docs.published`.
- Hàng `ops.hitl_runs` (xác nhận Tier B).

## HITL

**Tier B.** Founder xác nhận thông qua `AskUserQuestion` với URL xem trước.

## Failure modes

- Drift hiện tại → từ chối publish; hiển thị báo cáo drift.
- Vercel deploy timeout → emit sự kiện với `status: timeout`; founder điều tra thủ công.
- Vercel API auth thất bại → hiển thị; kiểm tra biến môi trường `VERCEL_TOKEN` (governance/SECRETS.md).

## Cost estimate

$0 LLM. Per-task-kind cap: `docs-publish` ≤ $0.10 (về cơ bản chỉ là chi phí AskUserQuestion).
