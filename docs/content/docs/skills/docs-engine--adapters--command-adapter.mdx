# docs-engine/adapters/command-adapter

## Input pattern

`.claude/commands/*.md`

## Output pattern

`docs/content/commands/<name>.mdx`

## Process

1. Cố gắng parse YAML frontmatter.
2. **Fallback nếu không có frontmatter:** dẫn xuất `title` từ H1 đầu tiên (`# /<name>`); `description` từ đoạn đầu tiên.
3. Tính `source_hash`.
4. Hiển thị MDX với các phần: "Synopsis", "Subcommands", "Workflow", "State persistence", "Drift gates", "HITL discipline".
5. Phát hiện bảng subcommand (bảng markdown có cột đầu tiên là "Invocation") → hiển thị với Fumadocs `<Tabs>` mỗi động từ chính.
6. Thêm marker idempotency.

## Edge cases

- Lệnh với bảng sub-command: `/wiki`, `/cla`, `/docs` (mới). Parse + cấu trúc.
- Lệnh không có sub-command: `/cto`, `/cgo`, `/ceo`, `/cpo`. Hiển thị dưới dạng narrative trang đơn.
- `/check-drift`, `/mcp-doctor`: các lệnh deterministic-tool không có LLM; ngắn gọn.
