# URL adapter (baseline Sprint 1)

## Khi nào dùng

- Được điều phối bởi `wiki-sync/ingest` khi path bắt đầu bằng `http://` hoặc `https://`
- source_kind: `article`
- entity_type: `article`
- wiki target: `wiki/<slug>/source.md` (layout source-grouped v4.0; các thực thể dẫn xuất được trích xuất bởi `distill` được đặt tại `wiki/<slug>/concepts/`, `wiki/<slug>/observations/`, v.v.)

## Inputs

- `path` — URL (http/https)

## Quy trình

### Bước 1 — Validate URL

- URL có parse được không? Nếu không, dừng lại.
- Scheme http/https? Nếu không, dừng lại.
- Host không nằm trong blocklist (ví dụ, `localhost`, `127.0.0.1`, `169.254.169.254` (AWS metadata SSRF)).

### Bước 2 — Lấy HTML

```bash
curl -sL -A "ritsu-wiki-sync/1.0" -H "Accept: text/html" --max-time 30 "$url" -o /tmp/raw.html
```

Capture:
- HTTP status (phải là 200; redirect tự động được follow)
- Header `ETag` (để phát hiện re-sync)
- Header `Last-Modified` (fallback cho re-sync)
- URL cuối cùng sau redirect

### Bước 3 — Tính source_hash

```bash
# Ưu tiên ETag nếu có, nếu không thì hash body
if [[ -n "$etag" ]]; then
  echo "etag:$etag"
else
  sha256sum /tmp/raw.html | cut -d' ' -f1
fi
```

### Bước 4 — Trích xuất Readability

Dùng `@mozilla/readability` (package Node; thêm vào deps mcp-server HOẶC một package helper wiki-sync mới). Pseudocode:

```javascript
import { Readability } from '@mozilla/readability';
import { JSDOM } from 'jsdom';

const dom = new JSDOM(html, { url });
const reader = new Readability(dom.window.document);
const article = reader.parse();
// { title, content (HTML), textContent, length, excerpt, byline, siteName, publishedTime }
```

### Bước 5 — HTML→Markdown

Dùng package Node `turndown` (hoặc tương tự):

```javascript
import TurndownService from 'turndown';
const td = new TurndownService({ headingStyle: 'atx', codeBlockStyle: 'fenced' });
const markdown = td.turndown(article.content);
```

### Bước 6 — Slug + attribution

- Slug: từ title bài viết → kebab-case, chữ thường, loại bỏ dấu câu, giới hạn 50 ký tự.
  Fallback: từ phần đuôi của URL path.
- Attribution: \{ author: article.byline, publication: article.siteName, published_at: article.publishedTime, url }

## Các chế độ thất bại

| Triệu chứng | Phản ứng |
|---|---|
| URL không thể truy cập / DNS fail | Dừng lại với exit code của curl |
| HTTP status không phải 2xx | Dừng lại với status; gợi ý save thủ công → markdown adapter |
| Readability không tìm thấy nội dung chính | Dừng lại; gợi ý trích xuất thủ công |
| Nội dung \< 200 ký tự sau khi trích xuất | Cảnh báo; gắn cờ low_quality |
| URL bị chặn (host SSRF) | Dừng lại với từ chối bảo mật rõ ràng |

## Bảo mật

- Chặn host private/loopback (phòng vệ SSRF)
- Timeout sau 30 giây
- Giới hạn kích thước response ở 10 MB (drop các fetch quá lớn)
- Loại bỏ tag `<script>` trước khi readability xử lý (readability cũng làm việc này, defense-in-depth)

## Ước tính chi phí

- HTTP fetch: MIỄN PHÍ
- Readability + turndown: MIỄN PHÍ (local)
- Embedding (downstream): ~$0.001-$0.005 / bài viết
- LLM-fallback (downstream, nếu được kích hoạt): ~$0.05 / chunk

Tổng cho mỗi bài viết thường: $0.05-$0.10.

## Phạm vi sprint

Sprint 2: xử lý bài viết nhiều trang (paginated/infinite-scroll).
Sprint 4+: subscription chủ động (Bài #18) — tự động poll feed.
