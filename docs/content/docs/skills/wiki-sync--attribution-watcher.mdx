# wiki-sync / attribution-watcher (v3.0)

## When this skill runs

- Background: triggered by `ops.events` rows of `event_type IN ('ritsu.file_edit_01_marketing', 'ritsu.file_edit_02_sales')` (these events are emitted by a file-watcher background process; see Wiring section below).
- Reactive: founder may explicitly invoke `/wiki attribution-check <content-file>` (Sprint 4+ — not in v3.0.0 first PR).

## Purpose (Muse M2 / axis A11)

When the founder writes content in `01-marketing/` or `02-sales/`, that content may paraphrase distilled observations from copyrighted sources (`license_status='copyrighted_internal_only'`). If >= 3 observations from a single copyrighted source feed into one content piece, the resulting public content may:
- Cross the substantiality line of fair use
- Require explicit attribution (which the founder may forget)

This skill catches that pattern PRE-PUBLISH and surfaces it to founder via Telegram heads-up. Founder either:
- Adds explicit attribution to the content (and ignores future alerts for this pair)
- Removes some of the paraphrased observations
- Re-frames content to be more original (less direct paraphrase)

## Inputs (event-driven)

When a `01-marketing/` or `02-sales/` file edit event fires:
- `content_file_path` — the edited file
- `edit_timestamp` — when edit happened
- `edit_diff_summary` — `git diff` of new content vs prior commit (file-watcher captures)

## Outputs

- Tier B Telegram message to founder when threshold (3+ obs from copyrighted_internal_only source) crossed
- One `ops.events` row per alert (`ritsu.wiki.attribution_alert`)
- `ops.cost_attributions` row (cost = $0 — DB queries + Telegram bot)

## Process

### Step 1 — Find recent /wiki ask invocations correlated with this edit

```sql
SELECT
  ar.id AS run_id,
  ar.input_payload->>'question' AS question,
  ar.output_payload->'citations' AS citations,
  ar.completed_at
FROM ops.agent_runs ar
WHERE ar.agent_slug = 'wiki-sync/ask'
  AND ar.completed_at BETWEEN $edit_timestamp - interval '10 minutes' AND $edit_timestamp
ORDER BY ar.completed_at DESC;
```

If 0 results → no correlation; this edit was written without `/wiki ask` lookup. Skip (attribution-watcher only fires when content was likely informed by wiki retrieval).

### Step 2 — For each correlated /wiki ask, count copyrighted observations cited

```sql
WITH cited_entities AS (
  SELECT DISTINCT
    citation->>'page_id' AS derived_page_id
  FROM jsonb_array_elements($citations) AS citation
),
copyrighted_sources AS (
  SELECT DISTINCT
    ke.source_page_id,
    sp.title AS source_title,
    sp.slug AS source_slug,
    COUNT(*) AS observation_count
  FROM ops.knowledge_extractions ke
  JOIN ops.knowledge_pages dp ON dp.id = ke.derived_page_id
  JOIN ops.knowledge_pages sp ON sp.id = ke.source_page_id
  JOIN cited_entities ce ON ce.derived_page_id::uuid = dp.id
  WHERE sp.frontmatter->>'license_status' = 'copyrighted_internal_only'
    AND ke.link_type = 'extracted_observation'
  GROUP BY ke.source_page_id, sp.title, sp.slug
)
SELECT * FROM copyrighted_sources WHERE observation_count >= 3;
```

## License-status discipline

For attribution-watcher to fire correctly, every distilled source MUST have `license_status` set on its source RECORD frontmatter. Distill skill (Step 1 pre-flight) prompts founder via AskUserQuestion on first ingest of a source if frontmatter doesn't already declare it.

Enum:
- `public_domain` — no attribution required (e.g., government reports, expired-copyright works)
- `creative_commons` — attribution required per CC license terms (already standard)
- `fair_use_excerpt` — short quotation; safe for any v3.0 content
- `copyrighted_internal_only` — proprietary; founder must NOT paraphrase publicly without explicit attribution agreement OR transformative re-framing

Default if founder doesn't pick: `copyrighted_internal_only` (safer to over-warn than under-warn).

## Failure modes

| Symptom | Response |
|---|---|
| Source frontmatter missing `license_status` | Treat as `copyrighted_internal_only` (conservative); founder can override by editing the source page's frontmatter directly. |
| `/wiki ask` was used but content NOT in 01-marketing/ or 02-sales/ (e.g., 04-product/ doc) | Out of scope for v3.0; v3.1 may expand monitored paths to 04-product/ and 06-ai-ops/. |
