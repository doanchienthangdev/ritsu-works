## Khi nào dùng

Được invoke bởi `resolver/orchestrator` khi subcommand là `query`.

Wrapper hướng tới operator quanh `scripts/resolver/query.cjs`.

Cho consumer **agent-to-agent**, invoke `resolver-query` (skill consumer-
contract) thay vì skill này; skill này dành cho invocation `/resolver
query "\<trigger>"` hướng operator.

## Process

1. Nhận args đã parse (trigger string + flags: --semantic, --plan, --json,
   --role, --kind)
2. Gọi `require('scripts/resolver/query.cjs').query({...})`
3. Render output:
   - Mặc định (human): `[decision] <matched-id> conf=N latency=Nms\n  alternatives:\n  invocation: ...`
   - `--json`: pretty-print JSON
4. Ghi audit (qua audit.cjs) — best-effort; defer nếu DB unreachable

## Error handling

Theo `scripts/resolver/errors.cjs`:
- `InvalidTrigger` → in usage "Trigger required"
- `ResolverDown` → in "Resolver not initialized" + remediation
- Tất cả các lỗi khác → in error.code + message + suggested action
