# Task Status

> Hiển thị tiến độ orchestration dưới dạng cây. Skill chuyển đổi ops.tasks rows thành thứ mà founder đọc trong 10 giây.

## Khi nào dùng

Ba bối cảnh kích hoạt:

1. **Founder hỏi về tiến độ.** Gọi trực tiếp thông qua Telegram bot (`/tasks`, `/status <id>`) hoặc CLI.
2. **GPS kiểm tra trước khi tiến hành parent.** Trước khi đánh dấu parent task `done`, GPS xác minh tất cả children ở trạng thái terminal.
3. **Chuẩn bị monthly review.** Skill `monthly-learning-review` dùng cái này để thu thập completion stats cho tháng qua.

Không dùng khi:
- Người gọi muốn raw SQL — dùng Supabase query trực tiếp, skill này hiển thị cho consumption con người
- Real-time pub/sub cần thiết — cái này là poll-based; pub/sub là post-v1.0

## Inputs

| Input | Type | Bắt buộc | Description |
|---|---|---|---|
| `mode` | string | yes | `tree` (single parent + descendants) HOẶC `list` (open orchestrations) |
| `task_id` | uuid | conditional | Bắt buộc cho `tree` mode |
| `assignee_role` | string | no | Lọc list mode theo role |
| `since` | timestamptz | no | Lọc list mode tới tasks tạo sau timestamp |
| `include_done` | bool | no | Mặc định false; có include terminal tasks hay không |

## Quality criteria

- Trả về trong 200ms wall-clock cho trees lên đến 20 children
- Output cho founder mode vừa trong 1 Telegram message (\< 4096 chars)
- Tính chi phí bao gồm tất cả subagent costs chính xác
- `next_action` field luôn non-empty cho in-progress orchestrations

## Failure modes

- **Task ID không tìm thấy** — trả về "task does not exist" rõ ràng; đừng trả về trống yên tĩnh
- **Schema chưa provision** — trả về "ops.tasks not yet created" với pointer đến provision recipe
- **Telegram message quá dài** — cắt ngắn danh sách child, gợi ý "/status \<id> --full" cho verbose
- **Database unreachable** — trả về graceful error; đừng block calling skill, chỉ nói "status unavailable, retry"

## Cost estimate

- 2-3 truy vấn SQL, ~50ms mỗi cái
- ~200-800 output tokens
- Per-invocation cost: \< $0.005
- Founder dùng ~5x/day = $0.025/day = $0.75/month. Negligible.
