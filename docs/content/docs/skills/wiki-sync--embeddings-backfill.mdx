# wiki-sync / embeddings-backfill (Sprint 2 PR3 baseline — v2.0.0)

## When this skill runs

**Sprint 2 PR3 (v0.1) wiring:** Invocable manually via:
```
node scripts/sync/backfill-wiki-embeddings.cjs [--max-pages=10] [--dry-run]
```

**Cron wiring deferred to follow-up PR:** the `wiki-embeddings-backfill`
entry in `knowledge/schedules.yaml` requires a corresponding handler key in
`supabase/functions/minion-worker/index.ts` SKILL_REGISTRY (enforced by L2
validator `validate-schedules-skills.cjs`). Adding the handler is its own
concern — see Sprint 2 PR4+ or the v0.2 milestone of this script.

Until cron wiring lands, founder backfills manually (or via subagent) by
invoking the script above when a new `OPENAI_API_KEY` is provisioned OR after
a batch of soft-deferred wiki pages accumulates.

## Inputs

- `max_pages` — batch size cap (default 10)
- `dry_run` — bool; if true, lists what WOULD be processed without API calls

## Process

### Step 1 — Self-throttle check (per CTO NIT 4)

Query `ops.scheduled_runs` for the most recent `wiki-embeddings-backfill` row:

```sql
SELECT state_payload->>'affected_rows' AS last_affected, fired_at
  FROM ops.scheduled_runs
 WHERE schedule_id = 'wiki-embeddings-backfill'
 ORDER BY fired_at DESC
 LIMIT 1;
```

If `last_affected = 0` AND `fired_at > now() - interval '6 hours'` → skip this
tick. Log to `ops.scheduled_runs`:
```
state = 'skipped',
state_payload = jsonb_build_object('reason', 'self_throttle', 'last_check', last_fired)
```
Return without API calls.

### Step 2 — Find deferred pages

v3.0 update: query covers BOTH source RECORD pages AND derived entity pages.
Derived entity pages (page_type IN concept/observation/decision/idea where
extracted_from_source_id IS NOT NULL) are produced by wiki-sync/distill —
they need embeddings so wiki-sync/dedup can do cross-source semantic matching.

```sql
-- Source RECORD pages with deferred embeddings (v2.0 pattern, preserved)
(SELECT kp.id, kp.slug, kp.file_path, kp.page_type,
        ij.id AS ingestion_job_id, 'source_record' AS page_class
   FROM ops.knowledge_pages kp
   JOIN ops.ingestion_jobs ij ON ij.resulting_page_id = kp.id
  WHERE ij.metadata->>'embeddings_deferred' = 'true'
    AND kp.deleted_at IS NULL
    AND NOT EXISTS (SELECT 1 FROM ops.knowledge_embeddings ke WHERE ke.page_id = kp.id))
UNION ALL
-- Derived entity pages (v3.0 — from distill skill)
(SELECT kp.id, kp.slug, kp.file_path, kp.page_type,
        ij.id AS ingestion_job_id, 'derived_entity' AS page_class
   FROM ops.knowledge_pages kp
   LEFT JOIN ops.ingestion_jobs ij ON ij.resulting_page_id = kp.extracted_from_source_id
  WHERE kp.extracted_from_source_id IS NOT NULL
    AND kp.legacy_v2_verbatim = false
    AND kp.deleted_at IS NULL
    AND kp.page_type IN ('concept', 'observation', 'decision', 'idea')
    AND NOT EXISTS (SELECT 1 FROM ops.knowledge_embeddings ke WHERE ke.page_id = kp.id))
ORDER BY created_at ASC          -- oldest first; FIFO fairness
LIMIT $max_pages;
```

If 0 rows → write `affected_rows=0` to scheduled_runs and return (next tick
will self-throttle if still 0 in 6h).

Per spec §3.7: dedup skill REQUIRES derived entity embeddings to function.
If derived entity backlog grows > 100 pages, dedup queue rate slows; founder
Telegram heads-up via daily digest.

### Step 3 — Read each wiki file + chunk

For each page in the batch:
- Read file at `wiki/<file_path>` (relative to repo root)
- Strip YAML frontmatter
- Chunk per adapter's strategy:
  - markdown_passthrough: structural per H2 boundary, else fixed 512 tokens
  - book (single page, no chapter children): structural per H2 inside, else token 1024
  - book (chapter child): structural per paragraph, else token 512
  - article: token 512 with overlap 64
  - episode/meeting: structural per speaker turn or VTT cue

### Step 4 — Call OpenAI embed API

Batch the chunks (OpenAI supports up to 2048 inputs per call). Use
`text-embedding-3-small` model (1536 dims, $0.02/1M tokens).

```javascript
const response = await openai.embeddings.create({
  model: 'text-embedding-3-small',
  input: chunks.map(c => c.text)
});
```

If API call fails (rate limit, network, key invalid):
- Mark this batch as RETRY → leave `embeddings_deferred=true` flag intact
- Surface error to founder via Telegram with exponential backoff (1h → 2h → 4h)
- After 3 consecutive failures, escalate to Tier B (founder must intervene)

### Step 5 — INSERT embeddings

For each chunk:
```sql
INSERT INTO ops.knowledge_embeddings (
  page_id, chunk_index, chunk_text, embedding,
  embedding_model, token_count, chunk_hash
) VALUES (...);
```

### Step 6 — Clear deferred flag

```sql
UPDATE ops.ingestion_jobs
   SET metadata = metadata - 'embeddings_deferred'
                || jsonb_build_object('embeddings_backfilled_at', now())
 WHERE id = $ingestion_job_id;
```

### Step 7 — Log + record cost

```sql
INSERT INTO ops.cost_attributions (
  run_id, agent_role, task_kind, model,
  input_tokens, cache_creation_tokens, cache_read_tokens, output_tokens,
  cost_usd
) VALUES (
  $run_id, 'etl-runner', 'wiki-embeddings-backfill', 'text-embedding-3-small',
  $total_input_tokens, 0, 0, 0,
  $total_input_tokens * 0.02 / 1000000  -- $0.02 per 1M tokens
);

UPDATE ops.scheduled_runs SET
  state = 'completed',
  state_payload = jsonb_build_object('affected_rows', $page_count, 'total_chunks', $chunk_count, 'cost_usd', $cost)
WHERE id = $scheduled_run_id;
```

### Step 8 — Founder heartbeat (only if work was done)

If `affected_rows > 0`:


If `affected_rows = 0` AND last hourly tick also 0: silent (self-throttle will kick in next hour).

## HITL

- Tier A normally (additive writes; reversible by DELETE FROM knowledge_embeddings)
- Tier B if:
  - API call has failed 3 consecutive times → surface to founder
  - Batch size > 50 pages on manual invocation → confirm cost
  - OPENAI_API_KEY not present → bail with clear message; founder provisions or accepts deferral

## Cost estimate

- ~$0.02 per 1M tokens input
- Typical wiki page (~2000 tokens) ≈ 4 chunks × 500 tokens = $0.00004 per page
- Batch of 10 pages: ~$0.0004
- Catching up 1000 deferred pages: ~$0.04 (one-time)

## Failure modes

| Symptom | Response |
|---|---|
| `OPENAI_API_KEY` not in env | Bail with "no key; deferred pages stay deferred"; founder action required |
| OpenAI rate limit (429) | Exponential backoff (1h → 2h → 4h); after 3 fails, founder alert |
| Network error | Retry once with 30s delay; if still fails, log + retry next tick |
| Wiki file missing on disk | Mark page row as `embeddings_failed_file_missing=true` in metadata; skip; alert founder |
| OpenAI returns dimensions ≠ 1536 | Hard fail; OpenAI API contract break — surface to founder Tier C |
| INSERT into knowledge_embeddings violates UNIQUE | Page may already have embeddings (race condition); skip; clear deferred flag |
