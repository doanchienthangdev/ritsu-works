## Quy trình

### Bước 1 — Kiểm tra self-throttle (theo CTO NIT 4)

Truy vấn `ops.scheduled_runs` cho dòng `wiki-embeddings-backfill` gần đây nhất:

```sql
SELECT state_payload->>'affected_rows' AS last_affected, fired_at
  FROM ops.scheduled_runs
 WHERE schedule_id = 'wiki-embeddings-backfill'
 ORDER BY fired_at DESC
 LIMIT 1;
```

Nếu `last_affected = 0` AND `fired_at > now() - interval '6 hours'` → skip tick này. Log vào `ops.scheduled_runs`:
```
state = 'skipped',
state_payload = jsonb_build_object('reason', 'self_throttle', 'last_check', last_fired)
```
Return mà không gọi API.

### Bước 2 — Tìm các trang deferred

Cập nhật v3.0: truy vấn bao gồm CẢ trang source RECORD AND trang derived entity. Trang derived entity (page_type IN concept/observation/decision/idea với extracted_from_source_id IS NOT NULL) được tạo bởi wiki-sync/distill — chúng cần embedding để wiki-sync/dedup có thể làm semantic matching cross-source.

```sql
-- Source RECORD pages with deferred embeddings (v2.0 pattern, preserved)
(SELECT kp.id, kp.slug, kp.file_path, kp.page_type,
        ij.id AS ingestion_job_id, 'source_record' AS page_class
   FROM ops.knowledge_pages kp
   JOIN ops.ingestion_jobs ij ON ij.resulting_page_id = kp.id
  WHERE ij.metadata->>'embeddings_deferred' = 'true'
    AND kp.deleted_at IS NULL
    AND NOT EXISTS (SELECT 1 FROM ops.knowledge_embeddings ke WHERE ke.page_id = kp.id))
UNION ALL
-- Derived entity pages (v3.0 — from distill skill)
(SELECT kp.id, kp.slug, kp.file_path, kp.page_type,
        ij.id AS ingestion_job_id, 'derived_entity' AS page_class
   FROM ops.knowledge_pages kp
   LEFT JOIN ops.ingestion_jobs ij ON ij.resulting_page_id = kp.extracted_from_source_id
  WHERE kp.extracted_from_source_id IS NOT NULL
    AND kp.legacy_v2_verbatim = false
    AND kp.deleted_at IS NULL
    AND kp.page_type IN ('concept', 'observation', 'decision', 'idea')
    AND NOT EXISTS (SELECT 1 FROM ops.knowledge_embeddings ke WHERE ke.page_id = kp.id))
ORDER BY created_at ASC          -- oldest first; FIFO fairness
LIMIT $max_pages;
```

Nếu 0 dòng → ghi `affected_rows=0` vào scheduled_runs và return (tick tiếp theo sẽ self-throttle nếu vẫn 0 trong 6h).

Theo spec §3.7: skill dedup YÊU CẦU embedding derived entity để hoạt động. Nếu backlog derived entity tăng > 100 trang, tốc độ queue dedup chậm; heads-up Telegram cho founder qua digest hằng ngày.

### Bước 3 — Đọc mỗi file wiki + chunk

Cho mỗi trang trong batch:
- Đọc file tại `wiki/<file_path>` (tương đối với repo root)
- Strip YAML frontmatter
- Chunk theo chiến lược của adapter:
  - markdown_passthrough: structural theo biên H2, fallback fixed 512 token
  - book (single page, không có chapter children): structural theo H2 bên trong, fallback token 1024
  - book (chapter child): structural theo paragraph, fallback token 512
  - article: token 512 với overlap 64
  - episode/meeting: structural theo lượt speaker hoặc VTT cue

### Bước 4 — Gọi API embed của OpenAI

Batch các chunk (OpenAI hỗ trợ tối đa 2048 input mỗi call). Dùng model `text-embedding-3-small` (1536 dims, $0.02/1M tokens).

```javascript
const response = await openai.embeddings.create({
  model: 'text-embedding-3-small',
  input: chunks.map(c => c.text)
});
```

Nếu API call fail (rate limit, network, key không hợp lệ):
- Đánh dấu batch này là RETRY → giữ nguyên cờ `embeddings_deferred=true`
- Báo lỗi cho founder qua Telegram với exponential backoff (1h → 2h → 4h)
- Sau 3 lần fail liên tiếp, leo thang lên Tier B (founder phải can thiệp)

## HITL

- Tier A bình thường (ghi additive; reversible bằng DELETE FROM knowledge_embeddings)
- Tier B nếu:
  - API call fail 3 lần liên tiếp → báo cho founder
  - Batch size > 50 trang khi gọi thủ công → confirm cost
  - OPENAI_API_KEY không có → bail với thông báo rõ ràng; founder provision hoặc chấp nhận hoãn

## Ước tính chi phí

- ~$0.02 mỗi 1M token input
- Trang wiki điển hình (~2000 tokens) ≈ 4 chunk × 500 tokens = $0.00004 mỗi trang
- Batch 10 trang: ~$0.0004
- Bắt kịp 1000 trang deferred: ~$0.04 (một lần)

## Các chế độ lỗi

| Triệu chứng | Phản ứng |
|---|---|
| `OPENAI_API_KEY` không có trong env | Bail với "no key; deferred pages stay deferred"; cần founder action |
| OpenAI rate limit (429) | Exponential backoff (1h → 2h → 4h); sau 3 fail, alert founder |
| Lỗi mạng | Retry một lần với delay 30s; nếu vẫn fail, log + retry tick tiếp theo |
| File wiki thiếu trên disk | Đánh dấu dòng trang là `embeddings_failed_file_missing=true` trong metadata; skip; alert founder |
| OpenAI trả về dimension ≠ 1536 | Hard fail; vi phạm contract OpenAI API — báo cho founder Tier C |
| INSERT vào knowledge_embeddings vi phạm UNIQUE | Trang có thể đã có embedding (race condition); skip; clear cờ deferred |
