# wiki-sync / package (Sprint 2 of v4.0 revise)

## When to use

- Founder runs `/wiki package <slug>` → dispatches here.
- Skill author wants to know if a package has the entities their template requires.

## Inputs

- `slug` — source package slug (folder name under `wiki/`)

## Process

### Step 1 — Validate

- Check `wiki/<slug>/` directory exists.
- Check `wiki/<slug>/source.md` exists. If absent, surface "not a v4.0 package" and offer `/wiki sync` to create it.

### Step 2 — Read source RECORD

Parse `wiki/<slug>/source.md` frontmatter:
- `type`, `slug`, `title`, `source_ref`, `source_hash`, `license_status`, `source_kind`

### Step 3 — Enumerate by type subfolder

For each of `{concepts, observations, decisions, ideas, chapters}/` subfolder of `wiki/<slug>/`:
- `ls *.md` (only `.md` files; skip `.gitkeep`, hidden)
- For each entity file, read frontmatter `type`, `slug`, `title`

### Step 4 — Render inventory

Output (Markdown to stdout for slash command; or JSON for callers):

```
# Package: <title> (`<slug>`)

- **Type:** <page_type> (source RECORD)
- **Source:** <source_ref>
- **License:** <license_status>
- **Hash:** <source_hash>

## Entities

### Concepts (N)
- [<entity-title>](wiki/<slug>/concepts/<entity-slug>.md)
- ...

### Observations (M)
- ...

### Decisions (K)
- ...

### Ideas (J)
- ...

### Chapters (P) (only if book / chapter-split)
- ...
```

### Step 5 — Cost

This skill makes no LLM call. Pure FS read. Cost: $0 (file I/O only).

## Failure modes

| Symptom | Response |
|---|---|
| `wiki/<slug>/` does not exist | Bail "not a package" + suggest `/wiki list` for available packages |
| `wiki/<slug>/source.md` missing | Bail "incomplete package" + suggest `/wiki sync` to create source RECORD |
| Frontmatter parse error on source.md | Bail with file:line + parse error detail |
