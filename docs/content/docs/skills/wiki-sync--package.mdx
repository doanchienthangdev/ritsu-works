# wiki-sync / package (Sprint 2 của v4.0 revise)

## Khi nào dùng

- Founder chạy `/wiki package <slug>` → dispatch đến đây.
- Tác giả skill muốn biết một package có các thực thể mà template của họ cần hay không.

## Đầu vào

- `slug` — slug source package (tên thư mục dưới `wiki/`)

## Quy trình

### Bước 1 — Validate

- Kiểm tra thư mục `wiki/<slug>/` tồn tại.
- Kiểm tra `wiki/<slug>/source.md` tồn tại. Nếu không có, thông báo "not a v4.0 package" và đề nghị `/wiki sync` để tạo nó.

### Bước 2 — Đọc source RECORD

Parse frontmatter của `wiki/<slug>/source.md`:
- `type`, `slug`, `title`, `source_ref`, `source_hash`, `license_status`, `source_kind`

### Bước 3 — Liệt kê theo subfolder type

Với mỗi subfolder `{concepts, observations, decisions, ideas, chapters}/` của `wiki/<slug>/`:
- `ls *.md` (chỉ tệp `.md`; bỏ `.gitkeep`, ẩn)
- Với mỗi tệp thực thể, đọc frontmatter `type`, `slug`, `title`

### Bước 4 — Render inventory

Đầu ra (Markdown ra stdout cho slash command; hoặc JSON cho caller):

```
# Package: <title> (`<slug>`)

- **Type:** <page_type> (source RECORD)
- **Source:** <source_ref>
- **License:** <license_status>
- **Hash:** <source_hash>

## Entities

### Concepts (N)
- [<entity-title>](wiki/<slug>/concepts/<entity-slug>.md)
- ...

### Observations (M)
- ...

### Decisions (K)
- ...

### Ideas (J)
- ...

### Chapters (P) (only if book / chapter-split)
- ...
```
