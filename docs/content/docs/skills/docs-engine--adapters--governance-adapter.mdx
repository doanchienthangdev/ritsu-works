# docs-engine/adapters/governance-adapter

## Input pattern

`governance/*.md` TRỪ `SECRETS.md`

## Output pattern

`docs/content/governance/<name>.mdx`

## Process

1. **Loại trừ cứng `governance/SECRETS.md`** ở mức walker (layer 1 redaction). Adapter không thấy nó.
2. Cho mỗi phần còn lại: title từ H1 đầu tiên.
3. Tính `source_hash`.
4. Hiển thị MDX. Áp dụng xử lý đặc biệt:
   - `HITL.md` → phát hiện bảng 4-tier; hiển thị dưới dạng Fumadocs `<Tabs>` mỗi tier.
   - `ROLES.md` → phát hiện định nghĩa role; hiển thị dưới dạng `<Cards>` grid mỗi role.
   - `BUDGET.md` → hiển thị cắt economic_budget dưới dạng bảng.
   - `IDENTITY.md` → pass-through tiêu chuẩn.
5. **Lớp scrub regex 2** vẫn chạy trên tất cả output (defense-in-depth) — nên redundant sau exclude nhưng bắt buộc per CTO mod #2.
6. Thêm marker idempotency.

## Edge cases

- HITL.md đề cập magic phrases là EXAMPLES — những cái này khớp với regex và sẽ kích layer 2. Giải pháp: walker emit raw HITL.md cho adapter; adapter thay thế ví dụ magic phrases bằng `<placeholder>` TRƯỚC regex scrub.
