# docs-engine/adapters/agent-adapter

## Input pattern

`.claude/agents/*.md` (trừ `README.md`)

## Output pattern

`docs/content/agents/<name>.mdx`

## Process

1. Parse YAML frontmatter (`name`, `description`, `tools`).
2. Tham chiếu chéo `knowledge/workforce-personas.yaml` để tìm role ràng buộc (ví dụ: cto → code-reviewer).
3. Tham chiếu chéo `governance/ROLES.md` để lấy quyền role + ngân sách.
4. Tính `source_hash`.
5. Hiển thị MDX với các phần: "Description", "Tools", "Bound role", "Permissions", "Activation patterns".
6. Thêm marker idempotency.

## Edge cases

- Persona `status: planned` → đánh dấu MDX với "🏗️ planned" badge; ghi chú fallback_role.
- Danh sách Tools trải dài nhiều dòng → hiển thị dưới dạng `<Files>` hoặc `<Tabs>`.
