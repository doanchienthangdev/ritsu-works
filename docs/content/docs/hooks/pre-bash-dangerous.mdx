# Hook: pre-bash-dangerous

> Phát hiện các mẫu lệnh shell nguy hiểm và escalate hoặc block tùy theo mức độ nghiêm trọng. Tập hợp các mẫu được xây dựng từ thực tế — từ "những điều đã gây ra sự cố ở nơi khác."

## Những gì nó làm

Kiểm tra trường `command` của bất kỳ lệnh Bash nào. So khớp với danh sách các loại mẫu được quản lý:

- **Catastrophic** → block vô điều kiện
- **High-risk** → escalate với full preview
- **Medium-risk** → escalate với brief preview
- **Sensitive context** → escalate nếu được thực thi trên các đường dẫn nhạy cảm

## Các loại mẫu

### Catastrophic (BLOCK, không cho phép override)

Những mẫu này bị block ngay cả khi có override. Cơ chế override không phải là giấy phép cho những hành động không thể đảo ngược.

```
rm -rf /                         # nuke filesystem
rm -rf /*                        # nuke filesystem
rm -rf ~                         # nuke home
:(){ :|:& };:                    # fork bomb
mkfs                             # reformat filesystem
dd if=/dev/zero of=/dev/sd[a-z]  # overwrite disk
chmod -R 000 /                   # lock permissions
```

Nếu khớp: `block` với lý do `catastrophic_pattern: <pattern>`. Founder sẽ được thông báo qua Telegram bất kể điều gì. Đây được coi là một sự kiện bảo mật.

### High-risk (ESCALATE; cho phép với override)

```
rm -rf <any path>                # bên ngoài catastrophic, nhưng vẫn đáng sợ
git push --force                 # viết lại lịch sử remote
git push -f                      # tương tự
git reset --hard <ref>           # phá hủy công việc local
git clean -fd                    # phá hủy các tập tin untracked
DROP TABLE                       # SQL destructive
DELETE FROM .* WHERE             # bulk delete; gate ngay cả với WHERE
TRUNCATE                         # SQL destructive
sudo                             # privilege elevation
chmod -R 777 <any>               # mở permissions globally
chown -R                         # bulk ownership change
> /dev/sd                        # write to raw disk
curl <...> | bash                # execute remote script
curl <...> | sh                  # tương tự
wget <...> -O- | bash            # tương tự
```

Nếu khớp: `escalate` với `high_risk_pattern: <pattern>`. Luồng HITL theo Tier C với mandatory dry-run preview.

### Medium-risk (ESCALATE; brief preview)

```
rm -r <any>                      # recursive delete (ít hơn rf)
rm <large-glob>                  # glob delete
git rebase                       # history rewrite
git push (to protected branch)   # main, master
npm publish                      # publishing package
docker push                      # publishing container
gh pr merge                      # merging PR via CLI
gh release create                # public release
```

Nếu khớp: `escalate` với `medium_risk_pattern: <pattern>`. Luồng HITL theo Tier B-C tùy theo ngữ cảnh.

### Sensitive context (CHECK PATH)

Những lệnh này không nguy hiểm nói chung nhưng trở thành rủi ro khi áp dụng vào các đường dẫn nhạy cảm:

```
git checkout <ref> -- governance/    # discards Tier 1 changes
git stash                            # nếu cwd có uncommitted Tier 1 changes
mv <Tier 1 file>                     # renaming Tier 1 file
cat <secret file pattern>            # reading .env, *.key
```

Nếu khớp và đường dẫn là Tier 1 HOẶC mẫu secret pattern: `escalate`.

## Logic quyết định

```
function decide(payload):
    cmd = payload.tool_payload.command

    # Normalize: collapse whitespace, lowercase keywords like SQL verbs
    normalized = normalize(cmd)

    # Catastrophic check (no override possible)
    if matches_any(normalized, CATASTROPHIC):
        alert_founder_security(payload, normalized)
        return block(reason="catastrophic_pattern: " + matched_pattern)

    # High-risk check
    if matches_any(normalized, HIGH_RISK):
        if has_active_override(payload.session_id):
            return allow(reason="override active for high-risk command")
        return escalate(
            reason="high-risk command requires HITL approval",
            log_extras={ "pattern": matched_pattern }
        )

    # Medium-risk check
    if matches_any(normalized, MEDIUM_RISK):
        return escalate(reason="medium-risk command", log_extras={ "pattern": matched_pattern })

    # Sensitive context check
    affected_paths = extract_paths(cmd)
    if any_path_matches_sensitive(affected_paths):
        return escalate(reason="command touches sensitive path")

    return allow()
```

## Dữ liệu đầu vào cần thiết

- `payload.tool_payload.command` — full shell command string
- Optional: cwd từ `payload.context.current_working_directory`
- Override state cho session

## Các trường hợp đặc biệt

- **Composite commands (`&&`, `||`, `;`):** chia và kiểm tra từng phần riêng biệt. Block nếu BẤT KỲ phần nào là catastrophic; escalate nếu BẤT KỲ phần nào là high-risk
- **Pipes:** kiểm tra từng thành phần; phía consumer thường là phía nguy hiểm (ví dụ `curl | bash`)
- **Subshells (`$(...)`):** trích xuất và kiểm tra lệnh bên trong
- **Aliases / functions:** nếu lệnh gọi một hàm tùy chỉnh được định nghĩa sớm hơn trong session, hook này không thể nhìn vào bên trong. Ghi lại hạn chế này; được giảm nhẹ bằng cách `pre-bash` chạy trên mọi lệnh Bash (ngay cả những lệnh được phát hành từ một function)
- **`echo`:** hoàn toàn cho phép — ngay cả khi nội dung khớp với mẫu. Mẫu là nội dung, không phải hành động

## Quan sát

Ghi lại mỗi escalation/block với mẫu được khớp. Sau 30 ngày nhật ký, xem lại 10 mẫu được block nhiều nhất:
- Có false-positives nào không? Tinh chỉnh mẫu.
- Có mẫu nào thực sự nguy hiểm và được cố gắng thường xuyên không? Huấn luyện các agent (cập nhật CLAUDE.md hoặc role prompts).

## Hạn chế

Hook này **không phải** là một sandbox. Đó là một tripwire. Một kẻ thù có mục đích có thể vượt qua bất kỳ danh sách mẫu nào với đủ obfuscation:

- `r''m -rf /` (quoted)
- `bash -c $'$(echo cm0gLXJmIC8= | base64 -d)'` (encoded)

Defense in depth: agent chạy trong một non-root user với quyền truy cập tệp hạn chế, và host (Claude Code) cung cấp thêm sandboxing.

## Tham chiếu triển khai

```python
CATASTROPHIC = [
    r'\brm\s+-rf\s+/(\s|$|\*)',
    r':\(\)\{\s*:\|:&\s*\};:',
    r'\bmkfs\b',
    r'\bdd\b.*of=/dev/sd[a-z]',
    # ...
]

HIGH_RISK = [
    r'\brm\s+-rf\b',
    r'\bgit\s+push\s+(--force|-f)\b',
    r'\bgit\s+reset\s+--hard\b',
    r'\bDROP\s+TABLE\b',
    r'\bTRUNCATE\b',
    r'\bsudo\b',
    r'\bcurl\s+.*\|\s*(bash|sh)\b',
    # ...
]

# Compile once at module load
CATASTROPHIC_RE = [re.compile(p, re.IGNORECASE) for p in CATASTROPHIC]
HIGH_RISK_RE = [re.compile(p, re.IGNORECASE) for p in HIGH_RISK]

def decide(payload):
    cmd = payload['tool_payload']['command']
    normalized = ' '.join(cmd.split())
    for pat in CATASTROPHIC_RE:
        if pat.search(normalized):
            return {'decision': 'block', 'reason': f'catastrophic_pattern: {pat.pattern}'}
    # ...
```
