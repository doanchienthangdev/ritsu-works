## 18.3 12 Patterns trích lọc

### Pattern 1 — Compiled Truth + Timeline knowledge model

```
---
type: concept
title: <topic>
---
<Compiled truth — current best understanding, mutable>

---
- 2024-11-15: <event>  (timeline append-only)
- 2024-12-01: <event>
```

**Insight:** 2 zones per page — assessment (mutable) + evidence (immutable).
**Adopt for Ritsu:** semantic memory pages format.

### Pattern 2 — Auto-link extraction (zero LLM)

```
on every put_page:
  Parse markdown → Extract entity refs → Strip code-fences →
  Typed inference cascade → Within-page dedup → Stale-link reconciliation
```

Cost: $0/write. **Adopt for Ritsu:** post-page-write hook + ops.knowledge_links.

### Pattern 3 — Hybrid search stack

```
Query → Intent classifier → Multi-query expansion → 
[Vector + Keyword] → RRF → Cosine re-score → Backlink boost → 4-layer dedup
```

~20 deterministic techniques. **Adopt for Ritsu:** Bài #4 episodic recall upgrade.

### Pattern 4 — Minions: deterministic job queue

| | Minions | Sub-agents |

**Routing rule:** Deterministic → Minions, Judgment → Sub-agents.

### Upgrade #2 — Bài #5 Multi-Agent: Add Minions Routing

Routing rule:
- Deterministic (same input → same steps → same output) → ops.minion_jobs queue
- Judgment (input requires assessment) → subagent (existing)

Schema:
```sql
CREATE TABLE ops.minion_jobs (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  job_kind        text NOT NULL,
  payload         jsonb NOT NULL,
  status          text NOT NULL,
  parent_task_id  uuid REFERENCES ops.tasks(id),
  attempt_count   int DEFAULT 0,
  ...
);
```

**Cost impact: ~$50-100/month savings at v1.0 scale.**

### Upgrade #3 — Bài #4 Memory: Compiled-Truth + Auto-Link

Page format adoption + post-page-write hook for auto-link extraction. New schema:
```sql
CREATE TABLE ops.knowledge_links (
  source_slug     text NOT NULL,
  target_slug     text NOT NULL,
  link_type       text,
  occurrence_count int DEFAULT 1,
  ...
);
```
