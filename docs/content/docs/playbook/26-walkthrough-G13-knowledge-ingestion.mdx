#### Axis 2 — Pipeline Orchestration + Minions

**Pipeline pattern:**

```
ritsu.knowledge.ingest_request event
  ↓
SOP-INGEST-001-knowledge-ingest
  ↓
Steps (deterministic-heavy → Minions queue):
1. Fetch raw source
2. Dedup check (URL hash + content hash + similarity)
3. Quality assessment (filter low-value)
4. Normalization
5. Chunking
6. Per-chunk parallel:
   - Embed (pgvector)
   - Topic classification
   - Entity extraction
7. Aggregate per-source:
   - Generate summary (judgment → subagent)
   - Generate slug
8. Write wiki page (Bài #14 format)
9. Auto-link extraction triggers (Bài #14)
10. Emit ritsu.knowledge.ingested event
11. Update ops.ingestion_jobs status
```

## 26.6 Lessons captured

1. **Ingestion = upstream of knowledge graph** (Bài #14).
2. **Adapter pattern parallels surface adapter** (Bài #17).
3. **Dedup essential** (3 layers: URL hash + content hash + similarity).
4. **Voice notes = special category** (time-sensitive, classification + auto-routing).
5. **Cost tracking critical** (Whisper $0.006/min × 100 min/week = $30+/month).
6. **Quality filter prevents signal-to-noise drop.**
7. **Chunking strategy per source kind** (podcast time-based, article token-based, book chapter-based).
8. **Source attribution non-negotiable.**
9. **Re-ingestion preserves slug, updates compiled-truth.**
10. **Pipeline as SOP + Minions** (deterministic-heavy, parallel).
11. **Active subscriptions = scheduled polling.**
12. **Cross-bài-toán integration heaviest** (7 updates).
