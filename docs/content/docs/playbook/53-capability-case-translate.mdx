## 53.3 Kiến trúc 3 pha — plan → translate (Workflow) → build

- **plan** (`cli.cjs plan`, *tất-định, KHÔNG LLM*): nhận-diện định dạng → ingest về markdown chuẩn-hoá → nhận-diện mode (`book`/`doc`/`slides`) → chia đơn-vị (sách: chương tại TOC/H1; đơn-vị dài cắt tại ranh-giới mục, trần 3.500 từ-nguồn) → ghi *brief* dịch theo ngôn-ngữ đích + `plan.json` (kèm danh-sách task per-unit) vào workdir gitignored. `--dry-run` dừng tại đây và in kế-hoạch (mode, số chương, số từ, ước-tính chi-phí).
- **translate** (do **skill** phóng một **Workflow**): mỗi đơn-vị một agent, đọc *brief + đơn-vị nguồn*, ghi *đơn-vị đã dịch*. Brief ép kỷ-luật: **trung-thành-nhưng-tự-nhiên**, thuật-ngữ nhất-quán, giữ nguyên cấu-trúc markdown (`#`/`##`/`###`, `>` blockquote, `**đậm**`, list, bảng) **+ `<sup>N</sup>` chú-thích verbatim** + danh-từ-riêng. Danh-sách task nhúng làm `const` trong script (KHÔNG qua `args` — args lớn về dạng string làm `.map` ném). Workflow chỉ trả manifest nhỏ; bản dịch ghi ra file (context sạch). Đơn-vị lỗi được chạy lại trước khi build.
- **build** (`cli.cjs build`, *tất-định, KHÔNG LLM*): ghép đơn-vị đã dịch (nối các nửa đã cắt) → render mỗi định dạng yêu-cầu theo design system → ghi `<tên>.<lang>.<đuôi>` cạnh nguồn.

Điểm mấu chốt kiến trúc: **`cli.cjs` không bao giờ phóng agent**; skill sở-hữu việc fan-out (đúng yêu-cầu "dùng Workflow để dịch song song"). LLM chỉ xuất-hiện ở pha translate; ingest/split/render là Node/Python thuần.

## 53.4 Quyết định khoá

- **D1 — nhận-diện cấu-trúc tổng-quát, không tinh-chỉnh theo từng tài-liệu.** PDF: `get_toc()` → heuristic font-size theo cỡ-thân modal → fallback đậm/heading; header/footer chạy-trang lọc theo lặp-lại; `<sup>` chú-thích qua cờ superscript của PyMuPDF. DOCX: style đoạn. PPTX: theo slide. HTML: thẻ ngữ-nghĩa + trích nội-dung-chính. **Suy-giảm duyên-dáng** (không bao giờ hardcode theo file) — trên cuốn sách gốc, generic chia 39 đơn-vị (thô hơn 23 đơn-vị của run tinh-chỉnh tay; đây là *giới hạn trung thực* của v0.1, để dành cho `/cla extend` về sau).
- **D2 — palette đổi theo `--style`, typography là bundled.** Source Serif 4 + Inter (đủ dấu tiếng Việt, instanced tĩnh) là cặp chữ đọc cho *mọi* style ở v0.1; design system cấp **bản-sắc-màu**. Giữ mọi đầu-ra ổn-định + đúng-dấu.
- **D3 — dịch là một Workflow, do skill phóng.** Tách trí-thông-minh (dịch) khỏi cơ-khí (ingest/render).
- **D4 — đầu ra cạnh nguồn; phần làm-việc trong `runtime/` gitignored.** Thư-mục nguồn chỉ nhận artifact cuối.
- **D5 — Tier A + cầu-dao `--max-cost-usd`.** Cục-bộ, đảo-ngược-được, đo-đếm. Gọi lệnh = khẳng-định quyền dịch.
- **D6 — tái-dùng, không fork.** `--style` đọc thư-viện design-system của repo cho palette ngoài-claude; các renderer dùng chung `design.py`.

## 53.5 Chất lượng dịch — brief là tài-sản

Phần "thật hay, thật sát" sống trong `brief.md` được tham-số-hoá theo ngôn-ngữ đích: persona dịch-giả-non-fiction hàng-đầu; *faithful-not-literal*; tái-cấu-trúc cú-pháp về tự-nhiên; idiom → idiom (không calque); giữ danh-từ-riêng + số + đơn-vị; **giữ verbatim `<sup>` + mọi markdown**; nhất-quán thuật-ngữ (kèm `--glossary` tuỳ chọn). ## 53.7 Dogfood + bài học

Dogfood end-to-end: một tài-liệu ngắn qua *đúng đường lệnh* (plan → Workflow 1-agent → build) cho ra tiếng Việt thật, render đủ 5 định-dạng, `<sup>` giữ nguyên, "lông mày" mục + folio đất-nung đúng phong-cách Claude. `--dry-run` trên cuốn sách 401 trang chứng-minh nhận-diện book-mode + chia chương trên một cuốn sách thật. 61 ca vitest cho lớp parse (detect/params), `check-consistency` xanh sau đăng-ký (registry + ROLES caps `ai-ops-translate` + resolver catalog/INDEX + SOP-AIOPS-013).

**5 bài học:**
1. **Tách-pha biến việc-tay thành capability.** Một bản dịch sách thủ-công = ingest + split + (song-song dịch) + render. Đặt tên 4 pha ⇒ một lệnh tổng-quát.
2. **Trí-thông-minh ở Workflow, cơ-khí ở script.** Dịch (phán-đoán) = agent; đọc/chia/ghép/đóng-gói (tất-định) = Node/Python thuần, testable.
3. **Brief là hợp-đồng chất-lượng.** Một brief chung + glossary giữ một cuốn sách mạch-lạc qua N agent song song; `<sup>`-verbatim là bất-biến chấp-nhận.
4. **Trung-thực về fidelity hơn hứa-hão.** v0.1 nói thẳng pdf/epub/md bóng-bẩy, docx sạch, pptx dùng-được, và generic-split thô hơn tinh-chỉnh-tay — kèm lộ-trình `/cla extend`.
5. **Tái-dùng trục design-system.** `--style` là DATA (đọc DESIGN.md → palette), không thêm dòng dispatch — đúng bài học Chương 47/48.

## 53.8 v0.2 — Bản nâng STEM (giữ ảnh/bảng · bảo toàn công thức · giữ-nguyên-format · đầu ra LaTeX)

`/cla extend` (founder-proxy) nâng `/translate` lên v0.2 với 4 năng lực phục vụ tài-liệu khoa-học/AI-ML/textbook/paper — mỗi cái dogfood end-to-end:

- **Req 1 — Ảnh / biểu-đồ / bảng.** `engine.py` trích **hình raster + `find_tables()`** từ PDF và **ảnh + bảng** từ docx, **theo đúng thứ-tự trong tài-liệu**, vào `assets/` kèm tham-chiếu `![alt](assets/…)`. Renderer mang theo vào pdf (base_url), epub (nhúng item), md (copy), **latex (`\includegraphics`)**. Logo/watermark lặp + icon \<50px bị loại. Brief dặn agent **giữ nguyên `(path)`, chỉ dịch alt**.
- **Req 2 — Công thức toán/khoa-học.** Brief giữ **VERBATIM** mọi thứ trong `$…$`, `$$…$$`, `\(…\)`, `\[…\]`, môi-trường toán LaTeX — copy từng ký-tự, KHÔNG dịch tên biến/hàm. Đầu ra **latex typeset công-thức NGUYÊN-BẢN** (amsmath). docx Office-Math (OMML) bắt best-effort thành `$…$`; toán trong PDF giữ dưới dạng hình cắt. Trung-thực: đầu-ra không-latex hiện `$…$` thô — dùng latex để typeset.
- **Req 3 — Giữ-nguyên-format (`--preserve`).** Một pipeline song-song (`preserve.py`): `plan` trích **các đoạn text** (`⟦S{id}⟧`, khoá theo CHỈ-SỐ-ĐOẠN-ĐẦY-ĐỦ), cùng Workflow dịch, `build` chèn lại vào **bản sao bản gốc** (run text đầu nhận bản dịch, các run khác để trống — giữ style + ảnh + bảng + layout). docx/pptx → **giống hệt bản gốc**, chỉ đổi ngôn-ngữ; PDF → quay về reflow (v0.2). **Bug đã sửa**: id phải là chỉ-số-đoạn-đầy-đủ ở CẢ plan lẫn build (lúc đầu build đếm-chỉ-đoạn-dịch-được → lệch, "Siêu tham số" rơi vào ô bảng) → enumerate MỌI đoạn ở cả hai phía.
- **Req 4 — Đầu ra LaTeX.** `latexout.py` chuyển block → `.tex` tự-chứa (`\documentclass{book|article}`, XeLaTeX, `\setmainfont` Source Serif 4 đủ-dấu, heading đất-nung, `\includegraphics`, `tabular`, math passthrough); `--out=pdf-latex` biên-dịch qua **tectonic** (KHÔNG cần cài LaTeX hệ-thống). NEW định-dạng **nguồn** `.tex` (`ingest_latex`: dịch prose, giữ toán + cấu-trúc).

**Bẫy kỹ-thuật đã vượt (bài học hệ-thống):** (a) **tectonic sandbox** chặn mở file tuyệt-đối → stage font/asset *bên trong* cây biên-dịch + đường-dẫn *tương-đối* + chạy với `cwd`=thư-mục .tex; (b) **fontspec `*`** nở thành tên-họ có dấu cách "Source Serif 4-Regular" ≠ file `SourceSerif4-Regular.ttf` → tham-chiếu **tên-file tường-minh**; (c) **Inter instanced hỏng** ("unknown file format") vì nguồn là WOFF2 → `f.flavor=None` khi save (PIL + XeTeX đều từ-chối nếu không); (d) LaTeX headings dùng serif (đủ-dấu) thay Inter cho chắc.
