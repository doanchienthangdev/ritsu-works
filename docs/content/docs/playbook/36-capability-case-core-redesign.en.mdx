## 36.7 Đột phá pattern mới: AI-as-founder-substitute

Capability này thử nghiệm pattern mới chưa có trong wiki-sync hay docs-engine: **AI synthesizes founder think-heavy content from existing repo material**.

Standard CLA Phase 7 Sprint 1 (founder docs) ước tính 6-10h founder solo writing. Actual: founder spent ~5 phút giving "go" + CC synthesized 9 docs (charter, founder-profile, north-star, icp-summary, positioning, values, principles, ai-native-philosophy, INDEX) trong ~15 phút bằng cách:

1. **Mining existing canonical material:** product.md (positioning), brand_voice.md (voice), transparency.md (boundaries), CLAUDE.md (operating belief), governance/HITL.md (decision rights), governance/ROLES.md (workforce structure), .archives/pillars/PLAN.md (architecture rationale).
2. **Tagging với intellectual honesty:** mỗi doc filled bằng AI có frontmatter:
   ```yaml
   ai_synthesized_v0_1: true
   ai_synthesized_at: 2026-05-21
   ai_synthesized_from: [product.md, brand_voice.md, transparency.md, ...]
   ai_synthesis_note: "First-draft content synthesized by Claude Code from existing repo material. Founder reviews + ratifies at 30-paying milestone."
   ```
3. **v0.1 calibration với explicit revisit trigger:** values + principles + ai-native-philosophy đều tagged `revisit_at: 30-paying` + `revisit_trigger: <specific event>` để force re-author từ observed customer data sau khi có evidence.

**Compression**: 6-10h founder solo → ~5 min watch + 15 min CC = ~30-40× faster.

**Risk acknowledged**: AI synthesis của values/principles pre-PMF có thể codify wrong values. Mitigation: explicit v0.1 tagging + revisit ceremony + founder reviews PR Tier C. Per **Boil-the-lake** principle (`principles.md` §3), khi AI compresses marginal cost to near-zero, do COMPLETE thing — including the v0.1 calibration discipline.

**When this pattern applies**:
- Content can be SYNTHESIZED from existing canonical material (not invented)
- v0.1 tagging với revisit_at trigger acceptable (not load-bearing decision yet)
- Founder time scarce + AI capacity ample
- Reviewer concern explicit: "structurally hard to estimate pre-PMF" applies to founder THINKING, not AI synthesis

**When this pattern DOES NOT apply**:
- Wedge (SOP-PRODUCT-002 PG gate — wedge is DISCOVERED not declared)
- Vocabulary (glossary — stable only after real usage)
- Decisions requiring observed customer behavior (post-PMF only)

## 36.11 Lessons learned

### What worked

1. **CLA framework worked end-to-end** for ground-truth foundation use case (not just tool integration). All 8 phases ran với state persistence + resume semantics intact across multiple sessions.

2. **Compressed Phase 4+5 saved $2-3** without quality loss. Brainstorm + adversarial spec review iter 1+2 (5/10 → 7/10) provided equivalent input to full CxO panel + Muse panel. Tier C founder approval ceremony preserved.

3. **CTO Phase 2 dispatch loop closed.** 2 verified gaps + 3 mandates → architect spec → Sprint 2 implementation acceptance. Validates @cto persona dispatch pattern as reliable architecture review layer.

4. **AI-as-founder-substitute pattern compressed Phase A 30-40×.** Founder authorized inline (Tier C); AI synthesized from existing repo material; v0.1 tagging + revisit_at trigger for intellectual honesty. New pattern documented for future capabilities.

5. **Bilingual docs pipeline integrates smoothly.** 3 docs sync + translate cycles totaling ~$0.17 over 1 day. Each PR auto-deploys to Vercel in ~5 min.

### What didn't work

1. **CI warn-tier check fails on every PR** — pre-existing 27 ROLES.md skill stubs. Tech debt that pre-dates this capability. All 4 PRs had to merge despite this warn-tier failure (warn-tier is non-blocking per branch protection).

2. **`docs-translate.cjs` requires `ANTHROPIC_API_KEY` env** — per spec it shouldn't when invoked from Claude Code Desktop. CC had to manually source `.env.local` each run. Filed as docs-engine carry-forward.

3. **`.mdx` vs `.vi.mdx` propagation non-obvious** — `docs-translate.cjs` writes to `.vi.mdx`; default URL serves from `.mdx`. CC had to manually `cp .vi.mdx → .mdx`. Filed as docs-engine carry-forward.

4. **Founder effort estimate was 4-40× off (in good direction)** — initial estimate 6-10h founder solo. Actual: ~25 min total. The "structurally hard to estimate pre-PMF" reviewer concern applied to founder THINKING time, NOT to AI synthesis time. Lesson: when CC can do the work, recompute Phase A as PR-review-only.
