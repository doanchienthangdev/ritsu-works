## 35.6 Secret redaction (3-layer fail-loud)

Layer 1: walker exclude list (in `scripts/docs-sync.cjs`):
```javascript
const WALKER_EXCLUDE = [
  "governance/SECRETS.md",
  "00-charter/founder-profile.md",
  "runtime/secrets/",
  "wiki/", ".archives/", "raw/",
  "node_modules/", ".next/",
];
```

Layer 2: regex scrub `docs/lint-secrets.cjs`. Patterns:
- `override:\s+\S+(\s+\S+){4,}` — HITL magic phrase
- `[a-z0-9]{20}\.supabase\.co` — Supabase project URL
- `sk-ant-[A-Za-z0-9_-]{20,}` — Anthropic API key
- `sk-[A-Za-z0-9]{32,}` — OpenAI API key
- `sb_(public|secret|publishable)_...` — Supabase service keys
- `ghp_[A-Za-z0-9]{36,}` + `github_pat_...` — GitHub PATs
- Telegram bot tokens

Layer 3: Husky pre-commit + Vercel build prebuild script invoke `node lint-secrets.cjs`. **Fail loud, no silent scrub** — operator must fix source or add to WALKER_EXCLUDE.

## 35.7 v1.2 incremental translation deep dive

**Pre-v1.2 bug:** walker overwrote VI body khi source changed → mọi `/docs sync` after source edit erased translations.

**v1.2 fix:** walker has 2 idempotency branches now:
```
existingHash === sourceHash               → SKIP (preserve both .mdx + .en.mdx)
existingHash !== sourceHash AND lang=vi   → PRESERVE VI body + flag stale
                              AND lang=en → REWRITE EN (always fresh)
```

Stale flag = `needs_retranslation: true` + `translated_source_hash: <old_hash>`.

`/docs translate` skill orchestrates re-translation:
1. Run verifier `--list-needs-translation` → list stale + untranslated files.
2. Batch by category (~6 files/batch).
3. Dispatch Claude Code subagent (haiku, no API key) per batch.
4. Each subagent translates → updates `translated_source_hash = source_hash` + removes `needs_retranslation`.
5. Re-verify. Iterate ≤ 3 times.
6. Local `pnpm build` + commit + push.

**Self-demo proof (PR #68):**
- Edited `.claude/commands/docs.md` + `knowledge/capability-registry.yaml` (this v1.2 work)
- Walker on commands area: 1 stale VI preserved (`docs.mdx`)
- Walker full pass: 1 more stale (`capability-registry.mdx`)
- `/docs translate` agent dispatched → 2 files translated
- Verifier: 100% Fresh / 0 Stale

## 35.8 Lessons learned

1. **CTO's `<!-- generated-by -->` marker had to change.** MDX2 strict parser rejects `<!--`. Changed to JSX comment `{/* generated-by */}` mid-Sprint 1. Lesson: validate idempotency markers against the actual rendering toolchain BEFORE Sprint 5 architect freeze.

2. **MDX escape is pervasive.** Walker escapes ALL `<` outside code blocks → `\<`. Caught `<email@x>`, `<source-slug>`, `<task-id>` patterns that would otherwise crash MDX parser. v1.0.1 candidate: known-tag allowlist (`<a>`, `<details>`, `<summary>`) — current blanket-escape is pragmatic.

3. **Fumadocs v14 vs v15 docs.** v15 introduces `defineI18n`, dot-suffix parser. v14 (pinned for stability) uses different APIs. Spent ~30 min debugging because Context7 + Fumadocs docs serve v15 examples. Lesson: pin docs URL alongside library version in spec.

4. **Sandbox blocks `.env.local` read.** API-based translator (`scripts/docs-translate.cjs`) needs `ANTHROPIC_API_KEY` but Claude Code sandbox blocks read of `runtime/secrets/.env.local`. Workaround: dispatch subagents inside Claude Code Desktop (use subscription, no API key). v1.2 codified này thành `docs-engine/translate` skill.

5. **`<Cards>` Fumadocs component for landing is the canonical pattern.** Hand-written HTML on landing → operators confused. `<Cards><Card href ... description />` → operators recognize, theme-respecting, mobile-responsive.

6. **`/api/raw/<slug>` endpoint = first-class AI runtime support.** Built originally for cofounder convenience; turned out to be MORE valuable for AI subagent context loading. Lesson per CPO Phase 4 P0 reframe: AI agents are primary audience for many "internal" pages, not just operators.

7. **5 versions in 10 hours is fine if each is cheap.** Total v1.0→v1.2 cost ~$4 LLM, ~10 hour wall-clock. Pre-CLA framework, đây sẽ là weeks. Bài #20 sub-flows (fix/extend/revise/tune) are right-sized — không cần full ceremony cho minor extend.
