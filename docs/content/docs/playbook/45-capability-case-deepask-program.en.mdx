## 45.4 Capability 2 — deepask (5-stage loop + Format Engine)

`/deepask "<q>" [--format][--sources][--depth][--dry-run]` chạy vòng lặp 5 bước:

1. **decompose** → MECE sub-needs, mỗi cái gắn IA-type A/B/C/D, depth-bounded ≤6 (standard)/≤12 (deep).
2. **resolve** → mỗi sub-need gọi resolver-plan → `ResolverPlan v1` (content_axis + capability_axis + governance + goal_metrics + no_coverage). deepask **không route**.
3. **execute / fan-out** (parallel) → ĐỌC content_axis + CHẠY capability_axis (auto Tier-A; surface Tier-B+; refuse D-MAX); ủy quyền web cho `deep-research`. deepask **tự viết** SQL read-only / câu wiki_ask / params — grounded trong `grounding_ref`/`columns_hint`, **không bịa tên cột** (nguyên tắc CLAUDE.md #3); self-correct có giới hạn (đọc lại schema → retry 1 lần → honest no_coverage, không bao giờ bịa kết quả).
4. **synthesize** → Pyramid (kết luận trước); **mọi claim đều cite**; authority-rank (SoR thắng fact, memory thắng judgement); flag conflict; tag freshness; adversarial-verify; phát ra IR format-agnostic.
5. **completeness-critic** → coverage matrix + MECE re-check + live-probe → **COMPLETE | PARTIAL-WITH-HONEST-GAPS** (+ remedy chính xác); ≤1 follow-up round.

**Format Engine:** IR → dispatch table → artifact, **tái sử dụng** skill có sẵn (anthropic-skills:\{pdf,docx,pptx,xlsx,canvas-design}, mermaid MCP, design:*, playbook-builder). 12 formats + smartauto. **Default = `inline`** (refinement v1.0.1, 2026-05-31): không gõ `--format` → câu trả lời cited render **thẳng vào hội thoại, KHÔNG tạo file** (vì đa số câu hỏi cần câu trả lời nhanh, không cần artifact trên đĩa). Chỉ khi gõ `--format` (kể cả `smartauto`) mới sang **file mode**: artifacts → `.archives/deepask/<date>-<slug>/` (`answer.md` + `plan.json` + `sources.json` + bản render). Audit rows (`ops.deepask_runs`/`_coverage`) ghi ở CẢ hai mode (`artifact_path` = NULL khi inline).
