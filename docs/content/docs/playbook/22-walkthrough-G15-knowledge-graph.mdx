**Schema:**

```sql
CREATE TABLE ops.knowledge_links (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  source_slug     text NOT NULL,
  target_slug     text NOT NULL,
  link_type       text NOT NULL,
  confidence      numeric DEFAULT 1.0,
  occurrence_count int DEFAULT 1,

  last_seen_at    timestamptz DEFAULT now(),
```

#### Axis 2 — Auto-Link Extraction (zero LLM)

**post-page-write hook flow:**

```
1. Parse markdown → wikilinks + bare slugs
2. Strip code-fences (no false positives)
3. Validate target slug exists
4. Type inference cascade (specific > generic):
   - "founded" pattern → founded edge
   - "works at" + role → works_at với metadata
   - "invested in" → invested_in
   - default → mentions
5. Within-page dedup (5 references = 1 edge với occurrence_count=5)
6. Stale reconciliation:
   - Diff old vs new version
   - Links removed → mark is_stale=true
   - New links → INSERT
7. Atomic transaction
```

**Tier 1 declarative rules:**

```yaml
# knowledge/link-inference-rules.yaml
rules:
  - id: founder-pattern
    pattern: "(\\[\\[person/[\\w-]+\\]\\]) (?:founded|co-founded) (\\[\\[company/[\\w-]+\\]\\])"
    edge_type: founded
    confidence: 0.95
    
  - id: works-at-with-role
    pattern: <regex with role capture>
    edge_type: works_at
    metadata: { role: "$2" }
    confidence: 0.90
    
  - id: invested-in
    pattern: <regex>
    edge_type: invested_in
    confidence: 0.95
    
  - id: customer-uses-product
    pattern: <regex>
    edge_type: uses
    confidence: 0.85
    
  - id: mentions-fallback
    pattern: "\\[\\[([\\w-]+/[\\w-]+)\\]\\]"
    edge_type: mentions
    confidence: 1.0
```

**Cost: $0/page write** (regex only, no LLM call).

**Skill marked deterministic** → ops.minion_jobs queue (GBrain Minions). Bulk backfill = parallel jobs.

#### Axis 3 — Cross-Source Edges

State transitions (Bài #13) + events (Bài #11) + ops.tasks (Bài #5) auto-emit edges.

**Bài #13 integration — DB trigger after state transition:**

```sql
CREATE OR REPLACE FUNCTION emit_state_transition_edge()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO ops.knowledge_links (source_slug, target_slug, link_type, ...)
  VALUES (
    'customer/' || (SELECT slug FROM customers WHERE id = NEW.customer_id),
    'customer-state/' || NEW.to_state,
    'transitioned_to',
    1.0,
    jsonb_build_object('at', NEW.changed_at, 'from_state', NEW.from_state)
  )
  ON CONFLICT DO UPDATE SET occurrence_count = ops.knowledge_links.occurrence_count + 1;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

**Pattern:** Knowledge graph emerges from BOTH text content AND structured operational data. Unified table, unified queries.

#### Axis 4 — Graph API + Search Integration

**Recursive CTE traversal:**

```sql
WITH RECURSIVE traversal AS (
  SELECT source_slug, target_slug, link_type, 1 AS depth, ARRAY[source_slug] AS path
  FROM ops.knowledge_links
  WHERE source_slug = $1 AND NOT is_stale
  
  UNION ALL
  
  SELECT kl.source_slug, kl.target_slug, kl.link_type, t.depth + 1, t.path || kl.source_slug
  FROM ops.knowledge_links kl
  JOIN traversal t ON kl.source_slug = t.target_slug
  WHERE NOT kl.is_stale
    AND t.depth < 10  -- DoS prevention
    AND NOT (kl.target_slug = ANY(t.path))  -- cycle prevention
)
SELECT DISTINCT * FROM traversal ORDER BY depth, source_slug;
```

**`graph-traverse` skill** wraps CTE với type filters, direction, depth, output formatting.

**MCP tool `ritsu.knowledge.graph_query`** (Bài #12):
- Inputs: source_slug, edge_types[], direction, depth (max 10)
- Returns connected entities với typed edges
- Role-scoped (founder + operator-all)
- Cost-bucket: read-only

## 22.6 Lessons captured

1. **Graph is not optional.** 2.8x P@5 gap per BrainBench.
2. **Auto-link extraction = $0/write.** Deterministic regex, no LLM cost.
3. **Page format convention essential.** Compiled-truth + timeline.
4. **Slug convention non-negotiable.** Without `<type>/<slug>`, edges ambiguous.
5. **Operational data = graph data too.** State transitions, events, ops.tasks emit edges.
6. **Postgres-native > separate graph DB.** Recursive CTEs at v1.0 scale.
7. **Backlink boost in search ranking.** Well-connected entities surface.
8. **Stale-link reconciliation prevents drift.**
9. **Type inference cascade (specific overrides generic).**
10. **GBrain validates Postgres + recursive CTE + auto-link at 17,888-page scale.**
