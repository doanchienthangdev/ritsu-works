# ritsu — Ritsu house video style

The default look + motion for Ritsu videos: electric cyan `#0ABCD0` on deep slate, Inter + JetBrains
Mono, the four-blade mark, cinematic letterbox, restrained motion (AI is the leverage, not the
spectacle).

- **[`frame.md`](frame.md)** — the authoritative video spec (frame-scale, HyperFrames-loaded).
  Fine-tuned from the HyperFrames "broadside" frame pack and re-skinned to Ritsu. Author against this.
- **[`DESIGN.md`](DESIGN.md)** — a pointer to `frame.md` (kept for the design-spec precedence chain).
- Extends the brand system at `00-core/design-system/ritsu/DESIGN.md`.

`assets/` — reusable binaries (logo, mark, fonts, LUTs, sfx). The canonical brand assets currently
live at `00-core/design-system/ritsu/assets/` (mark, logo, lockup, favicon).
