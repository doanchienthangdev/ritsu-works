# ritsu — Ritsu house video style

The default look + motion for Ritsu videos: electric cyan `#0ABCD0` on deep slate,
Inter + JetBrains Mono, the four-blade mark, cinematic letterbox, restrained motion
(AI is the leverage, not the spectacle).

Extends the brand system at `00-core/design-system/ritsu/DESIGN.md`.
See `DESIGN.md` (stub — to be authored) for the video-only tokens.

`assets/` — drop the reusable binaries here (logo, mark, fonts, LUTs, sfx). The
canonical brand assets currently live at `00-core/design-system/ritsu/assets/`.
