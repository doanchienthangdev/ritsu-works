## Part A — HeyGen's presentation standard (what the best channel in this niche actually does)

### Titles
Title Case, ~45–65 chars, keyword/outcome front-loaded, brand often *last* or in the thumbnail. Six repeatable formulas:

| Formula | Real HeyGen example |
|---|---|
| Curiosity gap + parenthetical | *HeyGen Just Combined Two of Its Best Tools **(Here's What Changes)*** |
| How + audience + outcome ∣ Series | *How Realtors Turn One Listing Into Weeks of Content ∣ SMB Series EP. 7* |
| "Everything You Can Do With X" | *Everything You Can Do With HeyGen's Free Plan* (their #1, 16K views) |
| Number/news proof | *HeyGen Hits $200M ARR: 22 New Features in 30 Days* |
| Contrarian service | *I Tried 5 Different AI Avatars So You Don't Have To* |
| Outcome promise (+ ALL-CAPS beat) | *Turn **ANY** Website into a Viral Video*, *Make a Month of Content Without Filming Once* |

Series are branded with a ` ∣ ` pipe or ` - ` dash + `(Episode N)` / `EP. N`.

### Description — the canonical template (identical across their videos)
```
[Hook: 1–3 sentences. A question or bold claim, benefit-led.]

👉 Try HeyGen: https://www.heygen.com/?utm_source=organicyoutube        ← primary CTA, above the fold

[Body: "In this video…" / "You'll learn how to…"]

Timestamps:                                                            ← 00:00 first = YouTube chapters
00:00 Hook
01:09 …

🔔 Subscribe: https://www.youtube.com/@heygen_official?sub_confirmation=1

Discord / X / LinkedIn / Instagram / TikTok

🔗 Everything you need:                                                ← resource block (arrow links)
Docs → https://…
GitHub → https://…

#HeyGen #AIVideo #AIAvatar #VideoAgent #ContentCreation               ← optional, 3–5, at the very bottom
```

### Link principles (the rules, not just the layout)
- **Primary product link is ALWAYS UTM-tagged** (`?utm_source=organicyoutube`) → every signup is attributable.
- **Subscribe link ALWAYS ends `?sub_confirmation=1`** → pops the one-click subscribe dialog.
- **First link sits within the first ~3 lines** (above the "…more" fold ≈ 157 chars).
- **One primary CTA, repeated once** (top + after the subscribe line). Never link-spammed.
- Emoji anchors do the wayfinding: **👉** CTA · **🔔** subscribe · **🔗** resources · **⌨️** commands · **💬** prompts · **✅** feature bullets. Inside lists, **`→`** separates label from URL.

### Hashtags
Optional. When present: **3–5**, brand + category, at the description bottom (`#HeyGen #AIVideo #AIAvatar #VideoAgent #ContentCreation`). The first 3 render *above* the title on the watch page.

### Tags (hidden `keywords`)
HeyGen reuses **one channel-wide set of ~15** on nearly every video (`AI, AI Avatar, Faceless AI, AI Video Generator, Text to video AI, AI Lip Sync, AI Avatar Tutorial…`) — a channel-identity signal, **not** per-video SEO. **Ritsu should do the opposite** (see Part E): a young channel with a specific ICP wins on *per-video long-tail* tags. **Category:** Science & Technology.

> Strategy grounded in the ICP (`00-core/icp-summary.md`: US-led, English-speaking, mastery-motivated serious learner; sharpest wedge = the US college STEM/pre-professional student with an exam) + category conventions. **Not** live search-volume data — validate with a keyword tool or Search Console once the channel has impressions.

| Cluster | Keywords | Intent / value |

**Prioritize for THIS video:** `AI study tool` · `AI tutor` · `study with AI` · `turn PDF into quiz` · `active recall` · `spaced repetition` · `exam prep AI` · `Quizlet/Anki alternative`.

Put the brand + a bold 3–5 word phrase in the **thumbnail** ("MASTERY, NOT RE-READING") so the title can spend its characters on keywords.

## Part F — Conversion links, ranked (where the click has to go)

All roads lead to **`/signup`** (free account, no card — the activation event). Priority + placement:

| Priority | Link | Role | Put it… |
|---|---|---|---|
| **1** | `ritsu.ai/signup` **(UTM'd)** | The conversion endpoint — free account, no card | Description line 2 (above fold) · **pinned comment** · YouTube **end screen** (last 20s) |
| **2** | `ritsu.ai/pricing` **(UTM'd)** | Purchase / upgrade intent (Free→Plus→Pro→Ultra) | Resource block · end screen |
| **3** | `/features/learning-commands` · `/knowledge-map` · `/every-source` · `/spaced-review` | Product education — mid-funnel, one per hero beat | Resource block · **cards** at the matching beat timestamp |
| **4** | `/use-cases/*` (exam-in-3-days, textbook, YouTube, research paper) | High-intent, lets the viewer self-select their job | Resource block |
| **5** | `ritsu.ai/#demo` | "See it in action" on the homepage | Optional, if not linking a feature page |

**Also do (HeyGen plays this well):**
- **Pinned comment** = the signup link + one line ("Start free, no credit card → …"). Highest-converting real estate on YouTube.
- **UTM every conversion link** (`utm_source=youtube&utm_medium=organic&utm_campaign=launch-film`) so `02-sales` / `10-metrics` can attribute signups to the film. Vary `utm_content` per placement (`desc`, `pinned`, `endscreen`) to see which converts.
- **End screen (last ~20s):** Subscribe element + a link element → `/signup`. The film already ends on a clean brand hold, so the end-screen overlay lands cleanly.
- **Cards** at 0:40 (→ every-source), 1:00 (→ learning-commands), 1:36 (→ spaced-review).
