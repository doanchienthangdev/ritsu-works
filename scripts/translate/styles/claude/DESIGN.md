# Claude — Design System (bundled default for /translate)

Warm, literate, calm — the feel of a well-made book. Ivory paper `#FAF9F5`, a single
clay accent `#CC785C` (deeper `#B24A2E` for rules/emphasis), warm near-black ink
`#1A1915`, serif **Source Serif 4** for reading, sans **Inter** for labels/folios.
The clay accent is the only color event on the page — one warm gesture, like a ribbon
in a hardcover. Used for translated books, reports, essays, and documents.
